# 26.11.5 (2026-11-09)

## 접속
- 리소스팩 용량을 크게 줄였습니다. 암호화한 팩 전체가 2.96MB에서 1.26MB로, 기본 팩은 2.51MB에서 0.85MB로 줄었습니다. 시험 접속에서 접속 시간이 17.6초에서 11.4초로 줄었습니다.
- 저장 네트워크 케이블과 부착물은 종류마다 모델 하나로 모든 연결 모양을 그립니다. 체 세 종류도 모델 하나를 함께 씁니다. 보이는 모양은 이전과 같습니다.
- 같은 그림인 기계 텍스처를 한 파일로 합치고, 쓰지 않는 텍스처와 Ore UI 스타일을 지웠습니다. 모든 이미지를 다시 압축했습니다.

## 도관
- 에너지, 아이템, 액체 도관망은 블록을 놓거나 부수거나 이웃이 바뀔 때만 다시 계산합니다. 도관 묶음은 더 이상 틱마다 돌지 않습니다.
- 에너지와 액체 도관망은 Mekanism처럼 버퍼를 가집니다. 남는 양을 담아 두었다가 모자랄 때 채웁니다. 버퍼는 도관마다 저장되고 WAILA에 보입니다.
- 도관을 하나 놓거나 부술 때는 그 주변만 다시 맞춰서, 큰 도관망에서도 렉이 줄었습니다.
- 이웃 블록이 바뀔 때 에너지를 두 번 나눠 주던 문제를 고쳤습니다.

## 화면
- 로비를 바닐라 Ore UI 색으로 그리고, 탭에 이름을 붙였습니다.

## 운영자
- 접속할 때마다 팩 전송, 게임 시작, 클라이언트 로딩에 걸린 시간을 로그에 남깁니다. 시작할 때 커스텀 블록, 상태, 퍼뮤테이션 수를 로그에 남깁니다.
- 블록 상태 수와 도관 그리기를 시험하는 상태 프로브(`SKYGEAR_STATE_PROBE=pair2`)를 추가했습니다. 끄면 아무것도 등록하지 않고 팩도 그대로입니다.
- 블록 텍스처 중복을 합치는 `tools/texdedup` 을 추가했습니다.
