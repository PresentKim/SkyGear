# 26.11.3 (2026-11-05)

## 저장 네트워크
- 리파인드 스토리지처럼 아이템을 모아 두는 저장 네트워크를 더했습니다. 네트워크 제어기, 케이블, 1k부터 64k까지의 디스크를 넣는 디스크 드라이브, 터미널, 가져오기·내보내기 장치, 상자·서랍·서랍 제어기를 잇는 외부 저장소, 패턴 인코더, 자동 제작기가 있습니다.
- 자동 제작은 필요한 재료를 계산하고 먼저 맡아 둔 뒤 만듭니다.
- 터미널 창은 인벤토리 화면입니다. 검색창, 네트워크 목록, 플레이어 인벤토리가 있고, 터미널 블록에서는 3x3 제작 칸도 씁니다. 제작 칸의 빈 칸은 네트워크에서 다시 채웁니다.
- 터미널에 바닐라 모양의 레시피 책을 붙였습니다. 섬에서 열린 레시피만 보이고, 누르면 네트워크와 인벤토리에서 재료를 칸에 놓습니다. 연구로 열지 않은 레시피는 만들 수 없습니다.
- 웅크리고 누르면 무엇을 들었든, 네트워크가 꺼져 있어도 터미널 창이 열립니다.

## 서랍
- 스토리지 컨트롤러는 스토리지 관리 블록이 되고, 스토리지 링크는 서랍 테두리가 됩니다. 기존 저장은 시작할 때 이름과 업적 기록을 새 블록으로 옮깁니다.
- 서랍 인터페이스를 더했습니다. 같은 묶음의 관리 블록처럼 클릭, 호퍼·도관 입출력, 목록을 씁니다. 한 묶음에 관리 블록이 둘이면 멈추므로, 접근 지점은 인터페이스로 늘립니다.

## 화면
- 서버가 그리는 인벤토리 화면이 바닐라 인벤토리처럼 움직입니다. 집기, 놓기, 오른쪽 클릭으로 반 집기와 하나 놓기, 더블 클릭으로 모으기, 끌어서 나누기, Shift 이동을 쓰고, 창 밖을 누르면 든 아이템을 버립니다. 터치도 지원합니다.
- 아이템 등급을 칸 테두리 대신 툴팁 테두리 색으로 보여 줍니다.
- 화면이 게임의 안전 영역 안에 들어옵니다.

## 이차원 사냥
- 보구와 몬스터 능력에 pixelfx 픽셀 이펙트를 입혔습니다. 불꽃 고리, 번개 지팡이, 서리 부메랑, 석궁, 회전 칼날, 처치 연기, 몬스터의 폭발·순간이동·회복이 있습니다.
- 이펙트 픽셀은 바닐라처럼 한 픽셀이 약 1/16블록입니다. 위로 솟는 이펙트는 서고, 바닥에서 퍼지는 이펙트는 바닥에 눕습니다.

## 저장 데이터
- 저장마다 데이터가 어느 SkyGear 버전인지 기록하고, 시작할 때 더 새 버전의 데이터 패치를 데이터베이스와 월드를 백업한 뒤 차례로 적용합니다.

## 운영자
- `/sgdebug fx <종류>` 는 이펙트를 사냥 카메라로 보여 주고, `/sgdebug net` 은 전원이 들어오고 아이템이 찬 네트워크를 만들어 터미널을 엽니다.
