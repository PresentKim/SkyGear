# 26.11.4 (2026-11-06)

## 기계
- 모든 기계 창을 게이지가 있는 Ore UI 화면 하나로 그립니다. 창 높이는 줄 수에 맞추고, 빈 게이지는 어둡게 그립니다.
- 인벤토리 제목은 왼쪽에, 기계 칸은 바닐라 화로처럼 가운데에 둡니다.
- 기계, 저장 네트워크, 수집기, 제작기, 서랍의 창을 그냥 오른쪽 클릭으로 엽니다.
- 자동 채굴기가 캘 블록을 보여 주고, 클릭한 면을 향해 놓입니다.
- 범위가 있는 기계는 X, Y, Z 축마다 범위를 정합니다. Item Collector처럼 숫자를 올리고 내리는 창에서 정하고, 범위는 반투명 상자로 보입니다. 기계를 보며 웅크리면 범위가 보입니다.
- 연료가 떨어진 발전기도 저장한 에너지를 계속 내보냅니다.

## 저장 네트워크
- 케이블이 Refined Storage처럼 얇은 모델이 되고, 클릭한 면에 붙어 놓입니다. 케이블 텍스처는 Refined Storage 2의 것을 그대로 씁니다.
- 부착물 머리에 색을 입히고, 얇은 블록에 Java Edition처럼 음영을 넣었습니다. 아이템에도 머리가 보입니다.
- 얇은 블록의 모든 면을 그려서 뒤가 비쳐 보이지 않습니다.
- 케이블 부착물의 이름과 창을 Refined Storage에 맞췄습니다.
- 임포터, 익스포터, 외부 저장소의 처리 속도를 Refined Storage 값으로 맞췄습니다. 임포터와 익스포터에 속도 업그레이드와 스택 업그레이드를 끼울 수 있습니다.
- 터미널의 레시피 책은 처음부터 모든 레시피를 보여 줍니다.
- 터미널 목록의 빈 칸은 어둡게 그리고 눌리지 않습니다.

## 화면
- 인벤토리 화면의 모양과 끌기를 바닐라와 같게 맞췄습니다. 마우스를 올린 칸은 바닐라처럼 흰 테두리가 있는 초록색 칸으로 보입니다.
- 인벤토리의 레시피 책과 칸을 바닐라 화면처럼 그립니다. 스크롤 손잡이가 레일을 벗어나지 않고, 제작 칸의 비우기 버튼은 오른쪽 위에 있습니다.
- 첫 터치에 바로 눌립니다. 서버 나가기는 클라이언트가 직접 연결을 끊습니다.
- 아이템 도관 설정 창을 카드 두 줄과 큰 색 사각형으로 배치하고 크기를 줄였습니다. 이웃 블록 이름은 보이지 않습니다.

## 접속
- 클래식 UI가 아닌 플레이어에게 접속할 때 클래식 UI를 권하는 창을 띄웁니다. 동의하면 클래식 UI로 바꾸고, 거부하면 그대로 진행합니다. 이전에는 모든 플레이어를 묻지 않고 클래식 UI로 바꿨습니다.

## 운영자
- `/sgdebug ui` 로 Ore UI 기계 화면을 미리 봅니다.

## 릴리스
- `v<버전>` 태그를 올리면 GitHub 릴리스가 만들어지고 Windows, Linux(amd64) 빌드가 올라갑니다. 변경 내역은 버전마다 `change_logs/<버전>.md` 에 적습니다.
