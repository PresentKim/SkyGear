# 단말 화면과 DDUI 인벤토리

스토리지 망 단말을 AE2 단말처럼 다시 만든다. 바탕이 되는 것은 Ore UI(DDUI) 화면 안에서 바닐라처럼 동작하는 인벤토리 부품이고, 다른 창고 화면도 나중에 이 부품으로 옮긴다.

## 목표

- 단말 화면 두 가지를 제작 토글 버튼으로 오간다.
  - 제작 단말: 위에서부터 제목과 검색칸, 망 목록(스크롤), 3×3 제작 칸과 결과 칸, 인벤토리 27칸, 핫바 9칸.
  - 일반 단말: 제작 칸이 없고 그만큼 망 목록이 길다.
- 창 왼쪽 바깥의 세로 버튼 줄: 정렬, 인벤토리 모두 넣기, 제작 토글, 빠른 이동(터치).
- 인벤토리와 제작 칸은 바닐라처럼 다룬다: 커서에 든 아이템, 왼쪽·오른쪽 클릭, 쉬프트 클릭, 끌어서 나누기, 두 번 클릭으로 모으기, 터치의 탭·길게 누르기·끌기.

## 부품 (재사용)

### 서버: `common/invclick`

Dragonfly 만 쓰는 순수 규칙. 칸 묶음(`Area`: 칸을 읽고 쓰고, 넣을 수 있는지 묻는다)과 커서 묶음으로 바닐라 클릭 결과를 낸다.

| 동작 | 결과 |
|---|---|
| 왼쪽, 커서 빔 | 칸 전체를 커서로 |
| 왼쪽, 칸 빔 | 커서 전체를 칸에(최대 묶음까지) |
| 왼쪽, 같은 아이템 | 칸에 채울 만큼 옮김, 남는 것은 커서에 |
| 왼쪽, 다른 아이템 | 맞바꿈 |
| 오른쪽, 커서 빔 | 칸의 절반(올림)을 커서로 |
| 오른쪽, 칸 빔 또는 같은 아이템 | 커서에서 한 개를 칸에 |
| 오른쪽, 다른 아이템 | 맞바꿈 |
| 두 번 왼쪽(커서에 아이템) | 영역들에서 같은 아이템을 커서 최대 묶음까지 모음 |
| 왼쪽 끌기 | 커서를 끈 칸 수로 고르게 나눠 놓고 나머지는 커서에 |
| 오른쪽 끌기 | 끈 칸마다 한 개 |
| 쉬프트 | 화면이 정한 대상 영역으로 빠른 이동 |

### 서버: `common/ui` 의 인벤토리 화면 틀

- 화면 데이터의 칸(`InvSlot`)은 id 와 영역 이름, 칸 번호를 가진다.
- 페이지가 보내는 이벤트: `kind: "slot"` (`value: {b: 0|1, shift, dbl}`)와 `kind: "drag"` (`value: {b, ids}`). 레이아웃이 칸 id 를 `SlotAct` 처리 함수로 잇는다.
- 커서 아이템은 서버가 플레이어별로 들고 화면 데이터의 `cursor` 로 보낸다. 화면이 닫히면 커서 아이템은 인벤토리로 돌아가고, 자리가 없으면 발밑에 떨어진다.
- 플레이어 인벤토리 영역(`PlayerArea`)을 기본으로 준다: 인벤토리 27칸과 핫바 9칸, 바닐라 순서.

### 페이지: `web/oreui/src/inventory/`

- `InvSlotView`: 칸 하나. 마우스 왼쪽·오른쪽·쉬프트, 두 번 클릭, 끌기를 받는다.
- `useCursor`: 커서 아이템을 마우스(터치는 마지막으로 닿은 곳) 옆에 그린다.
- `InvGrid`: 칸 줄 배치. `PlayerInventory` 는 27+9칸 배치.
- 터치: 탭은 왼쪽 클릭, 400ms 길게 누르기는 오른쪽 클릭, 누른 채 다른 칸으로 끌면 끌어 나누기(누른 시간이 400ms 를 넘으면 한 개씩). 빠른 이동 토글이 켜져 있으면 탭이 쉬프트 클릭이다. 인벤토리 칸은 툴팁 때문에 탭을 두 번 받지 않고, 마지막으로 닿은 칸의 이름을 창 위쪽 정보 줄에 쓴다.

## 단말 규칙 (`content/skygear/netstore`)

- 망 목록 칸: 커서가 비면 왼쪽은 한 묶음, 오른쪽은 반 묶음을 커서로, 쉬프트는 한 묶음을 인벤토리로. 커서에 아이템이 있으면 왼쪽은 전부, 오른쪽은 한 개를 망에 넣는다. 끌기는 망 목록에서 받지 않는다.
- 인벤토리 칸 쉬프트: 묶음을 망에 넣는다.
- 제작 칸은 단말 블록이 들고 세이브에 남는다. 제작 칸 쉬프트는 인벤토리로.
- 결과 칸: 왼쪽·오른쪽은 한 번 만들어 커서로(같은 아이템이면 쌓을 수 있을 때만), 쉬프트는 인벤토리가 받는 만큼 여러 번. 만든 뒤 빈 재료 칸은 망에서 같은 아이템으로 다시 채운다. 양동이 같은 남는 아이템은 인벤토리로 간다.
- 제작 칸 비우기(✕): 제작 칸 아이템을 망에 넣고, 못 넣은 것은 인벤토리로.
- 망이 꺼져 있으면 목록 자리에 꺼짐 문구를 쓰고 인벤토리와 제작 칸만 다룬다.
- 화면은 동작마다 서버가 다시 보낸다.

## 창 크기

단말 창은 폭 9칸 기준이고, 높이는 화면에 맞춰 망 목록 줄 수가 바뀐다(목록이 남는 높이를 채운다). 창 크기가 다른 화면에서 바뀌므로 단말은 열 때 새 창으로 연다.

## 작업 순서

1. `common/invclick` 규칙과 단위 테스트.
2. `common/ui` 인벤토리 화면 틀: 칸 이벤트, 커서, 닫힘 처리, 테스트.
3. 페이지 부품 `src/inventory/` 와 단말 화면 `src/screens/terminal.tsx`, vitest.
4. 단말 규칙과 제작 칸(조합법 판정은 Dragonfly 패치의 `shapedArrangementOK` 와 같은 규칙), Go 테스트.
5. 문서(`docs/tech/oreui.md`, `storagenet.md`, 설계 18), 번들 빌드.
