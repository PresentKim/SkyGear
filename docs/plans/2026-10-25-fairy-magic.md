# 요정 마법: 날씨와 태양 (설계·계획)

요정을 매일 밤 찾아오는 손님으로 바꾸고, 요정이 남기는 **요정의 날개가루**로 섬의 환경(날씨, 해의 움직임)을 다루는 **요정의 마법판**을 만든다.
사용자 확인을 마친 결정은 끝의 "결정 사항"에 모았다.

## 1. 용어

| 이름 | 종류 | 설명 |
|---|---|---|
| 요정의 날개가루 (`dragonfactory:fairy_dust`) | 재료 아이템 | 요정이 떨구는 가루. 섬의 환경을 다루는 데 쓴다 |
| 요정의 에메랄드 (`dragonfactory:fairy_emerald`) | 재료 아이템 | 마법 한 번에 하나씩 쓰는 연료 |
| 요정의 마법판 (`dragonfactory:fairy_board`) | 사용 아이템 | 손에 들고 쓰면 마법 창이 열린다. 설치하지 않는다 |

- "요정의 가루"와 "요정의 날개가루"는 같은 아이템이고 이름은 **요정의 날개가루** 하나로 쓴다.
- 텍스처·이름은 리소스팩(`assets/resourcepack/dragonfactory/`)에 둔다. 텍스처 PNG 는 임시 그림으로 넣고 나중에 바꾼다.

## 2. 요정 방문 (선물 요정 변경)

| 항목 | 지금 | 바뀐 뒤 |
|---|---|---|
| 방문 주기 | 인스턴스 2~4일마다 | **인스턴스 하루에 한 번, 반드시** |
| 방문 시각 | 정해진 날의 아무 때 | **하루의 끝 무렵 밤**: 하루의 75~85% 사이 무작위 시각(20분 하루 기준 15~17분째, 바닐라 시계로 자정 무렵) |
| 기다리는 시간 | 2분 | **1분** |
| 잡았을 때 | 선물을 발밑에 던져 주고 떠난다 | 같음. 선물에 **요정의 날개가루 2~3개가 더해진다** |
| 1분 안에 못 잡았을 때 | 그냥 떠난다 | **선물을 플레이어 주변에 흩뿌리고 떠난다**(`session.dropAt` 무작위 모션, 기획 02 §18.1). 흩뿌리는 선물도 날개가루 2~3개를 포함한다 |
| 대상 | 세이브의 무작위 플레이어 | 같음 |

- 방문 시각은 **인스턴스 시계**(`instance.Clock` 의 하루)를 따른다. 해를 낮으로 고정해도(§5) 요정은 그날의 끝에 온다.
- 섬은 세이브에 누군가 들어와 있을 때만 활성화되므로 방문 시각에는 늘 플레이어가 있다.
- 선물은 하루 평균 받는 양이 예전(평균 3일에 한 번)과 같도록 1/3로 줄인다: 연구 보상 5% → 2%, 연구 비용 절반 25% → 8%, 기본 선물은 참나무 원목 6개, 참나무 묘목 1개, 돌 돌멩이 6개 중 하나. 여기에 날개가루 2~3개를 늘 더한다.
- 날개가루는 연구와 상관없이 처음부터 떨군다(첫 날부터 요정 갈래를 따라갈 수 있게).
- `fairy_gift` 업적 카운터는 잡았을 때만 센다(지금과 같음).
- 세이브 상태 `NextFairy` 는 "다음 방문 시각"으로 그대로 쓰고, 계산만 "그날(지났으면 다음 날)의 75~85% 시각"으로 바꾼다. 이미 저장된 먼 시각은 첫 계산 때 가까운 밤으로 당긴다.

## 3. 조합법

조합대 3칸 가로 한 줄(shaped). 2×2 인벤토리 칸에서는 만들 수 없다.

| 결과 | 배치 | 수량 |
|---|---|---|
| 요정의 에메랄드 | `[날개가루][에메랄드][날개가루]` | 1 |
| 요정의 마법판 | `[날개가루][연구대][날개가루]` | 1 |

- 둘 다 §6 의 연구가 연다. 레시피 결과이므로 `creative.go` 에도 등록한다.
- 에메랄드는 철 메쉬 이상으로 자갈을 걸러 얻는다(`sievetable.go`). 그래서 마법판은 일찍 받아도 실제 마법은 중반부터 쓸 수 있다. 이 흐름을 연구 설명과 도움말에 적는다.

## 4. 요정의 마법판 (마법 창)

마법판을 손에 들고 사용(우클릭)하면 **폼**이 열린다(아이템이 오가지 않는 메뉴이므로 `common/ui` 폼, 모양은 `dfui` 테마). 설치되지 않는다.

```
요정의 마법판                      요정의 에메랄드 3
─ 날씨 ─  지금: 비 (남은 시간 2일 4시간)
  [화창]  [비]  [눈]
─ 해 ─    지금: 흐름
  [낮 고정] [저녁 고정] [밤 고정] [흐름]
```

- 버튼을 누르면 인벤토리의 요정의 에메랄드 하나를 쓰고 바로 적용한다. 에메랄드가 없으면 그 버튼들은 잠긴 모양으로 보이고 누를 수 없다.
- 지금 상태와 같은 버튼(해 모드의 현재 모드)은 눌러도 아무 일이 없고 에메랄드를 쓰지 않는다.
- 결과는 섬 모두에게 보이므로(비가 내림, 해가 멈춤) 따로 채팅 알림을 하지 않는다. 날씨의 남은 시간은 **마법판 창에만** 보인다.
- 마법판 자체는 쓰여 없어지지 않는다.

## 5. 환경 마법

### 5.1 날씨

- 세이브 월드의 **날씨는 저절로 바뀌지 않는다**(Dragonfly `WeatherCycle` 끔). 기본은 화창.

| 날씨 | 효과 | 유지 |
|---|---|---|
| 화창 | 기본, 효과 없음 | 계속 |
| 비 | **농작물 성장 50% 빠름** | 인스턴스 3일(20분 하루 기준 1시간) |
| 눈 | **기계 속도 50% 빠름** | 인스턴스 3일 |

- 비·눈은 시간이 다하면 화창으로 돌아간다. 유지 시간은 **인스턴스 시간**이라 인스턴스가 꺼져 있는 동안은 줄지 않는다.
- 같은 날씨를 다시 쓰면 남은 시간에 **3일을 더한다**. 다른 날씨(비 ↔ 눈, 화창으로 일찍 되돌리기)로 바꾸면 남은 시간은 버리고 새 날씨가 3일(화창은 계속) 간다. 어느 쪽이든 에메랄드 하나를 쓴다.
- **비의 "농작물"**: 시간으로 자라는 것 전부. 작물(밀·당근·감자·비트), 수박·호박 줄기의 성장과 열매 맺기, 마법 식물.
  - 구현: 작물 시각을 인스턴스 시각 대신 **성장 시계**(`State.GrowClock`)로 잰다. 성장 시계는 인스턴스 시간이 흐른 만큼 흐르고 비가 오면 1.5배로 흐른다. 처음 불러올 때 인스턴스 시각으로 맞추므로 기존 기록은 그대로 이어진다. WAILA 의 남은 시간은 지금 날씨의 배율로 나눠 보인다.
- **눈의 "기계"**: 에너지(RE)로 도는 작업 기계(분쇄기, 자동 체, 자동 채굴기, 전기 화로, 합금로, 자동 제작기 등)의 **작업 속도 ×1.5**. 틱당 에너지 사용량은 그대로라 같은 일에 드는 에너지가 줄어든다(과열이 내려가 효율이 오르는 느낌). 발전기의 발전량·연료 소모, 호퍼·도관의 이동 속도는 바꾸지 않는다.
  - 구현: 에너지를 쓰는 기계의 틱마다 작업 반복 수의 절반(홀수면 두 틱에 한 번)을 더 돌리고, 더 돈 반복은 에너지를 쓰지 않는다(`Machine.Tick`).
- **보이는 것**:
  - 비: 플레이어 주위의 빗줄기 파티클로 그린다. 월드는 날씨 순환을 끄고(`World.StopWeatherCycle`) 바닐라 비를 내리지 않는다.
  - 눈: 리소스팩의 하얀 옅은 안개(`PlayerFog`)와 플레이어 주위의 눈송이 파티클로 그린다. 접속 중인 클라이언트는 다시 보낸 청크의 바이옴을 반영하지 않아 바이옴 변경은 쓰지 않는다. 눈은 쌓이지 않는다.
  - 천둥·번개는 쓰지 않는다.

### 5.2 해 (시간 고정)

- 네 모드: **낮 고정, 저녁 고정, 밤 고정, 흐름**. 기본은 흐름.
- 바꾸면 다시 바꿀 때까지 계속 유지되고, **바꿀 때만** 요정의 에메랄드 하나를 쓴다(유지 비용 없음).
- 고정 시각(바닐라 시계): 낮 6000(정오), 저녁 12000(해 질 녘), 밤 18000(자정).
- 해는 보이는 것만 다룬다. **인스턴스 시계(날짜, 작물·배럴·요정 일정)는 계속 흐른다.**
- 흐름(기본) 모드에서 월드의 해는 **인스턴스 시계를 따른다**(인스턴스 하루의 시작 = 바닐라 시각 0, 해 뜰 녘). 그래서 "요정은 밤에 온다"가 화면과 맞는다.
- 구현: 흐름 모드는 `World.StartTime` 으로 해를 돌리고 1초마다 월드 시각과 `dayTime/dayLength×24000` 의 차이가 1초(20틱) 넘게 벌어지면 `SetTime` 으로 맞춘다. 고정 모드는 `StopTime` + `SetTime`. 세이브를 열 때 저장된 모드를 다시 적용한다.

### 5.3 저장

세이브 상태(`State`)에 더한다(게임 상태 JSON 이라 DB 스키마는 바뀌지 않는다).

```go
Weather      string        `json:"weather,omitempty"`       // "", "rain", "snow"
WeatherUntil time.Duration `json:"weather_until,omitempty"` // 인스턴스 시각
Sun          string        `json:"sun,omitempty"`           // ""(흐름), "day", "dusk", "night"
GrowClock    time.Duration `json:"grow_clock,omitempty"`    // 성장 시계(§5.1)
```

## 6. 연구 "요정 마법"

| 항목 | 값 |
|---|---|
| ID | `fairy_magic` |
| 선행 | 없음 (연구대만 있으면 된다) |
| 비용 | 요정의 날개가루 2, 연구대 1. 연구 정수 비용은 붙이지 않는다(`withEssenceCosts` 에서 뺀다) |
| 여는 조합법 | 요정의 에메랄드, 요정의 마법판 |
| 보상 | 요정의 마법판 1개 즉시 지급(`researchRewards`) |

- 연구 설명(`research.fairy_magic.*`)에 기능 전체를 자세히 쓴다: 요정이 언제 오는지, 날개가루 얻는 법, 에메랄드는 철 메쉬로 자갈을 걸러 얻는다는 것, 마법판 사용법, 날씨 세 가지의 효과와 유지 시간, 해 고정 네 모드와 비용 규칙.
- 연구 단순화: 이 연구 하나로 두 조합법과 마법판을 모두 준다.

## 7. 발전과제 "요정" 갈래

발전과제 트리는 '발전과제 화면과 트리 구현' 작업이 여러 선행·챕터 모델로 바꾸는 중이다. 요정 갈래는 그 새 모델의 **챕터 하나**로 넣는다(그 작업이 먼저 들어간 뒤 구현한다).

| 순서 | ID | 조건 | 선행 | 이름(초안) | 힌트(초안) |
|---|---|---|---|---|---|
| 1 | `fairy_dust` | 날개가루를 인벤토리에 가짐 | 없음(챕터 입구) | 반짝이는 손님 | 밤이 깊으면 요정이 찾아온다. 1분 안에 요정을 눌러 날개가루를 받자 |
| 2 | `fairy_emerald` | 요정의 에메랄드를 가짐 | 1 | 요정의 보석 | "요정 마법" 연구 뒤, 조합대에 가루·에메랄드·가루를 가로로. 에메랄드는 철 메쉬로 자갈에서 |
| 3 | `fairy_board` | 요정의 마법판을 가짐 | 1 | 마법판 손에 쥐고 | "요정 마법" 연구(날개가루 2, 연구대 1)를 마치면 바로 받는다 |

- 가루(1) 뒤에 에메랄드(2)와 마법판(3)이 두 갈래로 나란히 선다. 마법판은 요정이 남긴 선물처럼 연구로 먼저 받는 목표다.
- 1 의 아이콘은 날개가루, 2·3 은 각 아이템. 안내 연구(`Guide`)는 2·3 모두 `fairy_magic`.
- 이름·힌트는 `internal/locales/ko.json` 에 넣는다.

## 8. 도움말(가이드)

메뉴 → 도움말에 **"요정과 마법"** 주제를 더한다(아이콘: 요정의 마법판). 내용: 요정 방문(밤, 1분, 못 잡으면 흩뿌림), 날개가루의 쓰임, 두 조합법, 마법판 사용법, 날씨·해 마법의 효과·유지·비용. 서버 가이드(도움말 구조 정리 작업)가 바뀌면 그 구조에 맞춘다.

- `docs/design/02-dragonfactory.md` §2 선물 요정 문단을 새 방문 규칙으로 고쳐 쓰고, 새 절 "요정 마법"(날씨·해)을 더한다. §10 갈래 목록에 요정을 더한다.
- `docs/design/open-questions.md` 밸런싱 표: 요정 방문 행을 고치고 날개가루 2~3, 날씨 유지 3일·배율 1.5, 마법 비용 에메랄드 1 행을 더한다.
- `docs/tech/admin.md`: `/dfdebug fairy` 설명 유지, 날씨·해를 바로 바꾸는 디버그 명령 `/dfdebug weather <clear|rain|snow>`, `/dfdebug sun <day|dusk|night|cycle>` 을 더한다.

## 10. 구현 순서 (커밋 단위)

1. 아이템 3종 + 리소스팩(이름·임시 텍스처) + 조합법 + `creative.go`
2. 요정 방문 변경(밤마다, 1분, 흩뿌리기, 날개가루)
3. 연구 `fairy_magic` + 보상 + 연구 설명
4. 날씨 상태·마법판 폼 + 비(작물 가속) + 눈(기계 가속) + 날씨 표시(빗줄기·안개·눈송이)
5. 해 모드 + 월드 시각을 인스턴스 시계에 맞추기
6. 발전과제 요정 챕터(트리 개편 이후)
7. 도움말 주제 + 기획·밸런싱·관리 문서
8. 시나리오 `spike/scenarios`: 요정 부르기 → 날개가루 → 연구 → 마법판으로 비 → 작물 가속 확인

각 단계는 `go vet`, `go test`, `gofmt` 와 해당 테스트(아이템·팩 키, 조합법, 성장 배율, 기계 배율, 상태 저장·불러오기)를 함께 넣는다.

## 11. 결정 사항 (2026-10-25 사용자 확인)

1. 요정의 가루 = 요정의 날개가루, 한 아이템.
2. 요정은 하루의 75~85%(자정 무렵)에 온다.
3. 못 잡아서 흩뿌리는 선물에도 날개가루 2~3개가 들어간다.
4. 섬은 플레이어가 있을 때만 활성화되므로 빈 섬은 고려하지 않는다.
5. 선물 비율은 예전 등장 간격(평균 3일)과 비교해 하루 기대량이 같도록 줄인다.
6. 같은 날씨를 다시 쓰면 3일을 더한다. 날씨 상태는 마법판 창에만 보인다.
