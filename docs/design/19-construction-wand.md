# 19. 건축 지팡이

> 수치는 모두 초안이다. [ConstructionWand](https://github.com/Theta-Dev/ConstructionWand)(ThetaDev, MIT) 모드의 지팡이 로직과 그림을 옮겼다. 라이선스 전문은 `third_party/licenses/ConstructionWand-MIT.txt`.

섬이 커지면 벽과 바닥을 한 칸씩 쌓는 일이 길어진다. **건축 지팡이**는 블록의 한 면을 누르면 그 면에 이어진 같은 블록들 앞에 블록을 한꺼번에 놓는다.

## 1. 쓰는 법

지팡이를 손에 든다.

- **블록의 면을 우클릭 = 넓히기**: 누른 블록 앞 칸에서 시작해, 그 면과 같은 평면에서 이웃한 칸으로 번진다. 칸 뒤(누른 면 쪽의 반대)에 누른 블록과 맞는 블록이 있고, 칸이 비어 있으면 블록을 놓는다. 지팡이 한계만큼 놓으면 멈춘다.
- **웅크리고 허공을 우클릭 = 원형 메뉴**: 방향 제한, 블록 일치, 덮어 놓기, 무작위를 고르고, 마지막 작업을 되돌린다(§4).
- **미리보기**: 지팡이를 들고 블록을 보면 놓일 블록이 그 자리에 초록 유리를 겹쳐 보인다(최대 256칸, 보는 사람에게만). 세상은 그대로 두고 보는 사람에게만 블록 갱신 패킷을 보낸다. 레이어 0에는 **미리보기 유리**(`skygear:preview_glass`)를, 레이어 1(액체 층)에는 놓일 블록(반 블록이면 반 블록)을 보낸다. 조준이 바뀌거나 지팡이를 내려놓으면 두 레이어 모두 실제 블록으로 되돌린다.
- 미리보기 유리는 바닐라 초록 색유리 그림(`textures/blocks/glass_green`)을 쓰는 커스텀 블록이다. 충돌 상자와 선택 상자가 없어서 크로스헤어와 클릭이 그 칸을 지나 뒤의 블록에 닿고, 몸도 걸리지 않는다. 월드에 놓이지 않고 아이템도 없다(`/sgadmin give`·도감·연구에 나오지 않는다). 다리 놓기·철 망치 미리보기와 함께 `content/skygear/preview` 에 있고, 세 미리보기가 같은 칸을 덮으면 하나를 지울 때 남은 미리보기가 다시 보인다.

지팡이를 들고 누르면 블록의 창은 열리지 않는다.

## 2. 지팡이

| 지팡이 | 한 번에 놓는 블록 | 내구도 | 조합법(오른쪽 위 머리, 대각선 막대기 둘) | 연구 |
|---|---|---|---|---|
| 돌 건축 지팡이 | 9 | 131 | 조약돌 | "건축 지팡이"(선행: 돌 도구. 비용: 조약돌 32, 막대기 8) |
| 철 건축 지팡이 | 27 | 250 | 철 주괴 | "철 건축 지팡이"(선행: 건축 지팡이, 철 도구. 비용: 철 주괴 16) |
| 다이아몬드 건축 지팡이 | 128 | 1561 | 다이아몬드 | "다이아몬드 건축 지팡이"(선행: 철 건축 지팡이, 다이아몬드 도구. 비용: 다이아몬드 8) |
| 무한 건축 지팡이 | 1024 | 닳지 않음 | 네더라이트 주괴 | "무한 건축 지팡이"(선행: 다이아몬드 건축 지팡이, 네더라이트 메쉬. 비용: 네더라이트 주괴 2, 다이아몬드 16) |

- 놓은 블록마다 내구도가 1 줄고, 남은 내구도보다 많이 놓지 않는다. 크리에이티브에서는 닳지 않고 블록도 가져가지 않는다.
- 모드의 무한 지팡이는 네더의 별로 만들지만, 섬에서 얻기 어려워 네더라이트 주괴로 바꿨다.

## 3. 놓는 블록

- 블록은 인벤토리에서 가져간다. 모드처럼 메인 인벤토리에서 먼저, 단축바에서 마지막에 꺼내서 단축바의 블록이 오래 남는다.
- 지팡이가 부서지면 오토필(§9)이 같은 지팡이를 인벤토리에서 손으로 가져온다.
- 놓는 블록이 뒤의 블록과 같으면 그 상태를 그대로 따른다(계단·반 블록·통나무의 방향). 겹 반 블록 앞에는 반 블록 하나를 놓는다.
- 놓지 않는 블록: 충돌 상자가 없는 블록(횃불·꽃·작물), 블록 엔티티가 있는 블록(상자·화로 등), 문·침대·두 칸짜리 꽃, 퇴비통, 기계·도관·서랍처럼 상태가 있는 스카이기어 블록. 스카이기어 블록 중 부서진 블록과 광석 블록은 놓는다.
- 섬 밖(소유하지 않은 청크)이나 생물이 서 있는 칸에는 놓지 않는다.

## 4. 설정

설정은 지팡이 아이템에 담긴다(아이템 값 `sg_wand`). 이름 아래 설명에 한계와 지금 설정이 나온다.

| 설정 | 선택지 | 기본 |
|---|---|---|
| 방향 제한 | 제한 없음 · 좌우 · 위아래(옆면) · 남북 · 동서(윗면·아랫면) | 제한 없음 |
| 블록 일치 | 같은 블록 · 비슷한 블록(흙·잔디·회백토·균사체·경작지·흙길·뿌리 흙을 하나로) · 모든 블록 | 비슷한 블록 |
| 덮어 놓기 | 켜짐(풀·물·눈처럼 덮이는 블록 자리에도 놓음) · 꺼짐 | 켜짐 |
| 무작위 | 켜짐(단축바의 블록을 섞어 놓음) · 꺼짐 | 꺼짐 |

### 원형 메뉴

설정은 화면 가운데 뜨는 원형 메뉴에서 고른다. 인벤토리 틀 없이 게임 화면 위에 뜨고, ore-ui-react 의 `RadialMenu` 를 1.3배로 키워서 쓴다(화면을 너무 가리지 않는 크기).

- 칸은 방향 제한·블록 일치·덮어 놓기·무작위·되돌리기 다섯이다. 원판을 다섯 부채꼴(링 섹터)로 나누고 경계에 바큇살을 긋는다. 칸마다 아이콘, 이름, 지금 값(되돌리기는 남은 횟수)이 있고, 원 위에 지팡이 이름과 한도·내구도가 나온다.
- 칸을 누르면 바로 바뀐다. 방향 제한은 제한 없음 → 좌우 → 위아래 → 남북 → 동서 → 제한 없음, 블록 일치는 같은 블록 → 비슷한 블록 → 모든 블록 → 같은 블록 차례로 넘어가고, 덮어 놓기·무작위는 켜짐과 꺼짐이 바뀐다. 메뉴는 닫히지 않고 바뀐 값으로 다시 그려진다.
- 고른 칸(마우스가 가리키거나 키로 고른 칸)은 부채꼴 전체가 밝아진다. 켜져 있는 덮어 놓기·무작위는 바깥 가장자리에 초록 띠가 생긴다.
- 되돌릴 작업이 없으면 되돌리기 칸이 흐리게 보이고 눌리지 않는다.
- 가운데 단추는 닫기다.
- 페이지에는 캔버스가 없고 SVG 가 그려지는지는 확인되지 않았다. 그래서 부채꼴은 원 가운데를 축으로 돌린 얇은 상자들(3도 간격)로 채운다(`radial.tsx` 의 `fanBars`).

조작은 이렇다.

| 입력 | 동작 |
|---|---|
| 마우스 | 가리킨 칸이 밝아지고 그 설명이 원 아래에 나온다. 누르면 바뀐다 |
| 터치 | 칸을 누르면 바로 바뀐다 |
| 방향키·WASD | 위에서부터 시계 방향으로 고를 칸을 옮긴다(→·↓·D·S 다음 칸, ←·↑·A·W 이전 칸) |
| 숫자 1~9 | 그 칸을 고른다. 같은 숫자를 한 번 더 누르면 실행한다 |
| Enter·Space | 고른 칸을 실행한다 |
| Esc | 닫는다 |

방향 제한이 옆면용(좌우·위아래)일 때 윗면·아랫면을 누르면, 또는 윗면용(남북·동서)일 때 옆면을 누르면 아무것도 놓지 않는다(모드와 같다).

## 5. 되돌리기

원형 메뉴의 "되돌리기"는 마지막 클릭이 놓은 블록 중 아직 그대로인 것을 거두고 아이템을 돌려준다(인벤토리가 차면 발밑에 떨어뜨린다). 플레이어마다 마지막 세 번을 기억하고, 세이브를 나가면 잊는다. 되돌려도 지팡이 내구도는 돌아오지 않는다.

## 6. 모드에서 옮기지 않은 것

- 천사 코어(허공·뒤쪽에 놓기)와 파괴 코어(면 지우기), 코어를 끼우는 조합.
- 방향 설정의 "플레이어" 쪽(놓는 사람을 보게 놓기). 블록은 늘 뒤의 블록 방향을 따른다.
- 왼손 블록 우선(이 서버는 왼손에 블록을 들 수 없다), 셜커 상자·꾸러미 속 블록 쓰기, Ctrl 키 되돌리기(원형 메뉴 칸으로 바꿨다).

## 8. 되돌리기와 크리에이티브

되돌리기는 놓을 때 블록을 가져갔는지(크리에이티브가 아니었는지)를 기억해, 가져간 블록만 돌려준다. 크리에이티브에서 놓고 서바이벌에서 되돌려도 블록이 생기지 않는다.

## 9. 오토필

설정 "다 쓴 손의 아이템 자동으로 채우기"(기본 켜짐, `autofill`)를 켜면, 손에 든 묶음을 다 쓴 순간 같은 아이템이 인벤토리에서 손으로 온다([Mouse Wheelie](https://github.com/xanderseven/MouseWheelie)의 다시 채우기). 메인 인벤토리를 먼저 보고 단축바는 마지막에 본다(단축바 배치를 지키려고).

| 다 쓰는 때 | 채우는 것 |
|---|---|
| 마지막 블록을 놓음 | 같은 블록 |
| 마지막 음식을 먹음, 마지막 눈덩이·달걀·엔더 진주를 던짐 | 같은 아이템 |
| 손의 도구가 부서짐(지팡이 포함) | 같은 종류의 도구(닳은 정도는 따지지 않음) |
| 체에 마지막 블록을 넣음 | 같은 블록 |

공용 함수는 `content/skygear/core/refill.go`(`RefillHand`, 게임이 묶음을 줄인 뒤에 채우는 `RefillHandLater`)이고, 핸들러(놓기·먹기·쓰기·도구 닳기), 체(`machine/sieve.go`), 지팡이가 부른다.

## 10. 구현 위치

`content/skygear/wand`: 설정(`wand.go`), 놓을 자리 찾기와 블록 공급(`build.go`의 `Plan`), 클릭·되돌리기·미리보기(`use.go`), 원형 메뉴(`screen.go`, 화면은 `common/ui/radial.go` 의 `ShowRadial` 과 `web/oreui/src/screens/radial.tsx`). 아이템은 `sgitem/wand.go`(`Wand`, `InfinityWand`). 클릭은 `handler.go`의 `HandleItemUseOnBlock`(넓히기)과 `HandleItemUse`(웅크리고 허공: 원형 메뉴)가 가로채고, 미리보기는 `look` 의 바라보기 갱신이 부른다. 블록마다 핸들러의 `HandleBlockPlace` 를 거쳐 섬 영역 검사와 놓기 집계가 다른 블록과 같다.
