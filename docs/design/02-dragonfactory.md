# 02. 드래곤팩토리

> 이름의 유래: **Dragonfly** 구동기로 돌아가는 **공장** 서버.

스카이팩토리 / 알케미 팩토리 스타일의 공장 만들기 게임.
작은 섬에서 **차원의 코어**가 만들어 내는 블록을 가공·자동화하고,
**메인 미션**을 납품해 레벨을 올리면서 새로운 상품과 코어(=시대)를 개방한다.

## 1. 코어 루프

```
코어가 블록 생성 → 채굴 → 가공(기계) → 상점 판매 / 미션 납품
        ↑                                      ↓
  코어 강화·새 코어 ← 상점 구매 ← 돈·레벨 업 ←──┘
```

## 2. 시작 상태

- 새 세이브는 작은 섬(시작 청크 안의 작은 플랫폼)과 그 위의 **1티어 코어** 1개로 시작한다. 코어 아래에는 참나무 원목 코어 기반이 깔려 있어 원목을 만든다.
- 시작 지급품은 최소한(기본 도구 정도). 진행 대부분은 상점 구매로 이뤄진다.

## 3. 차원의 코어

> 13차 뒤: 코어 하나만 남기고 기본 자원 생산에만 쓰며 레시피를 연구로 여는 **개편을 검토 중**([결정 필요](open-questions.md)). 아래는 지금 구현.

### 3.1 동작
- 코어는 **티어(1~4)만 가진 엔진**이다. 무엇을 만들지는 **코어 바로 아래 블록(코어 기반)** 과 **코어 기반 둘레(같은 높이 네 방향)** 의 조합이 정한다(코어 레시피).
- 코어 바로 **위 칸**이 비어 있으면 생성 주기마다 레시피의 블록 하나를 만든다. 위 칸이 비워진 뒤 한 주기를 다 기다린다. 코어 기반이나 둘레가 바뀌어 레시피가 달라지면 진행도는 처음부터.
- 코어 기반과 둘레 블록은 **닳지 않는다**(촉매). 코어 기반을 바꾸면 같은 코어가 다른 것을 만든다.
- 맞는 레시피가 없으면 코어는 쉰다. 우클릭 안내에 "반응 없음" 또는 "n티어 이상 코어가 필요한 코어 기반"이 나온다.
- 기본은 **손으로 채굴**한다. 자동 자원 채굴기는 존재하지만 **매우 적은 수만** 얻을 수 있다(레벨 보상 등). 자동화의 중심은 채굴 이후의 가공·운반 라인이다.
- **같은 티어 코어를 여러 개** 둘 수 있다. 캐면 코어 아이템으로 돌아온다. 재발급은 없고 상점에서 다시 산다.
- 생성 주기 = `티어 기본 주기 × (1 - 0.12 × 그 티어의 속도 강화 Lv)`. 티어 기본 주기 1~4티어 3·5·8·12초(초안).
- 코어 아래를 코어 기반이 차지하므로 코어와의 자동화 연결은 위·옆으로 한다.

### 3.2 코어 레시피
- 코어 기반과 둘레 조건을 만족하는 레시피 중 **코어 티어가 허용하는 것**에서 **둘레 조건이 가장 많은(구체적인) 것**이 고른다. 예: 1티어 코어 + 모래 코어 기반 + 사방 물 → 2티어 레시피(점토)는 못 쓰므로 모래.
- 잔디 블록은 흙으로 본다(코어 기반·둘레 모두). 흙 기반은 코어에 덮여 있어 잔디가 되지 않지만, 둘레 흙은 잔디가 될 수 있다.
- 숨은 레시피는 도감에 단서만 보이다가, 세이브의 코어가 처음 만들면 **발견**으로 기록되고(참여자 공유) 모두에게 알린다.
- 초안(`corerecipe.go` `coreRecipes`, [확인 필요](open-questions.md)):

| 티어 | 코어 기반 | 둘레 | 결과 | 공개 |
|---|---|---|---|---|
| 1 | 참나무 원목 | | 참나무 원목 | 공개(시작 코어 기반) |
| 1 | 조약돌 / 흙 / 모래 / 자갈 | | 같은 블록 | 공개 |
| 1 | 조약돌 | 물 1개 이상 | 돌 | 숨김 — "물에 닿은 조약돌은 매끄러워진다" |
| 2 | 흙 | 물 1개 이상 | 진흙 | 공개 |
| 2 | 석탄 블록 | | 석탄 광석 | 공개 |
| 2 | 점토 블록 / 호박 / 수박 / 건초 더미 | | 같은 블록 | 공개 |
| 2 | 모래 | 사방 물 | 점토 블록 | 숨김 — "사방이 물에 잠긴 모래는 끈적해진다" |
| 3 | 철 블록 / 구리 블록 | | 철 광석 / 구리 광석 | 공개 |
| 3 | 말린 켈프 블록 | | 말린 켈프 블록 | 공개 |
| 3 | 돌 | 철 블록 1개 이상 | 철 광석 | 숨김 — "철과 맞닿은 돌에 광맥이 스민다" |
| 4 | 금 블록 | | 금 광석 | 공개 |

### 3.3 레시피 공개 (도감 + 발견 + 단서)
- **코어 도감**(메뉴 → 코어 관리 → 코어 도감, 코어 우클릭 안내에서도): 티어별로 레시피를 보여 준다.
  - 공개 레시피와 발견한 숨은 레시피(★)는 `코어 기반 + 둘레 → 결과` 로 전부 보인다.
  - 발견하지 못한 숨은 레시피는 `???`. 연구 노트로 단서를 얻으면 `??? 단서: …`, 아직 열리지 않은 티어는 `(Lv.n에 n티어 개방)`.
  - 위에 "숨은 레시피 발견 n/m".
- **현장 안내**: 코어 우클릭 → 코어 기반, 지금 만드는 것과 주기, 또는 반응 없음·티어 부족. 숨은 레시피를 발견 전에 만들고 있으면 "무언가에 반응하고 있습니다"만 나온다.
- **단서는 연구 노트로 얻는다.** 발견하지 못한 숨은 레시피는 처음에 `???` 만 보이고, 연구 노트를 사용하면(우클릭) 열린 티어의 숨은 레시피 하나를 골라 단서를 공개한다(세이브 공유). 더 알아낼 단서가 없으면 노트는 닳지 않는다.
- 연구 노트는 **선물 요정**이 준다(§3.5).

### 3.4 상점과 강화
- 코어(상점 → 코어 분류): 1티어 하루 1개 무료(시작 코어를 잃어도 막히지 않게) + Lv.2부터 300G 하루 2개, 2티어 Lv.4 1,500G, 3티어 Lv.7 4,000G, 4티어 Lv.10 8,000G(하루 1개).
- 코어 기반으로 쓸 블록은 상점 재료 탭에서 판다(§5.1). 석탄·철·금·점토 블록은 체 부산물로, 건초 더미는 밀(흙을 걸러 나온 씨앗)로 만든다.
- **코어 강화 포인트**: 레벨이 오를 때 받는다. 메뉴 → 코어 관리에서 **티어별 속도**를 올린다(단계마다 주기 -12%, 최대 Lv.3, 1·2·3포인트). 같은 화면에서 작물 성장 강화(§9)도 산다.
- 옛 세이브: 자원별 코어(나무·돌·…·금, 그 전의 대지·생명)는 같은 티어 코어로 바뀐다(설치된 블록은 틱할 때, 인벤토리는 입장할 때, 분실물은 꺼낼 때). 섬 가운데 옛 나무·대지 코어는 코어 기반이 없으면 참나무 원목 코어 기반을 받는다. 다른 위치의 옛 코어는 코어 기반을 놓아야 다시 만든다.

### 3.5 선물 요정
- 인스턴스 시간으로 **2~4일(평균 3일)마다** 한 번, 세이브 안의 무작위 플레이어에게 요정(클라이언트에는 알레이)이 찾아와 그 주위를 새처럼 날아다닌다(주위의 무작위 지점으로 부드럽게 날아갔다 잠깐 머물기를 반복). 현재 하루 20분 설정에서 약 1시간에 한 번. 세이브에 아무도 없으면 기다렸다가 누군가 있을 때 온다.
- 요정은 이름표 없이 보인다. **우클릭·좌클릭 모두 같은 상호작용**으로, 선물을 플레이어 발밑으로 던져 주고 날아간다(좌클릭해도 맞지 않는다: 피해·밀려남 없음). 2분 안에 받지 않으면 그냥 날아간다. 한 번에 한 마리.
- 선물: **10%** 확률로 연구 노트, 아니면 지금 아는 레시피(공개 + 발견) 중 **열린 티어**의 결과 블록 하나를 골라 1티어 32·2티어 16·3티어 8·4티어 4개.
- 수치는 초안([밸런싱 표](open-questions.md)).

### 3.6 시대(Era)
- 새 티어 코어와 그 티어의 레시피가 열리는 것이 새 시대의 시작이다.

| 시대(예시) | 레벨 | 주요 코어 | 대표 기계 |
|---|---|---|---|
| 1. 개척 | 1~7 | 원목·조약돌·흙·모래·자갈(1티어), 석탄·점토·진흙(2티어), 철(3티어) | 분쇄기(돌→조약돌→자갈→모래), 체, 자동 자원 채굴기 |
| 2. 경작 | 8~10 | 호박·수박·건초(2티어), 구리·켈프(3티어), 금(4티어) | 자동 농작물 수확기, 발효기(미정) |
| 3. 제련 | 미정 | 광석 계열 | 용광로 라인, 주조기 |
| 4. 연금 | 미정 | 네더 재료 | 연금 합성기 |

- 2시대 초안(구현됨, 수치·품목은 [확인 필요](open-questions.md)):
  - 레벨 8~10 미션(생명의 싹·건초 창고·늪의 기운), 새 품목의 매입가·긴급 매입 후보 추가.
  - **자동 농작물 수확기**(초안, Lv.9 상점 4,000G): 같은 높이 9×9 안의 다 자란 밀·당근·감자·비트를 거두고 씨앗 1개(거둔 것에서, 없으면 수확기 출력칸에서)를 써서 다시 심는다 — 씨앗이 없으면 다시 심지 않는다(11차 실기 뒤; 전에는 무료로 다시 심었다), 줄기에서 자란 수박·호박을 자른다. 2초에 하나. 결과는 출력칸 4칸 → 옆·위 상자로(자동 자원 채굴기는 11차 실기 뒤 출력 1칸). 경작용 돌 괭이를 Lv.8 상점에서 판다(밀 씨앗은 체로 흙을 걸러서).
  - 발효기 등 나머지 2시대 기계는 아직 없다.

## 4. 레벨과 메인 미션

- 세이브에는 **레벨**이 있고, 레벨마다 **메인 미션** 하나가 주어진다.
- 메인 미션 = "품목 X를 N개 납품". 상위 레벨은 여러 품목 동시 요구.
- 미션·긴급 매입·상점 매입·기계 레시피는 **추가 NBT가 없는 순수 아이템**만 받는다. 이름·설명·스택 값(기간제 만료 시각 등)이 붙은 아이템은 다른 아이템으로 본다.
- 납품은 **납품함**(전용 블록)으로 한다. 납품함을 사용하면 미션 폼이 열리고, "제출하기" 버튼으로 인벤토리에서 필요한 아이템을 낸다(손에 든 아이템을 바로 넣지 않는다). 호퍼로 자동 투입도 된다. 메뉴의 메인 미션 폼도 같다.
- 미션 완료 → 레벨 업 → 보상: 상점 상품 개방(새 코어 포함), **코어 강화 포인트**, 수표 등.
- 미션과 보상은 데이터(설정 파일)로 정의한다.

## 5. 상점

상점에는 **구매(상점 → 플레이어)**와 **매입(플레이어 → 상점)** 두 방향이 있다. 둘 다 세이브 단위로 공유된다.

### 5.1 구매
- 상품은 레벨로 개방된다. 구매 화면은 위쪽 **탭(도구 / 재료 / 설비 / 기계 / 코어)** 으로 나뉘고 처음에는 첫 탭이 열린다. 상품은 인벤토리 칸 같은 작은 카드 격자(한 줄 6개)로, 상품마다 가격과 **남은 재고 수**(품절·1회 한정)를 보인다. 아직 잠긴 상품도 개방 레벨과 함께 보인다. 뒤로 버튼은 닫기 버튼 왼쪽.
- 재료 탭은 코어 기반으로 쓸 블록도 판다: 조약돌·흙 x16 40G(Lv.2), 모래·자갈 x16 60G(Lv.3), 호박·수박 블록 200G(Lv.8), 구리 블록 1,500G(Lv.9), 말린 켈프 블록 300G(Lv.10).
- 상품마다 **재고**가 있고, **재입고 주기**(인스턴스 시간 기준)마다 최대 재고까지 채워진다.
- **1회성 상품**: 재입고되지 않는 수량 1개 상품. 코어는 1회성이 아니라 개방 레벨부터 매일 재입고되는 상품이다(§3.4).

```
ShopItem { ID, Item, Price, UnlockLevel, Stock, MaxStock, Restock: Period | Never }
```

### 5.2 매입
한 가지만 대량생산하는 플레이를 막고, 다양한 생산 라인을 만들게 하는 것이 목적이다.

- **총 매입 예산**: 상점이 플레이어에게서 사들일 수 있는 금액에 한도가 있다. 예산이 바닥나면 매입이 멈춘다.
- **품목별 매입 한도**: 일부 품목은 정해진 수량까지만 사들인다.
- 예산과 품목 한도는 **인스턴스 하루**마다 회복된다.
- 광석 코어(철·구리·금)에서 나오는 원석과 그 주괴, 점토 블록도 사들인다(초안: 철 원석 40G·주괴 60G, 구리 25·35G, 금 80·120G, 점토 블록 18G). 주괴는 화로 가공의 보상으로 원석보다 비싸다.
- 판매 화면에서 품목을 누르면 **팔 개수**를 슬라이더로 고른다(가진 수와 오늘 팔 수 있는 수 중 작은 쪽까지).
- "전체 판매"는 먼저 **표**(아이콘·이름 / 수량 / 개당 / 합계, 예산·한도 반영)와 그 아래 총합계·판매·취소 버튼을 보여 주고, 판매를 누르면 판다.
- 플레이어가 상점에서 구매하면 상점 예산이 늘어나는 기능은 **지금은 넣지 않는다.** 실제 플레이에서 형평성을 검증한 뒤 결정한다.

```
ShopBuyback { Budget, MaxBudget, Items: [{Item, Price, Limit?, Bought}] }
```

### 5.3 긴급 미션(긴급 매입)
- **플레이어가 접속해 인스턴스가 활성화된 동안에만 발생**한다.
- "제한 시간(10~30분) 안에 품목 X를 최대 N개, 매입가의 n%로 매입". 현재 레벨에서 생산 가능한 품목에서 고른다.
- 인스턴스가 비활성화되면 **타이머가 멈추고**, 다시 활성화되면 이어서 진행한다.
- 납품 방법은 메인 미션과 같다. 남은 시간·수량은 보스바와 알림으로 표시.
- 긴급 매입은 일반 매입 예산과 **별도**다(예산을 소모하지 않음).
- 진행 중인 긴급 매입은 **보스바**로 보여 준다: 품목·납품 수·개당 가격·남은 시간, 게이지는 남은 시간. 마지막 개수를 채우면 바로 끝난다.
- 구현(수치는 초안): Lv.2부터, 플레이 10분 뒤 첫 발생, 끝난 뒤 15~30분마다. 제한 시간 10~30분, 최대 32·64·96·128개, 매입가의 150~250%.
  - 품목은 레벨별 후보(`urgent.go` `urgentItems`)에서 고른다. 시작할 때 제목·소리·채팅으로 알리고, 보스바에 남은 수량·시간을 보인다.
  - 메인 미션 폼(납품함·메뉴)의 "긴급 납품" 버튼이 인벤토리의 해당 품목을 판다. 납품함 호퍼 투입은 메인 미션이 먼저, 필요 없으면 긴급 매입(돈은 호스트에게).
  - 시간은 인스턴스 시간이라 비활성화되면 멈춘다. 운영자 `/dfadmin urgent` 로 바로 시작.

## 6. 공장 / 자동화

Dragonfly에는 피스톤·옵저버·드로퍼·디스펜서·리피터·비교기가 없고 **호퍼, 상자, 화로**는 있다.
따라서 자동화는 **커스텀 기계 블록**이 중심이다.

- 기계 = 커스텀 블록 + 블록 엔티티(내부 인벤토리·진행도) + 틱 처리.
- **동력은 없다.** 설치하면 작업마다 정해진 시간만 걸린다(이후 시대에서 동력 도입 검토).
- 아이템 이동은 호퍼 규칙과 호환된다: 위·옆 호퍼 → 기계 입력, 기계 출력 → 아래 호퍼.
- 기계 화면은 **엔티티 상자**(입력칸·진행 화살표·출력칸·회수 버튼만 보이는 기계별 레이아웃, [json-ui](../tech/json-ui.md)). 호퍼도 같은 칸을 쓴다.
- 기계 위에는 이름·진행도 글자를 띄우지 않는다(보기에 거슬림). 진행도는 기계 창의 진행 칸에서, 체는 모델에 쌓인 양으로 본다.
- 체에는 창이 없다(부산물이 여러 종류라 칸으로 관리하지 않는다).
- 기계를 부수면 기계와 안의 아이템이 함께 떨어진다(서랍도 부수면 내용물·업그레이드를 담은 채로 떨어진다; 메뉴의 "서랍 회수"는 11차 실기 뒤 없앴다). 기계 창 제목 줄의 닫기 버튼 왼쪽 **정보 아이콘**에 마우스를 올리면 기계 설명이 나온다.

### 6.1 첫 시대 기계 (M4)

| 기계 | 동작 | 입수 |
|---|---|---|
| 분쇄기 | 돌 → 조약돌 → 자갈 → 모래, 개당 4초 | 상점 Lv.3 |
| 체 | 손으로 거르는 체(Dorios' Basics 방식). 자갈·모래·흙을 들고 사용하면 1개를 얹고, 사용할 때마다 한 단계씩 걸러 8번째에 부산물(부싯돌·철/금 조각·석탄·점토·씨앗·묘목)이 위로, 무작위 방향으로 튀어나온다. 2칸 안 같은 높이의 체도 함께 걸러진다. 저절로는 걸러지지 않고, 호퍼로 넣을 수 없다 | 상점 Lv.2 |
| 자동 체 | 체와 같은 모양(쇠 틀). 호퍼나 손으로 여러 개를 넣으면 개당 3초에 저절로 걸러, 부산물을 옆·아래 상자(호퍼 등 컨테이너)에 넣고 없거나 가득 차면 위로 떨군다. 손으로 거르기도 된다 | 상점 Lv.4 |
| 판매함 | 들어온 아이템을 상점 매입 규칙(예산·품목 한도)대로 1초마다 판매, 돈은 설치한 플레이어에게 | 상점 Lv.5 |
| 자동 자원 채굴기(희소) | 바로 아래 블록(일반 블록만)을 2초마다 캐서 옆·위의 상자·호퍼·서랍·기계·납품함으로 보낸다. 받을 곳이 없는 아이템은 다른 아이템을 막지 않는다. 결과 칸은 1칸(11차 실기; 예전 4칸에 있던 아이템은 저장에 남아 칸이 비면 옮겨진다) | Lv.5 미션 보상 1개 |

- **망치**(수동 분쇄): 망치로 돌·조약돌·자갈을 캐면 분쇄기 결과가 떨어진다(돌→조약돌, 조약돌→자갈, 자갈→모래). 돌·조약돌은 속도 6, 자갈·모래·흙은 속도 2로 캐서 블록마다 비슷한 시간이 걸린다(클라이언트에도 속도를 보냄, Dragonfly 패치). 내구도 131, 블록마다 1 소모. 상점 Lv.2.
- 첫 무인 라인 예: 코어 위 블록 ← 자동 자원 채굴기 → (옆) 분쇄기 → 호퍼 → 상자/납품함, (반대쪽) 판매함.
- 수치(시간·확률·가격)는 초안이며 [밸런싱 표](open-questions.md)에서 관리한다.
- 이후 후보: 자동 농작물 수확기, 발효기(2시대), 용광로 라인(3시대).

### 6.2 작물 성장(시간 기반)

- 작물(밀·당근·감자·비트)과 수박·호박 줄기는 **무작위 틱으로 자라지 않고**, 심은 때부터 흐른 **인스턴스 시간**으로 정해진 대로 자란다(PMMP식). 인스턴스가 비활성화되면 성장도 멈춘다.
  - 다 자라는 시간(초안): 밀·비트 8분, 당근·감자 10분, 줄기 6분. 다 자란 줄기는 4분마다 열매 하나(옆에 이미 있으면 기다림, 옆 칸이 비고 아래가 흙·경작지일 때).
  - 단계(0~7)는 시간에 고르게 나뉜다. 블록은 **단계가 실제로 바뀌는 순간에만** 바꾼다: 작물마다 다음 변경 시각을 시간순 대기열에 두고, 1초마다 시각이 된 것만 처리한다.
  - 기록은 세이브 상태(`Crops`, 위치별 심은 시각)에 남는다. 뼛가루로 앞서 자란 작물은 그 단계부터 이어서 자란다. 캐거나 없어진 작물은 기록에서 지운다.
- **작물 성장 강화**(코어 관리 화면, 코어 강화 포인트): 단계마다 성장·열매 시간 -15%, 최대 Lv.3, 1·2·3포인트. 올리면 자라던 작물은 지금까지 자란 비율을 유지한 채 새 시간으로 이어서 자란다.
- **작물 우클릭**: 다 자란 작물을 우클릭하면 수확되고 같은 작물이 다시 심긴다(지금은 무료, 나중에 기간제·횟수제 검토). 자라는 작물 위 우클릭은 아무 일도 하지 않아 블록이 놓이지 않는다. 웅크리고 우클릭하면 평소대로(블록 놓기·뼛가루). 단계와 남은 시간은 바라보면 WAILA 패널에 보인다(우클릭 시간 글자는 패널 도입으로 없앰).
- 코드: `crops.go`, Dragonfly 패치 `block.ScheduledCropGrowth`.

## 7. 돈과 수표

- 돈은 **세이브 × 플레이어** 단위다. 세이브 밖에서는 의미가 없고, 같은 세이브의 참여자도 각자 지갑을 가진다.
- **수표**: 돈을 아이템으로 출력한 것.
  - 메뉴에서 금액을 정해 발행 → 지갑에서 차감되고 수표 아이템 지급.
  - 수표를 사용하면 금액이 사용한 플레이어의 지갑에 들어간다.
  - 창고(상자)에 보관하거나 다른 플레이어에게 건네 **돈을 주고받는 수단**이 된다.
  - 아이템 보상만 지급하는 UX(미션 보상, 상자 보상 등)에서 **돈 대신 수표를 지급**하는 용도로도 쓴다.
- 수표는 발행된 세이브에서만 사용할 수 있다(NBT에 세이브 ID 기록).
- 복제 방지: 수표마다 고유 ID를 부여하고 사용 시 세이브의 사용 기록과 대조한다.

## 8. 섬 영역

- 섬은 **청크 단위로 구매**해서 넓힌다(UX가 나쁘면 다른 단위 검토).
- **확장 모드**(메뉴 → 섬 확장): 플레이어 몸은 그 자리에 고정되고(이동·클릭 막힘), 카메라가 대상 청크 위에서 아래를 내려다본다.
  - **이동 키**로 선택 청크를 한 청크씩 옮긴다(누르고 있으면 0.35초마다). 카메라가 선택 청크 위를 따라간다. 커서 엔티티는 없고 선택 청크는 색으로 표시한다.
  - 선택은 몸에서 6청크까지(클라이언트는 몸 주변 청크만 받음). 더 멀리는 끝내고 걸어가서 다시 연다. 유리 바닥은 선택 청크 주변 4청크까지만 그린다.
  - 반투명 유리 바닥은 그 플레이어에게만 보인다(월드는 바뀌지 않음). 소유 청크는 연두·초록 **체크무늬**(이웃 청크와 색이 달라 경계가 보임), 구매 가능 청크는 노랑.
  - 선택 청크는 소유면 하늘색, 구매 가능하면 주황, 살 수 없으면 빨강. 선택 청크는 빈 칸뿐 아니라 **테두리 한 줄을 실제 블록 위에도** 그려 경계를 분명히 한다.
  - 확장 모드 동안 플레이어는 보기 전용 게임 모드(부수기·놓기·상호작용 없음, 피해 없음)라 클라이언트가 유리 바닥을 부수는 예측을 하지 않는다. 끝내면 원래 게임 모드로 돌아온다(그사이 저장되면 서바이벌로 기록).
  - 핫바 위에 대상 청크의 상태와 가격을 계속 표시한다.
  - 웅크리면(또는 메뉴 아이템·`/menu`) 구매·계속·끝내기 폼.
  - 청크 경계 디버그 셰이프는 위에서 보면 선이 어긋나 보여 쓰지 않았다.
  - **표시 방식: `map`(기본, 13차 확정)**. 운영자는 `/dfadmin expandview <map|floor>` 로 섬 전체 방식을 바꿀 수 있다.
    - `map`: 섬을 **멀리 떨어진 곳(x·z 약 +30000, 청크 +1875)에 지도처럼** 보여 준다. 커서 주변 청크마다 각 칸의 가장 위 블록만 섬 표면 바로 아래로 눌러 담고 그 위(섬 표면, `floor` 와 같은 높이)에 유리(색도 `floor` 와 같음)를 깐 가짜 청크를 그 플레이어에게만 보내고(`ViewFakeChunk`), 카메라는 지도 위 `floor` 와 같은 높이. 유리가 블록 바로 위라 가려지지도 뜨지도 않는다. 실제 섬 청크는 건드리지 않는다. 클라이언트는 플레이어 주변 청크만 그리므로(첫 구현에서 지도가 안 보임) **몸도 지도로 옮겨** 카메라 4칸 위에 고정하고 커서를 따라가며, 끝나면 원래 자리로 돌려놓는다(나갈 때도 저장 전에 돌아감). 그래서 커서는 몸에서 6청크 제한 없이 섬 끝까지 간다. 확장 중 서버가 죽으면 몸이 지도 쪽에 저장되지만 공허로 떨어져 섬으로 돌아온다. 엔티티(서랍 표시 등)는 지도에 없다.
      - 12차 뒤 실기: 잘 보임. 유리가 한 칸 높았고, 횃불처럼 빈 곳이 있는 블록이 맨 위면 아래가 비어 깨져 보임 → 유리를 한 칸 내리고, 맨 위 블록이 꽉 찬 불투명 블록이 아니면(빛이 통하는 블록, 우리 커스텀 모델 블록 포함) 그 아래 첫 블록을 한 칸 아래에 함께 깐다(2층).
      - 13차: 가장자리로 갈수록 원근 왜곡 → 지도 카메라는 시야각 30도(`SetCameraFOV`)로 좁히고 65칸 위에서 내려다봐 크기는 그대로, 진짜 위에서 본 지도에 가깝게. 끝나면 시야각을 되돌린다.
    - `floor`: 섬 높이(`expandFloorY`)의 유리 바닥(위 설명). 건물이 있으면 유리가 가려진다(11차).
    - 시험 후 뺀 방식(12차): 가장 높은 블록 위 유리(`sky`, 높은 블록이면 카메라에 너무 가까움), 디버그 셰이프 테두리(`lines`, 선이 얇음), 반투명 판 엔티티(`plates`, 위로 뜬 판과 실제 청크의 거리감 괴리. 블록 너머로 그리는 재질은 지금 렌더러가 리소스팩 재질을 읽지 않아 못 씀).
- 소유 청크 밖에는 건축·채굴할 수 없다.
- 활성 인스턴스는 소유 청크 전체를 로드·틱하므로 확장 가격은 높게, 단계적으로 개방한다.
- 섬은 중심에서 12청크까지 넓힐 수 있다(초안). 인스턴스 로드 반경(4청크) 밖의 소유 청크는 청크마다 로더를 둬 활성 중 계속 로드·틱한다.
- 구매 가능한 청크는 기존 소유 청크와 맞닿은 청크로 제한한다.

## 9. 안전 장치

### 9.1 사망
- 사망해도 인벤토리를 **유지**한다.
- 서버 전체에서 **낙하 피해를 없앤다.**

### 9.2 보이드 낙하
- 보이드에 도달하면 낙하 지점의 x, z에서 **가장 가까운 블록**을 찾고, 그 블록 위 **높은 곳**(예: 섬 높이 + 300)으로 텔레포트해 다시 떨어지게 한다.
  낙하 피해가 없으므로 그대로 착지한다.
- 목적: 낙사의 불쾌감을 줄이고 하던 작업 위치로 되돌려 놓는 것.

### 9.3 분실물 보관함
떨어뜨린 아이템을 잃어버리는 경험을 막는다.

- **보이드로 떨어져 사라진** 드롭 아이템만 **분실물 보관함**에 모은다. 용암·불·선인장·디스폰 등 다른 소실은 처리하지 않는다.
  (공허에 섬만 주는 대신 제공하는 혜택이다.)
- 보관함은 **인스턴스(세이브) 단위**로 하나다. 누가 떨어뜨렸는지, 기계에서 나온 것인지와 관계없이 모두 같은 보관함에 들어간다.
- 보관 기간: 마지막으로 들어온 시점부터 **인스턴스 시간 1일**. 날짜 단위가 아니라 경과 시간으로 판단한다.
- **같은 아이템은 하나의 항목으로 합쳐 수량만 늘린다.** 항목은 **최근 드롭 순**으로 정렬한다.
- 메뉴에서 꺼낼 수 있다.

```
LostItem { Item(NBT 포함 동일성), Count, LastDroppedAt(인스턴스 시간) }
```

## 10. 서랍 (단일 아이템 대용량 보관함)

> 참고: Functional Storage의 1칸 서랍. 여러 종류를 담는 서랍, 압축 서랍은 만들지 않고 **한 종류 아이템을 많이·안전하게** 보관하는 데 집중한다.

### 10.1 기본 규칙
- 서랍 하나에는 **한 종류의 아이템**만 들어간다(아이템 + NBT가 같아야 같은 종류). 겹쳐지지 않는 아이템(최대 1개: 도구, 양동이 등)은 넣을 수 없다.
- 첫 아이템이 들어가는 순간 종류가 정해지고, 비면 다시 아무 아이템이나 받는다(잠금 시 예외, §10.4).
- 용량은 **스택 수** 단위로 정한다(기본값 초안: 32스택 = 64 기준 2,048개). 수량은 내부적으로 정수(int64)로 저장한다.
- 설치하면 앞면이 플레이어 쪽을 향한다.

### 10.2 조작

| 동작 | 결과 |
|---|---|
| 앞면 사용(우클릭/탭) | 손에 든 아이템 스택을 넣는다 |
| 앞면을 0.5초 안에 두 번 사용(손에 무엇을 들었든) | 인벤토리의 서랍 아이템을 전부 넣는다(아이템이 정해진 서랍만: 내용물이 있거나 잠겨 있음) |
| 앞면 때리기(좌클릭/길게 누르기 시작) | 1개 꺼낸다 |
| 웅크린 채 앞면 때리기 | 1스택 꺼낸다 |
| 앞면이 아닌 면에서 채굴 | 서랍을 부순다 |

- 앞면을 때려서는 서랍이 부서지지 않는다(꺼내기 전용).
- 꺼낸 아이템은 인벤토리로 들어가고, 넘치면 플레이어 발밑에 떨군다.

### 10.3 표시
- 서랍 블록은 모델링 없는 **정육면체**: 정면 한 면은 앞면 텍스처(`textures/blocks/drawer_front.png`), 나머지 다섯 면은 옆면 텍스처(`drawer_side.png`). 손잡이는 없다.
- 앞면에 **보관 중인 아이템**을 고정된 자세로 보여주고, 그 위에 **수량 텍스트**(개수만, 예: `1,234`)를 표시한다.
- 수량 텍스트는 엔티티 이름표 대신 클라이언트 디버그 셰이프 글자(공중 글자)로 그린다.
- 아이템 표시는 회전·흔들림이 있는 아이템 엔티티 대신 **아이템 홀딩용 커스텀 엔티티**(`dragonfactory:item_holder`)가 아이템을 들고 있는 방식으로 한다.
- 비어 있으면 표시를 지운다. 잠긴 빈 서랍은 잠긴 아이템을 계속 보여주고 수량 텍스트에 잠금 표시를 한다.

### 10.4 업그레이드와 잠금

업그레이드는 용량·공허 두 가지, 잠금은 **잠금 키**로 한다.

| 종류 | 효과 |
|---|---|
| 용량 업그레이드 | 단계별로 용량 배수 증가(배수는 밸런싱) |
| 공허 업그레이드 | 가득 찬 상태에서 들어오는 같은 아이템을 파괴(생산 라인이 막히지 않게) |
| 잠금 키 | 서랍 앞면에 사용할 때마다 잠금을 켜고 끈다. **닳지 않는다.** 잠긴 서랍은 비어도 아이템 종류를 유지. 빈 서랍도 잠근다: 아이템 종류가 없는 잠긴 서랍에는 호퍼·기계가 넣지 못하고, 플레이어가 손으로 넣은 아이템이 그 종류가 된다(11차 실기) |

- 넣기·꺼내기·키·업그레이드 장착은 **앞면에서만** 된다(11차 실기). 웅크리고 빈손 우클릭하면 **어느 면에서나** 서랍 창이 열린다.
- **서랍 창**(인벤토리처럼 보이는 폼, `ui.SlotMenu`): 위에 보관 칸(아이템·수량, 누를 수 없음)과 그 오른쪽에 이름·수량/최대, 아래 왼쪽에 저장 업그레이드 칸(용량 3칸), 오른쪽에 유틸리티 칸(공허·잠금). 찬 칸은 업그레이드 아이템, 빈 칸은 흐린 실루엣으로 무엇을 더 끼울 수 있는지 보인다. 빈 칸을 누르면 인벤토리의 업그레이드를 끼우고, 찬 칸을 누르면 빼서 돌려준다(용량을 줄이는 빼기는 내용물이 새 용량 이하일 때만). 잠금 칸은 키 없이 잠금을 켜고 끈다(잠금 키는 앞면에서 바로 켜고 끄는 도구로 남는다). 칸마다 안내 문구가 있다: 마우스는 올리면 보이고 클릭하면 실행, 터치는 첫 탭에 칸이 선택되며 안내가 보이고 다시 탭하면 실행(리소스팩 JSON UI만으로 처리, `$touch`).
- 업그레이드는 서랍 앞면에 사용(우클릭)하거나 서랍 창의 빈 칸으로 장착하고, 서랍 창에서 뺄 수 있다.
- 빈 서랍은 잠글 수 없다(잠글 아이템 종류가 없음).
- 앞면 표시(배경 없는 공중 글자): 아래쪽 수량, 위 테두리 가운데 작은 자물쇠(잠김, 업그레이드 표시와 같은 높이), 오른쪽 위 업그레이드(용량 배수 `×2`·`×4`·`×8`, 공허는 보라 구슬). 자물쇠·공허는 리소스팩 폰트 글리프(`font/glyph_E1.png`, U+E100·U+E101). 서랍 아이템 설명에도 잠금 표시.
- 예전 잠금 업그레이드 아이템은 서랍에 사용하면 잠금 키로 바뀐다.
- 잠금·해제·업그레이드 장착은 메시지 없이 앞면 표시 변화와 소리로 알린다(잠금 구리 다락문 닫힘, 해제 열림, 장착 철 갑옷 착용, 안 될 때 거부음). 블록 조작은 대체로 메시지보다 보이는 변화·소리로 알린다.

### 10.5 자동화
- 호퍼로 **넣기(위·옆 호퍼 → 서랍)** 와 **빼기(서랍 → 아래 호퍼)** 를 지원한다. 커스텀 기계도 같은 방식으로 연결한다.

### 10.6 부술 때
- 내용물(아이템 종류, 수량)과 업그레이드, 잠금 상태를 **서랍 아이템의 NBT에 그대로 담아** 떨어뜨린다. 다시 설치하면 그대로 복원된다.
- 서랍 아이템 설명(lore)에 보관 중인 아이템과 수량을 표시한다.
- 내용물이 있는 서랍 아이템은 서로 겹쳐지지 않는다.

### 10.7 입수 경로 · 범위
- 기본 서랍은 상점에서 레벨로 개방, 업그레이드는 상점과 미션 보상으로 얻는다.
- 여러 종류를 담는 서랍, 압축 서랍, **서랍 컨트롤러는 제공하지 않는다.**
