# 02. 드래곤팩토리

> 이름의 유래: **Dragonfly** 구동기로 돌아가는 **공장** 서버.

스카이팩토리 / 알케미 팩토리 스타일의 공장 만들기 게임.
작은 섬에서 **차원의 코어**가 만들어 내는 블록을 가공·자동화하고,
**메인 미션**을 납품해 레벨을 올리면서 새로운 상품과 코어(=시대)를 개방한다.

## 1. 코어 루프

```
코어가 블록 생성 → 채굴 → 가공(기계) → 상점 판매 / 미션 납품
        ↑                                      ↓
  코어 강화·새 코어 ← 상점 구매 ← 돈·레벨 업 ←──┘
```

## 2. 시작 상태

- 새 세이브는 작은 섬(시작 청크 안의 작은 플랫폼)과 그 위의 **기본 코어** 1개로 시작한다.
- 시작 지급품은 최소한(기본 도구 정도). 진행 대부분은 상점 구매로 이뤄진다.

## 3. 차원의 코어

### 3.1 동작
- 코어 바로 **위 칸**이 비어 있으면 생성 주기마다 테이블에서 블록 하나를 골라 생성한다(주기 기반).
- 기본은 **손으로 채굴**한다. 자동 채굴기는 존재하지만 **매우 적은 수만** 얻을 수 있다(1회성 상품, 레벨 보상 등).
  자동화의 중심은 채굴 이후의 가공·운반 라인이다.
- 생성 결과 = `코어 종류의 테이블 × 티어 × 강화 × 설정`.

| 요소 | 영향 |
|---|---|
| 코어 종류(테마) | 생성 가능한 블록 풀. 예: 대지 코어(흙·돌·나무), 광맥 코어(광석), 생명 코어(작물 블록), 네더 코어 … |
| 티어 | 블록 풀에 상위 블록 추가, 기본 속도 상승 |
| 강화 | 속도(주기 감소), 행운(희귀 블록 가중치), 산출(가끔 추가 생성) 등 |
| 설정 | 특정 블록 비중 올리기·제외 같은 필터(강화로 해금) |

### 3.2 코어 강화 포인트
- **레벨이 오를 때 코어 강화 포인트**를 받는다. 포인트로 각 코어의 강화 항목을 올린다.
- 포인트를 어느 코어에 쓸지는 플레이어가 고른다(테마 선택이 곧 전략).

### 3.3 유일성과 추적
- 코어는 **종류별로 월드에 하나만** 설치할 수 있다. 서로 다른 종류의 코어는 동시에 설치 가능.
- 코어는 타일(블록 엔티티)로 관리하며 세이브에 `코어 레코드`를 둔다.

```
CoreRecord {
  Type       // 코어 종류 = 세이브 내 고유 키
  Tier, Upgrades, Settings
  Generation // 재발급할 때마다 +1
  State      // Placed(pos) | Item | Lost
}
```

- 코어 아이템과 코어 블록은 모두 `(Type, Generation)`을 NBT로 가진다.
  레코드와 `Generation`이 다른 사본은 설치할 수 없고, 발견하는 즉시 제거한다.
- **분실 재발급**: 레코드 위치에 코어가 없거나 아이템 상태로 확인되지 않으면 메뉴에서 무상 재발급.
  재발급 시 `Generation+1` → 떠돌던 옛 사본은 자동 무효. 티어·강화·설정은 레코드에 있으므로 유지된다.
- 코어를 캐면 코어 아이템으로 회수된다(강화 정보 유지).

### 3.4 시대(Era)
- 코어 종류 하나 = 시대 하나. 새 코어가 상점에 개방되는 것이 새 시대의 시작이다.

| 시대(예시) | 코어 | 주요 산출 | 대표 기계 |
|---|---|---|---|
| 1. 개척 | 대지 코어 | 흙, 돌, 원목 | 분쇄기(돌→자갈→모래) |
| 2. 경작 | 생명 코어 | 작물 블록, 묘목 | 자동 수확기, 발효기 |
| 3. 제련 | 광맥 코어 | 광석 | 용광로 라인, 주조기 |
| 4. 연금 | 네더 코어 | 네더 재료 | 연금 합성기 |

## 4. 레벨과 메인 미션

- 세이브에는 **레벨**이 있고, 레벨마다 **메인 미션** 하나가 주어진다.
- 메인 미션 = "품목 X를 N개 납품". 상위 레벨은 여러 품목 동시 요구.
- 납품은 **납품함**(전용 블록, 호퍼로 자동 투입 가능) 또는 메뉴에서 인벤토리 제출.
- 미션 완료 → 레벨 업 → 보상: 상점 상품 개방, 코어 개방(1회성 상품), **코어 강화 포인트**, 수표 등.
- 미션과 보상은 데이터(설정 파일)로 정의한다.

## 5. 상점

상점에는 **구매(상점 → 플레이어)**와 **매입(플레이어 → 상점)** 두 방향이 있다. 둘 다 세이브 단위로 공유된다.

### 5.1 구매
- 상품은 레벨로 개방된다.
- 상품마다 **재고**가 있고, **재입고 주기**(인스턴스 시간 기준)마다 최대 재고까지 채워진다.
- **1회성 상품**: 재입고되지 않는 수량 1개 상품. **코어**는 해당 레벨에서 1회성 상품으로 개방된다.

```
ShopItem { ID, Item, Price, UnlockLevel, Stock, MaxStock, Restock: Period | Never }
```

### 5.2 매입
한 가지만 대량생산하는 플레이를 막고, 다양한 생산 라인을 만들게 하는 것이 목적이다.

- **총 매입 예산**: 상점이 플레이어에게서 사들일 수 있는 금액에 한도가 있다. 예산이 바닥나면 매입이 멈춘다.
- **품목별 매입 한도**: 일부 품목은 정해진 수량까지만 사들인다.
- 예산과 품목 한도는 **인스턴스 하루**마다 회복된다.
- 플레이어가 상점에서 구매하면 상점 예산이 늘어나는 기능은 **지금은 넣지 않는다.** 실제 플레이에서 형평성을 검증한 뒤 결정한다.

```
ShopBuyback { Budget, MaxBudget, Items: [{Item, Price, Limit?, Bought}] }
```

### 5.3 긴급 미션(긴급 매입)
- **플레이어가 접속해 인스턴스가 활성화된 동안에만 발생**한다.
- "제한 시간(10~30분) 안에 품목 X를 최대 N개, 매입가의 n%로 매입". 현재 레벨에서 생산 가능한 품목에서 고른다.
- 인스턴스가 비활성화되면 **타이머가 멈추고**, 다시 활성화되면 이어서 진행한다.
- 납품 방법은 메인 미션과 같다. 남은 시간·수량은 사이드바와 알림으로 표시.
- 긴급 매입은 일반 매입 예산과 **별도**다(예산을 소모하지 않음).

## 6. 공장 / 자동화

Dragonfly에는 피스톤·옵저버·드로퍼·디스펜서·리피터·비교기가 없고 **호퍼, 상자, 화로**는 있다.
따라서 자동화는 **커스텀 기계 블록**이 중심이다.

- 기계 = 커스텀 블록 + 블록 엔티티(내부 인벤토리·진행도) + 틱 처리.
- **동력은 없다.** 설치하면 작업마다 정해진 시간만 걸린다(이후 시대에서 동력 도입 검토).
- 아이템 이동은 호퍼 규칙과 호환된다: 위·옆 호퍼 → 기계 입력, 기계 출력 → 아래 호퍼.
- 기계 화면은 **엔티티 상자**(입력칸·출력칸·진행도 표시). 호퍼도 같은 칸을 쓴다.
- 기계를 부수면 기계와 안의 아이템이 함께 떨어진다.

### 6.1 첫 시대 기계 (M4)

| 기계 | 동작 | 입수 |
|---|---|---|
| 분쇄기 | 돌 → 조약돌 → 자갈 → 모래, 개당 4초 | 상점 Lv.3 |
| 체 | 자갈·모래·흙을 걸러 확률로 부산물(부싯돌·철/금 조각·석탄·점토·씨앗·묘목), 개당 3초 | 상점 Lv.4 |
| 판매함 | 들어온 아이템을 상점 매입 규칙(예산·품목 한도)대로 1초마다 판매, 돈은 설치한 플레이어에게 | 상점 Lv.5 |
| 자동 채굴기(희소) | 바로 아래 블록(일반 블록만)을 2초마다 캐서 옆·위의 상자·호퍼·서랍·기계·납품함으로 보낸다. 받을 곳이 없는 아이템은 다른 아이템을 막지 않는다 | Lv.5 미션 보상 1개 |

- 첫 무인 라인 예: 코어 위 블록 ← 자동 채굴기 → (옆) 분쇄기 → 호퍼 → 상자/납품함, (반대쪽) 판매함.
- 수치(시간·확률·가격)는 초안이며 [밸런싱 표](open-questions.md)에서 관리한다.
- 이후 후보: 자동 수확기, 발효기(2시대), 용광로 라인(3시대).

## 7. 돈과 수표

- 돈은 **세이브 × 플레이어** 단위다. 세이브 밖에서는 의미가 없고, 같은 세이브의 참여자도 각자 지갑을 가진다.
- **수표**: 돈을 아이템으로 출력한 것.
  - 메뉴에서 금액을 정해 발행 → 지갑에서 차감되고 수표 아이템 지급.
  - 수표를 사용하면 금액이 사용한 플레이어의 지갑에 들어간다.
  - 창고(상자)에 보관하거나 다른 플레이어에게 건네 **돈을 주고받는 수단**이 된다.
  - 아이템 보상만 지급하는 UX(미션 보상, 상자 보상 등)에서 **돈 대신 수표를 지급**하는 용도로도 쓴다.
- 수표는 발행된 세이브에서만 사용할 수 있다(NBT에 세이브 ID 기록).
- 복제 방지: 수표마다 고유 ID를 부여하고 사용 시 세이브의 사용 기록과 대조한다.

## 8. 섬 영역

- 섬은 **청크 단위로 구매**해서 넓힌다(UX가 나쁘면 다른 단위 검토).
- 구매 화면은 **청크 지도**(엔티티 상자 9×5, 위가 북쪽, 내 위치 중심, 화살표로 이동): 소유(초록)·구매 가능(노랑)·불가(회색), 내 청크는 나침반. 구매 가능한 칸을 누르면 확인 후 구매.
- 소유 청크 밖에는 건축·채굴할 수 없다.
- 활성 인스턴스는 소유 청크 전체를 로드·틱하므로 확장 가격은 높게, 단계적으로 개방한다.
- 구매 가능한 청크는 기존 소유 청크와 맞닿은 청크로 제한한다.

## 9. 안전 장치

### 9.1 사망
- 사망해도 인벤토리를 **유지**한다.
- 서버 전체에서 **낙하 피해를 없앤다.**

### 9.2 보이드 낙하
- 보이드에 도달하면 낙하 지점의 x, z에서 **가장 가까운 블록**을 찾고, 그 블록 위 **높은 곳**(예: 섬 높이 + 300)으로 텔레포트해 다시 떨어지게 한다.
  낙하 피해가 없으므로 그대로 착지한다.
- 목적: 낙사의 불쾌감을 줄이고 하던 작업 위치로 되돌려 놓는 것.

### 9.3 분실물 보관함
떨어뜨린 아이템을 잃어버리는 경험을 막는다.

- **보이드로 떨어져 사라진** 드롭 아이템만 **분실물 보관함**에 모은다. 용암·불·선인장·디스폰 등 다른 소실은 처리하지 않는다.
  (공허에 섬만 주는 대신 제공하는 혜택이다.)
- 보관함은 **인스턴스(세이브) 단위**로 하나다. 누가 떨어뜨렸는지, 기계에서 나온 것인지와 관계없이 모두 같은 보관함에 들어간다.
- 보관 기간: 마지막으로 들어온 시점부터 **인스턴스 시간 1일**. 날짜 단위가 아니라 경과 시간으로 판단한다.
- **같은 아이템은 하나의 항목으로 합쳐 수량만 늘린다.** 항목은 **최근 드롭 순**으로 정렬한다.
- 메뉴에서 꺼낼 수 있다.

```
LostItem { Item(NBT 포함 동일성), Count, LastDroppedAt(인스턴스 시간) }
```

## 10. 서랍 (단일 아이템 대용량 보관함)

> 참고: Functional Storage의 1칸 서랍. 여러 종류를 담는 서랍, 압축 서랍은 만들지 않고 **한 종류 아이템을 많이·안전하게** 보관하는 데 집중한다.

### 10.1 기본 규칙
- 서랍 하나에는 **한 종류의 아이템**만 들어간다(아이템 + NBT가 같아야 같은 종류).
- 첫 아이템이 들어가는 순간 종류가 정해지고, 비면 다시 아무 아이템이나 받는다(잠금 시 예외, §10.4).
- 용량은 **스택 수** 단위로 정한다(기본값 초안: 32스택 = 64 기준 2,048개). 수량은 내부적으로 정수(int64)로 저장한다.
- 설치하면 앞면이 플레이어 쪽을 향한다.

### 10.2 조작

| 동작 | 결과 |
|---|---|
| 앞면 사용(우클릭/탭) | 손에 든 아이템 스택을 넣는다 |
| 앞면을 0.5초 안에 두 번 사용 | 인벤토리의 같은 아이템을 전부 넣는다 |
| 앞면 때리기(좌클릭/길게 누르기 시작) | 1스택 꺼낸다 |
| 웅크린 채 앞면 때리기 | 1개 꺼낸다 |
| 앞면이 아닌 면에서 채굴 | 서랍을 부순다 |

- 앞면을 때려서는 서랍이 부서지지 않는다(꺼내기 전용).
- 꺼낸 아이템은 인벤토리로 들어가고, 넘치면 플레이어 발밑에 떨군다.

### 10.3 표시
- 앞면에 **보관 중인 아이템**을 고정된 자세로 보여주고, 그 위에 **수량 텍스트**(예: `1,234 · 19스택+18`)를 표시한다.
- 아이템 표시는 회전·흔들림이 있는 아이템 엔티티 대신 **아이템 홀딩용 커스텀 엔티티**(`dragonfactory:item_holder`)가 아이템을 들고 있는 방식으로 한다.
- 비어 있으면 표시를 지운다. 잠긴 빈 서랍은 잠긴 아이템을 계속 보여주고 수량 텍스트에 잠금 표시를 한다.

### 10.4 업그레이드

업그레이드는 아래 세 가지로 확정한다.

| 업그레이드 | 효과 |
|---|---|
| 용량 | 단계별로 용량 배수 증가(배수는 밸런싱) |
| 잠금 | 비어도 아이템 종류를 유지(필수 기능) |
| 공허 | 가득 찬 상태에서 들어오는 같은 아이템을 파괴(생산 라인이 막히지 않게) |

- 업그레이드는 서랍에 사용(우클릭)해서 장착하고, 메뉴에서 떼어낼 수 있다. 용량을 줄이는 제거는 내용물이 새 용량 이하일 때만 가능.

### 10.5 자동화
- 호퍼로 **넣기(위·옆 호퍼 → 서랍)** 와 **빼기(서랍 → 아래 호퍼)** 를 지원한다. 커스텀 기계도 같은 방식으로 연결한다.

### 10.6 부술 때
- 내용물(아이템 종류, 수량)과 업그레이드, 잠금 상태를 **서랍 아이템의 NBT에 그대로 담아** 떨어뜨린다. 다시 설치하면 그대로 복원된다.
- 서랍 아이템 설명(lore)에 보관 중인 아이템과 수량을 표시한다.
- 내용물이 있는 서랍 아이템은 서로 겹쳐지지 않는다.

### 10.7 입수 경로 · 범위
- 기본 서랍은 상점에서 레벨로 개방, 업그레이드는 상점과 미션 보상으로 얻는다.
- 여러 종류를 담는 서랍, 압축 서랍, **서랍 컨트롤러는 제공하지 않는다.**
