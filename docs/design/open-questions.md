## 밸런싱 단계에서 결정

구현은 설정값으로 두고, 플레이 테스트로 수치를 정한다.

| 항목 | 비고 |
|---|---|
| 인스턴스 하루의 길이(실제 시간) | 알케미 팩토리·마인크래프트 참고, 인게임 흐름이 잡힌 뒤 조정 |
| 레벨 업 시 코어 강화 포인트 지급량, 강화 항목별 비용 | |
| 섬 확장 단위(청크)와 가격 | UX가 나쁘면 다른 단위 검토 |
| 상점 가격·재고·재입고 주기, 매입 예산·품목 한도 | |
| 긴급 미션 발생 간격·제한 시간(10~30분)·매입 배율 | |
| 보이드 복귀 높이 | 초안: 섬 높이 + 300 |
| 세이브당 최대 인원 | 초안: 4명 |
