# 결정이 필요한 사항

답이 정해지면 해당 문서에 반영하고 여기서는 지운다.

## 결정 필요

- **스카이블록 진행 개편([05](05-sky-progression.md))에서 남은 것(13차 뒤)**: 코어 없앰·경제 정리·도구와 기계는 연구 조합법·맨손 시작은 정해져 반영했다. 남은 것:
  - 섬: 3×3×3 섬으로 시작하지만 건축 가능 범위는 그대로 2×2 청크, 청크 구매도 그대로(돈 대신 조약돌 납품, 초안). 이대로 좋은가.
  - 초반 물: 지금은 얻을 길이 없다(운영자 `/dfadmin give water`만). 나무 그릇·양동이·선인장·비 같은 길이 필요하다.
  - 흙: 모래를 부수면 이제 먼지가 나온다(새 설계). 흙은 발효기 전까지 늘릴 길이 없다(처음 섬의 흙 1층뿐).
  - 돌멩이: 임시로 돌·안산암·섬록암·화강암 네 종(70:10:10:10). 안산암·섬록암·화강암은 지금 쓸 곳이 거의 없다. 다른 종류나 쓰임을 원하면 알려 주세요.

- **발전과제에서 임시로 정한 것(13차 뒤)**: 발전과제는 세이브 단위(섬의 모두가 함께, 연구처럼)로 했다. 마인크래프트처럼 플레이어마다 따로 원하면 알려 주세요. 보상은 아직 없다(힌트 역할만).

- **퇴비통·배럴에서 임시로 정한 것(13차 뒤)**: "32스택"을 **아이템 32개**로 읽었다(서랍의 "스택" 용량과 헷갈릴 수 있음: 2048개로 읽으면 흙 1개에 너무 큼). 가득 찬 퇴비통은 **흙 1개**. 퇴비통은 호퍼로 자동화하지 않는다. 다르게 원하면 알려 주세요.
  - 배럴의 물: 양동이는 철 도구 연구에 있어 **철기 전에는 물을 퍼 갈 수 없다**. 양동이만 따로 일찍 열까, 다른 방법(예: 그릇)을 쓸까.
  - 배럴의 물이 되는 시간(2분)·레시피(판자 6 + 막대기 2)·연구 비용은 초안.
  - 배럴 텍스처 세 장(나무·퇴비·물)은 임시 그림.

- **호퍼 개편에서 임시로 정한 것(13차 뒤)**: 나무 호퍼 4초에 1개·연구 판자 48·레시피 판자 5 + 상자 1, 역방향 호퍼의 속도(나무 4초, 철 0.4초), 나무·철 역방향이 각각 자기 호퍼와만 오가는 조합. 호퍼 모델 텍스처 두 장(나무·철)은 임시 그림. 다르게 원하면 알려 주세요.

- **체 메쉬·원석 조각에서 임시로 정한 것(13차 뒤)**: 원석 조각은 철·금·구리 세 가지, 4개 → 원석 1개. 자동 체 레시피는 철 주괴 4 + 체 + 호퍼(실이 빠져 대신 체를 넣음). 메쉬는 체를 우클릭해 끼우고 빼는 방법은 아직 바꾸기(끼운 것을 다른 메쉬로 교체)뿐이다. 석탄은 조각 없이 그대로 나온다. 다르게 원하면 알려 주세요.

- **연구 개편에서 임시로 정한 것(13차 뒤)**: 체 부산물에 켈프(모래)·호박/수박 씨앗(흙)을 더했다. 화로 굽기와 우리 기계 가공은 잠그지 않는다. 다르게 원하면 알려 주세요.

- **자유 생성(스카이팩토리식)으로의 전환 범위**: 코어·기계 수 제한을 얼마나 풀지, 섬당 기계·블록 엔티티 상한을 둘지. 부하 시험 결과는 [performance.md](../tech/performance.md)(이 모듈 기준 섬 하나 150개 안팎, 섬 하나는 CPU 코어 하나).

## 확인 필요 (6차 실기 후 작업에서 임시로 정함)

- 체 방식: 7차 실기에서 결정 — 손 체와 자동 체로 나눔(창 없음, 손 체는 떨구기만, 자동 체는 옆·아래 상자 → 없으면 떨구기).
- 망치 방식: 7차 실기에서 결정 — 캐서 분쇄(도구 속도).

## 확인 필요 (8차 전 자율 작업에서 임시로 정함)

- **2시대 초안**: 레벨 8~10 미션과 보상, 호박·수박·건초·켈프 공급(13차 뒤: 체 부산물·연구, 진흙은 벽돌로 대체) 레벨. 품목·가격·레벨을 이대로 갈지, 자동 농작물 수확기 초안(9×9, 2초, 4,000G Lv.9)을 이대로 갈지, 발효기 등 다른 2시대 기계를 어떻게 할지.
- **섬 최대 반경 12청크**: 더 넓히거나 좁힐지.
- **업적·칭호·이름 색 초안**(M7): 업적 9개와 칭호 이름, 이름 색 해금 조건(업적 3·6개). 파티클 등 다른 치장을 넣을지.

## 확인 필요 (코어 기반에서 임시로 정함)

결정됨: 코어 기반 방식으로 자원별 코어를 대체, 코어 기반 + 둘레 조합 레시피, 티어별 코어 아이템, 도감 + 발견 + 단서 공개.

- **레시피 표**(02-dragonfactory.md §3.2): 코어 기반·둘레·결과·티어·숨김 여부와 단서 문구. 광석 레시피가 광석 블록을 만들지(현재), 원석을 만들지.
- **둘레 범위**: 코어 기반과 같은 높이 네 방향만 본다. 위·대각선·더 넓은 패턴(3×3 등)이 필요한지.
- **1티어 코어 하루 1개 무료**: 시작 코어를 잃은 세이브가 막히지 않게. 날마다 공짜로 늘릴 수 있는 점이 괜찮은지(유료는 Lv.2부터 300G 하루 2개).
- **재료 탭 상품**(코어 기반용 블록): 조약돌·흙·모래·자갈 x16, 호박·수박·구리 블록·말린 켈프 블록 가격과 개방 레벨.
- **자동 자원 채굴기 입수**: 코어를 여러 개 둘 수 있어도 채굴기는 Lv.5 보상 하나뿐. 상점(1회 한정·하루 1개 등)이나 레벨 보상으로 더 줄지. 지금은 그대로 둠.
- **옛 세이브 전환**: 자원별 코어 → 같은 티어 코어. 섬 가운데 것만 원목 코어 기반을 깔아 주고 나머지는 코어 기반을 놓아야 한다. 예전 강화 포인트는 돌려주지 않음.

## 확인 필요 (기간제 아이템에서 임시로 정함)

- **어떤 아이템을 기간제로 줄지**: 기술만 준비됨. 상점·보상·이벤트 중 어디서 기간제 아이템을 줄지는 미정.
- (결정됨) 보관·가공·납품·판매는 NBT 전체로 아이템을 구분한다. 만료 시각은 한국 시간으로 표시. 알림은 사라질 때만.

- **점토**(초안): 물이 담긴 배럴에 먼지 1개 → 점토 공 1개(물 유지, 즉시, 손으로만). 먼지 여러 개당 1개나 물 소모, 호퍼 자동화는 정하지 않았다.
