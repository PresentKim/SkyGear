## 확인 필요 (6차 실기 후 작업에서 임시로 정함)

- 체 방식: 7차 실기에서 결정 — 손 체와 자동 체로 나눔(창 없음, 손 체는 떨구기만, 자동 체는 옆·아래 상자 → 없으면 떨구기).
- 망치 방식: 7차 실기에서 결정 — 캐서 분쇄(도구 속도).

## 확인 필요 (8차 전 자율 작업에서 임시로 정함)

- **2시대 초안**: 레벨 8~10 미션과 보상, 호박·수박·건초·켈프·진흙 코어의 개방 레벨. 품목·가격·레벨을 이대로 갈지, 자동 수확기 초안(9×9, 2초, 4,000G Lv.9)을 이대로 갈지, 발효기 등 다른 2시대 기계를 어떻게 할지.
- **섬 최대 반경 12청크**: 더 넓히거나 좁힐지.
- **업적·칭호·이름 색 초안**(M7): 업적 9개와 칭호 이름, 이름 색 해금 조건(업적 3·6개). 파티클 등 다른 치장을 넣을지.

## 확인 필요 (받침 코어에서 임시로 정함)

결정됨: 받침 방식으로 자원별 코어를 대체, 받침 + 둘레 조합 레시피, 티어별 코어 아이템, 도감 + 발견 + 단서 공개.

- **레시피 표**(02-dragonfactory.md §3.2): 받침·둘레·결과·티어·숨김 여부와 단서 문구. 광석 레시피가 광석 블록을 만들지(현재), 원석을 만들지.
- **둘레 범위**: 받침과 같은 높이 네 방향만 본다. 위·대각선·더 넓은 패턴(3×3 등)이 필요한지.
- **1티어 코어 하루 1개 무료**: 시작 코어를 잃은 세이브가 막히지 않게. 날마다 공짜로 늘릴 수 있는 점이 괜찮은지(유료는 Lv.2부터 300G 하루 2개).
- **받침용 블록 상품**: 조약돌·흙·모래·자갈·호박·수박·구리 블록·말린 켈프 블록 가격과 개방 레벨.
- **자동 채굴기 입수**: 코어를 여러 개 둘 수 있어도 채굴기는 Lv.5 보상 하나뿐. 상점(1회 한정·하루 1개 등)이나 레벨 보상으로 더 줄지. 지금은 그대로 둠.
- **옛 세이브 전환**: 자원별 코어 → 같은 티어 코어. 섬 가운데 것만 원목 받침을 깔아 주고 나머지는 받침을 놓아야 한다. 예전 강화 포인트는 돌려주지 않음.

## 확인 필요 (기간제 아이템에서 임시로 정함)

- **어떤 아이템을 기간제로 줄지**: 기술만 준비됨. 상점·보상·이벤트 중 어디서 기간제 아이템을 줄지는 미정.
- (결정됨) 보관·가공·납품·판매는 NBT 전체로 아이템을 구분한다. 만료 시각은 한국 시간으로 표시. 알림은 사라질 때만.
