## 밸런싱 단계에서 결정

구현은 설정값으로 두고, 플레이 테스트로 수치를 정한다.

| 항목 | 비고 |
|---|---|
| 인스턴스 하루의 길이(실제 시간) | 알케미 팩토리·마인크래프트 참고, 인게임 흐름이 잡힌 뒤 조정. 현재 20분(`platform.toml`) |
| 레벨 업 시 코어 강화 포인트 지급량, 강화 항목별 비용 | 지급량 초안: `dragonfactory/mission.go` `Levels` |
| 미션 품목·수량·보상 | 초안: `dragonfactory/mission.go` `Levels` |
| 대지 코어 생성 주기·블록 확률 | 초안 3초, `dragonfactory/core.go` `coreTypes` |
| 섬 확장 단위(청크)와 가격 | UX가 나쁘면 다른 단위 검토. 초안 1,000G부터 ×1.5 (`island.go` `chunkPrice`) |
| 상점 가격·재고·재입고 주기, 매입 예산·품목 한도 | 초안: `shop.go` `ShopItems`, `BuybackItems`, `buybackBudget` |
| 긴급 미션 발생 간격·제한 시간(10~30분)·매입 배율 | |
| 보이드 복귀 높이 | 초안: 섬 높이 + 300 |
| 세이브당 최대 인원 | 초안: 4명 |
| 서랍 기본 용량, 용량 업그레이드 배수 | 초안: 32스택, ×2/×4/×8 (`drawer.go`) |
| 기계 작업 시간, 체 확률, 기계 상점 가격·개방 레벨 | 초안: 분쇄 4초, 체 3초, 채굴 2초, 판매 1초 (`machine.go` `machineKinds`, `sieveRecipes`), 분쇄기 1,500G Lv.3 · 체 2,000G Lv.4 · 판매함 3,000G Lv.5 |
| 레벨 6~7 미션, 부산물 매입가 | 초안: `mission.go` `Levels`, `shop.go` `BuybackItems`(부싯돌·점토·철/금 조각) |
