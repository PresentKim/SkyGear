# 결정이 필요한 사항과 밸런싱 표

답이 정해지면 해당 문서에 반영하고 여기서는 지운다. 아래는 구현에서 임시로 정한 것으로, 다르게 원하면 알려 주세요.

## 결정 필요

- **섬 크기**: 3×3×3 섬으로 시작하지만 건축 가능 범위는 2×2 청크이고, 청크는 조약돌 납품으로 산다. 이대로 좋은가.
- **초반 물**: 물은 배럴에서 얻지만 퍼 담는 양동이가 철기 연구(철 주괴 6)에 있어 철기 전에는 물을 퍼 갈 수 없다. 양동이만 따로 일찍 열까, 다른 방법(예: 그릇)을 쓸까.
- **돌멩이 종류**: 돌·안산암·섬록암·화강암 네 종(70:10:10:10). 안산암·섬록암·화강암은 쓸 곳이 거의 없다. 다른 종류나 쓰임이 필요한가.
- **발전과제 범위**: 세이브 단위(섬의 모두가 함께, 연구처럼)로 진행한다. 플레이어마다 따로 원하면 알려 주세요. 보상은 없고 힌트 역할만 한다.
- **퇴비통·배럴**: "32스택"을 아이템 32개로 읽었다(2048개로 읽으면 흙 1개에 너무 큼). 가득 찬 퇴비통은 흙 1개. 배럴의 물이 되는 시간(2분)·레시피(판자 6 + 막대기 2)·연구 비용은 초안이다.
- **점토**: 물이 담긴 배럴에 먼지 1개 → 점토 공 1개(물 유지, 즉시, 손으로만). 먼지 여러 개당 1개나 물 소모, 호퍼 자동화는 정하지 않았다.
- **체와 메쉬**: 원석 조각은 철·금·구리·주석·납·은·니켈이고 4개 → 원석 1개(새 금속은 가루로만). 자동 체 레시피는 철 주괴 4 + 체 + 호퍼. 석탄은 조각 없이 그대로 나온다. 체 부산물에 켈프(모래)·호박/수박 씨앗(흙)을 넣었다.
- **호퍼**: 나무 호퍼 4초에 1개·연구 판자 32·레시피 판자 5 + 상자 1, 역방향 호퍼의 속도(나무 4초, 철 0.4초). 호퍼 모델 텍스처 두 장은 임시 그림이다.
- **기계 수 제한**: 섬당 기계·블록 엔티티 상한을 둘지. 부하 시험 결과는 [performance.md](../tech/performance.md)(이 모듈 기준 섬 하나 150개 안팎, 섬 하나는 CPU 코어 하나).
- **업적·칭호·이름 색**: 업적 3개(첫 연구, 첫 기계, 청크 10개)와 이름 색 해금 조건(업적 3·6개). 파티클 등 다른 치장을 넣을지.

- **정수가 드는 연구의 범위**: 기계 자동화·작물 자동화·액체·합금 설비·몬스터·마법·프로젝트 연구에 연구 정수("공학의 정수" 등 다섯 가지)를 붙이고 도구·갑옷 단계는 제외했다([11 §5](11-research-essences.md)). 이 범위와 연구별 개수가 맞는가.
- **정수 재료에 액체를 더할지**: 정수 제작에 물이나 용암을 쓰면 액체 라인이 연구소까지 이어진다(지금은 아이템 재료만).

- **정지 알림의 기본값**: 정지 알림은 기본으로 켜 두고 통계 화면에서 끈다([12](12-production-monitor.md)). 채팅이 어지러워질 수 있어 기본을 꺼 둘지.
- **기계 강화의 범위와 단계 이름**: 기본·고급·정밀·궁극 네 단계와 강화되는 기계 목록([13 §2](13-machine-tiers.md)). 기계에 단계가 보이는 곳은 WAILA와 정보 아이콘뿐이다(블록 모양은 그대로).
- **마법 체의 대체 규칙**: 엔더맨·피글린·익사자 에센스는 일부 입력의 기본 드롭을 대체한다([15 §4](15-magic-sieve.md)). 대체 대신 모두 추가로 할지.
- **새 몬스터 4종과 웨이브 변경**: 익사자·마녀·피글린·위더 스켈레톤을 웨이브 3·4·6·7·8단계에 넣었다([15 §1](15-magic-sieve.md)). 웨이브가 어려워질 수 있다.
