# 15. 마법 체와 에센스 테마

> 수치는 모두 초안이며 [open-questions](open-questions.md)의 표에서 관리한다. 체와 메쉬는 [02 §6](02-skygear.md), 몬스터·웨이브·시뮬레이터는 [07 §7](07-progression-expansion.md), 에센스꽃은 [08 §3](08-storage-gear-magic.md). 드롭 표의 기준은 `content/skygear/sievetable/magicsieve_tables.go`다.

**마법 체**는 자동 체에 **에센스 칸**을 더한 기계다. 몬스터의 에센스를 넣으면 체에서 나오는 것이 그 몬스터의 **테마**로 바뀐다. 익사자의 에센스는 바다의 것을, 엔더맨의 에센스는 엔드의 것을, 피글린의 에센스는 지옥의 것을 내놓는다. 어려운 몬스터의 에센스일수록 희귀한 것이 더 잘 나온다.

## 1. 몬스터와 난이도

몬스터는 열한 종이고, 난이도는 희귀 배수에 쓰인다(웨이브 몬스터의 기본 능력치는 `monster.go`).

| 몬스터 | 난이도 | 나오는 웨이브 | 시뮬레이터 드롭 |
|---|---|---|---|
| 좀비 | 1 | 1·2·3·5·7·8 | 썩은 살점 |
| 스켈레톤 | 1 | 2·4·5·8 | 뼈, 화살 |
| 거미 | 2 | 3·6 | 실, 거미 눈 |
| 크리퍼 | 2 | 3·6 | 화약 |
| 슬라임 | 2 | 4 | 슬라임볼 |
| **익사자** | 3 | 4 | 썩은 살점, 구리 주괴, 앵무조개 껍데기 |
| **마녀** | 3 | 3 | 설탕, 막대기, 레드스톤, 발광석 가루, 거미 눈, 유리병 |
| **피글린** | 4 | 6·7 | 금 조각, 금 주괴, 익히지 않은 돼지고기 |
| 엔더맨 | 5 | 5·7·8 | 엔더 진주 |
| 블레이즈 | 6 | 6·7·8 | 블레이즈 막대 |
| **위더 스켈레톤** | 7 | 8 | 뼈, 석탄, 위더 해골 |

웨이브 단계별 구성과 보상은 [07 §7](07-progression-expansion.md)에 있다. 몬스터는 죽을 때 12%로 자기 에센스를 떨군다.

## 2. 에센스를 얻는 곳

- **웨이브**: 처치할 때 12%, 단계를 처음 깰 때 보상.
- **체 먼지**: 철 메쉬부터 먼지에서 나온다. 익사자·마녀·피글린은 다이아몬드 메쉬(익사자·마녀·피글린)와 네더라이트 메쉬(위더 스켈레톤)에서 나온다. 자세한 확률은 도감.
- **에센스꽃**: 일곱 종(좀비·스켈레톤·크리퍼·거미·슬라임·엔더맨·블레이즈)을 꽃으로 키운다. 익사자·마녀·피글린·위더 스켈레톤의 에센스는 웨이브와 체로 얻는다.

## 3. 마법 체

| 항목 | 값 |
|---|---|
| 창 | 입력 칸 1, **에센스 칸** 1, 진행 링, 출력 칸 4, 에너지 게이지 (`§d§m§9`) |
| 주기 | 90틱(4.5초)마다 블록 하나 |
| 에너지 | 40 RE/t |
| 메쉬 | 자동 체처럼 체 블록에 메쉬를 우클릭해 끼운다. 메쉬 없이는 거르지 않는다 |
| 에센스 | 칸에 에센스가 있으면 하나를 써서 **24회**를 충전한다. 거를 때마다 1회를 쓴다 |
| 에센스가 없을 때 | 자동 체처럼 메쉬 표의 드롭만 나온다 |
| 입력 | 자갈·모래·흙·먼지 |
| 출력 | 4칸. 넘치는 것은 기다리고, 가득 차면 멈춘다 |
| 강화 | 단계 키트로 속도·소비·버퍼가 오른다([13](13-machine-tiers.md)) |

호퍼·도관은 입력 칸에 블록을, 에센스 칸에 에센스를 넣는다(받는 칸은 아이템이 정한다). 에센스 칸은 에센스만 받는다.

## 4. 드롭이 정해지는 법

한 블록을 거를 때 굴리는 것은 다음과 같다.

1. **기본 표**: 끼운 메쉬의 표(`sievetable.Tables`).
2. **테마 표**: 충전된 에센스의 몬스터가 그 입력에 대해 가진 항목들.
3. 테마가 그 입력을 **대체**하면 기본 표의 항목은 굴리지 않는다(예: 엔더맨 + 자갈은 부싯돌·석탄·철 대신 엔드 돌이 나온다). **추가**이면 기본 표에 더한다.
4. 테마 항목의 확률(천분율)은 메쉬 배율(`meshBoost`)을 곱한다.
5. **희귀** 표시가 붙은 항목은 몬스터의 난이도로 더 곱한다: 곱 = 1 + 0.2 × (난이도 − 1). 위더 스켈레톤은 ×2.2, 좀비는 ×1.
6. 한 항목의 확률은 95%를 넘지 않는다. 항목마다 따로 굴리므로 한 블록에서 여러 개가 나올 수 있다.

## 6. 안내와 화면

- **WAILA**: 충전된 에센스와 남은 횟수("익사자 에센스 · 18회")가 보인다. 에센스 없이 기본 표로 거를 때는 이름만 보인다.
- **도감**: 에센스를 고르면 그 테마의 표가 나오고, 테마 아이템의 "얻는 곳"에 "마법 체 + ○○ 에센스: N%"가 나온다. "몬스터·웨이브" 쪽에 난이도가 있다.
- **업적**: 마법 체로 거른 횟수(전체와 몬스터별), 희귀 항목을 얻은 횟수, 테마 아이템을 처음 가진 순간.

## 7. 연구와 레시피

- 연구 "마법 체": 선행은 자동 체, 몬스터 시뮬레이터, 마법 식물. 비용은 다이아몬드 8, 엔더 진주 8과 연구 정수(공학 8·연금술 8·사냥 6·마법 6).
- 레시피: 자동 체 1 + 엔더의 눈 2 + 다이아몬드 2 + 자수정 조각 4 (무형).

## 8. 업적

| 키 | 단계 |
|---|---|
| `magic_sift` 마법 체로 거르기 | 1 / 100 / 1천 / 1만 / 10만 |
| `magic_sift_<몬스터>` 에센스별 | 1 / 100 / 1천 (열한 종) |
| `rare_find` 희귀 항목 | 1 / 10 / 50 / 250 |
| 테마 아이템을 처음 가진 순간 | 앵무조개 껍데기, 바다의 심장, 스펀지, 프리즈머린 조각, 셜커 껍데기, 용의 숨결, 고대 잔해, 가스트 눈물, 위더 해골, TNT 외 |
