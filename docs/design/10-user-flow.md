# 10. 유저 플로우 분석과 보강

> 수치(시간, 비용)는 초안이며 [open-questions](open-questions.md)의 표에서 관리한다. 이 문서는 지금 구현된 요소를 처음부터 끝까지 따라가며 막히는 곳을 찾고, 어떤 유저를 위해 무엇을 보강하는지 적는다.

## 1. 대상 유저

| 유저 | 기대 | 이탈 요인 |
|---|---|---|
| **장르 경험자** (스카이팩토리·ATM·Create 등을 해 본 유저) | 자원 사슬을 스스로 설계하는 자유, 효율을 높이는 선택, 레시피를 찾아보는 도구, 뚜렷한 최종 목표 | 느린 초반, 어디서 무엇이 나오는지 알 수 없음, 끝이 보이지 않음, 지나치게 쉬운 안내 |
| **처음 접하는 유저** | 지금 무엇을 해야 하는지, 작은 성공을 자주 맛보는 것, 틀려도 되돌릴 수 있는 것 | 낯선 용어(체, 메쉬, RE), 막혔을 때 이유를 모름, 한꺼번에 너무 많은 선택지 |
| **협동 파티** (2~4명) | 역할을 나누고 진행을 공유하는 것 | 한 명이 모든 걸 해야 하는 병목, 진행이 사람마다 다른 것 |

설계의 원칙은 둘이다. **막힘은 안내로 풀고(처음 유저), 끝은 열어 둔다(경험자).** 안내는 켜고 끄는 선택이 아니라 눈에 띄지만 강요하지 않는 곳(퀘스트 창, 연구 설명, 도감)에 둔다.

## 2. 단계별 흐름

시간은 장르 경험자 기준의 초안 추정이다(처음 유저는 1.5~2배).

| 단계 | 플레이어가 하는 일 | 안내 장치 | 예상 시간 | 위험 |
|---|---|---|---|---|
| 0. 입장 | 서버 안내, 세이브 선택 | 안내 폼, 도움말 | 5분 | 용어가 낯섦 |
| 1. 나무 | 원목 → 판자 → 조합대 → 연구대, 첫 연구(막대기) | 퀘스트 창, 발전과제 힌트 | 10분 | 연구대를 쓰는 법을 모름 |
| 2. 돌 | 돌멩이 → 조약돌 → 화로·돌 도구·망치 | 발전과제 힌트 | 10~15분 | **손작업 노동량** |
| 3. 체 | 껍질 → 실 → 체 → 메쉬 → 철 | 발전과제, 도움말 | 1시간 | 실(섬유) 수급, 체 드롭 확률을 모름 |
| 4. 에너지 | 발전기, 도관, 분쇄기·자동 체 등 첫 자동화 | 연구, 도움말(에너지·도관) | 1.5시간 | 기계가 왜 멈췄는지 모름, 라인 구성이 막막함 |
| 5. 금속·액체 | 새 금속, 합금, 광석 세척, 시뮬레이터, 양동이·용암 | 연구, 도감 | 3~5시간 | 정보 부족, 설비 수가 많아짐 |
| 6. 전투 | 차원 게이트 웨이브, 장비 제작 | 웨이브 표, 도감 | 4~6시간 | 난이도 급등 |
| 7. 마법 | 꽃, 광석꽃·보석꽃·에센스꽃, 염색 | 연구, 도감 | 3~5시간 | 조합 재료가 복잡함 |
| 8. 프로젝트 | 세 프로젝트, 용의 알 | 도움말(목표와 흐름), 발전과제 | 5시간 이상 | **목표가 보이지 않으면 동기가 없음** |

## 3. 정체 구간 (분석)

1. **손작업 노동량(단계 2).** 화로·돌 도구·망치 연구에 각각 조약돌 16개가 든다. 돌멩이 4개가 조약돌 1개이고 돌 돌멩이가 70%라, 합쳐 우클릭 약 280번이다. 경험자는 견디지만 처음 유저가 가장 먼저 지치는 구간이라 계속 관찰한다.
2. **정보 접근성(단계 3 이후).** 체에서 무엇이 얼마나 나오는지, 합금 비율, 몬스터 드롭, 마법 식물의 수확물을 확인할 곳이 필요하다. 이 장르의 유저는 레시피 뷰어(JEI·EMI)를 기본 도구로 여긴다.
3. **장기 목표(단계 6 이후).** 웨이브 8단계와 마법 식물 뒤에는 이끌어 줄 최종 목표가 필요하다. 이 장르는 ATM Star 같은 최종 목표가 동기를 이끈다.
4. **막힘 진단.** 기계가 멈추는 이유(에너지 부족, 출력 슬롯 부족, 재료 부족)를 바라보는 것만으로 알 수 있어야 한다.
5. **자동화 설계.** 기계가 늘어날수록 "어떻게 이어야 하는가"가 문제가 되므로 예시가 필요하다.
6. **보이지 않는 선행 연구.** 퀘스트 창은 발전과제 순서대로 목표를 보이는데, 아이템 목표의 절반 가까이는 레시피를 여는 연구가 먼저 필요하고, 합금로(선행 연구 4개)·액체 도관(3개)처럼 여러 겹인 곳도 있다. 목표만 보이고 어느 연구를 해야 하는지 보이지 않으면 "이제 뭐하지?"가 된다.
7. **칭호 보상의 도달 가능성.** 이름 색 해금이 업적 3·6개를 요구하므로 업적이 그만큼 있어야 마지막 색에 닿는다.

## 4. 보강

| 항목 | 대상 | 내용 | 상태 |
|---|---|---|---|
| 초반 노동량 | 처음 유저 | 화로·돌 도구·망치 연구의 조약돌 비용을 16으로 낮게 둔다(막대기도 4~8개) | 구현 |
| **도감**(`/도감`) | 모두 | 체 드롭표(블록 × 메쉬), 가공·합금표, 몬스터 드롭과 웨이브표, 마법 식물, 장비 재료. 도감은 탭 줄(검색·체·가공·몬스터·식물)이 있는 창이고, **검색** 탭은 도감이 아는 모든 아이템을 이름(초성도 됨)으로 찾는다(검색어 입력의 뒤로·닫기는 검색 탭으로 돌아온다). 위에 즐겨찾기와 최근 본 아이템이 있다(아이템 쪽의 별 칸으로 즐겨찾기한다). 아이템을 들고 `/도감`이나 메뉴 → 도감에서 **얻는 곳과 쓰이는 곳**을 찾는다. 아이템 쪽은 레시피 뷰어처럼 그림으로 보인다: "얻는 법"과 "쓰는 곳" 두 보기에서 조합대 레시피는 실제 조합대처럼 3×3 칸에, 기계 레시피는 재료 → 화살표 → 결과로, 체는 블록·메쉬 → 드롭과 확률로 그린다. 막대기·망치·도끼·괭이 같은 손작업과 퇴비통·도가니·배럴도 같은 모양으로 나온다. 만들 수 있는 아이템은 원재료를 사슬 끝까지 세어 보여 준다. 칸을 누르면 그 아이템의 도감으로 이어진다. 기계가 읽는 표를 그대로 읽으므로 어긋나지 않는다 | 구현 |
| **프로젝트** | 경험자 | 공장·사냥꾼·재배자 프로젝트(연구 형태, 재료를 쌓아서 바침) → 마지막 "용의 알" 연구 → 용의 알 조합 → 섬에 놓으면 완성 | 구현 |
| 완성의 의식 | 모두 | 알을 놓으면 섬의 모두에게 알림·효과·업적·칭호 | 구현 |
| 업적 5개 추가 | 모두 | 첫 웨이브, 게이트 지배자, 내 손으로 만든 도구, 첫 개화, 드래곤팩토리 완성(모두 칭호가 따라옴) → 이름 색이 모두 도달 가능 | 구현 |
| 기계 상태 표시 | 처음 유저 | 바라보면 "결과 칸이 가득 참", 자동 제작기의 "조합법을 정하세요 / 재료 부족: …" | 구현 |
| 연구 단계 표시 | 처음 유저 | 퀘스트 창의 목표가 연구 뒤에 있거나 연구가 여러 겹 선행되어 있으면, 지금 할 수 있는 연구와 그 재료를 목표 아래에 보여 준다 | 구현 |
| 목표 추적 | 경험자 | 발전과제 화면에서 달성하지 않은 목표 하나를 추적하면 퀘스트 창이 트리 순서 대신 그 목표를 따른다(달성하면 트리 순서로 돌아간다). 초반에는 안내를 따르고, 후반에는 하고 싶은 목표를 고른다 | 구현 |
| 발전과제 → 도감 | 모두 | 발전과제 화면에서 목표 아이템의 도감(얻는 곳·쓰이는 곳)으로 바로 간다 | 구현 |
| 연구 정수와 정수 추출기 | 경험자 | 높은 연구에 시기별 생산 라인(철·레드스톤, 합금, 작물, 몬스터 드롭, 마법 식물)을 요구해 중반 공장을 키운다. 연구는 즉시 끝나고 시간은 정수 생산에 든다 ([11](11-research-essences.md)) | 구현 |
| 도움말 "목표와 흐름" | 처음 유저·경험자 | 최종 목표와 여섯 단계, 어디서 힌트를 얻는지 | 구현 |
| 도움말 "자동화 라인 예시" | 처음 유저 | 조약돌·나무·금속 라인 예시와 연결 규칙 | 구현 |
| 도움말 탭과 이어 읽기 | 처음 유저·경험자 | 주제를 진행 단계 탭(처음·손작업·자동화·금속·전투·마법)으로 나누고, 주제 쪽의 앞·뒤 버튼으로 탭을 차례로 읽는다. 마지막으로 본 탭이 다시 열린다 | 구현 |

## 5. 목표의 3층 구조

게임 이론의 세 층(즉각·중기·장기 목표)으로 정리한다.

- **즉각 목표(1분~10분)**: 퀘스트 창의 다음 발전과제, 연구 하나를 끝내는 것. 화면에 항상 보인다.
- **중기 목표(1~3시간)**: 새 기계 계열을 여는 것(에너지, 금속, 액체, 웨이브). 연구 트리가 가까운 선택지를 보여 준다.
- **장기 목표(수십 시간)**: 세 프로젝트와 용의 알. 도움말 "목표와 흐름"에서 처음부터 알 수 있고, 연구 목록에 프로젝트가 나타나는 순간 눈앞의 일이 된다.

## 6. 프로젝트 설계

| 프로젝트 | 선행 | 바치는 것 | 어떤 플레이를 요구하는가 |
|---|---|---|---|
| 공장 | 엔더 도관, 스토리지 컨트롤러, 자동 제작기, 용암 발전기 | 강철·엘렉트럼·인바·청동 주괴 32개씩, 다이아몬드 16, 공학·연금술의 정수 16개씩 | 합금 라인을 규모 있게 자동화 |
| 사냥꾼 | 차원 게이트, 장비 제작대, 다이아 갑옷, 블레이즈 가공 | 블레이즈 막대·엔더 진주·슬라임볼·거미 눈 16개씩, 뼈 32, 사냥의 정수 16·공학과 연금술의 정수 8개씩 | 시뮬레이터와 웨이브 활용 |
| 재배자 | 에센스꽃, 염색 | 에센스꽃·보석꽃 씨앗, 에센스, 농사의 정수 16·사냥의 정수 8·마법의 정수 16 | 마법 식물을 끝까지 키우기 |
| 용의 알 | 세 프로젝트 | 다이아몬드 32, 에메랄드 32, 네더라이트 주괴 4, 강철 주괴 32, 다섯 정수 32개씩 | 모든 흐름의 합 |

- 세 프로젝트는 서로 순서가 없고, 협동 파티는 갈라서 맡을 수 있다(바치는 사람은 인벤토리에서 낸다).
- 용의 알의 조합은 엔더의 눈 1개와 흑요석 8개이고, 알을 놓으면 끝이다. 게임은 계속할 수 있다.

## 7. 검증 질문 (플레이 테스트)

- 처음 유저가 10분 안에 막대기 연구를 끝내는가, 첫 30분 안에 화로까지 가는가.
- 체 앞에서 "무엇이 나오는가"를 도감으로 해결하는가, 아니면 포기하는가.
- 기계가 멈췄을 때 바라봐서 이유를 알아내는가.
- 경험자가 도움말 "목표와 흐름"을 읽고 장기 계획을 세우는가.
- 세 프로젝트의 비용이 시간상 균형이 맞는가(사냥꾼이 가장 빠르지는 않은가).

## 8. 앞으로의 방향

- 첫 접속 튜토리얼 흐름(처음 3개 발전과제에서 클릭 위치를 직접 가리키는 연출).
- 협동 역할 표시(누가 어느 프로젝트에 얼마나 바쳤는지).
- 생산량·소비량 통계 화면(공장 병목 찾기).
- 주간 목표나 도전 과제 같은 반복 콘텐츠.
