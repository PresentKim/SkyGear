# 08. 저장·장비·마법 식물·성장 (2차 진행 확장)

> 상태: **초안, 구현 진행 중.** 07([진행 확장](07-progression-expansion.md)) 다음 묶음. 수치는 전부 초안이고 [open-questions](open-questions.md)의 밸런싱 표를 따른다.

## 1. 스토리지 컨트롤러 (FunctionalStorage)

여러 서랍을 하나의 저장소로 묶는다(`storage.go`).

- **스토리지 컨트롤러**: 서랍 또는 **스토리지 링크**를 거쳐 면이 맞닿아 이어진 서랍을 컨트롤러 기준 **각 축 16칸 안**까지 한 저장소로 본다(가까운 서랍부터).
- **스토리지 링크**: 서랍 기능 없이 이음만 하는 블록(철 주괴 2 + 레드스톤 1 → 4개). 떨어진 서랍이나 서랍 줄을 컨트롤러에 잇는다.
- 호퍼·도관이 컨트롤러에 넣으면 같은 아이템을 이미 담은 서랍에 먼저, 없으면 잠기지 않은 빈 서랍에 들어가고(서랍의 잠금·공허 규칙 그대로), 뺄 때는 어느 서랍에서든 나온다.
- 우클릭: 아이템을 들고 있으면 그 묶음을 모두 넣고, 빈손이면 목록이 열려 누른 항목을 한 묶음씩 꺼낸다(쪽 넘김).
- 연구 "스토리지 컨트롤러"(서랍 업그레이드·아이템 도관·주석 뒤, 철 32 + 청동 8), 컨트롤러 = 청동 4 + 서랍 + 호퍼 + 레드스톤 2.
