## 비전

하나의 서버 안에서 여러 종류의 **섬 게임**을 골라 플레이하는 플랫폼.
첫 번째 게임은 스카이팩토리 / 알케미 팩토리 스타일의 **공장 만들기** 게임 **드래곤팩토리**이며,
기존에 구현한 원블럭 농사 프로토타입은 이 게임의 "차원의 코어" 시스템으로 흡수·재설계한다.
게임 종류를 늘릴 수 있는 구조로 개발하되, 당분간 사용자에게는 게임 선택 단계를 보여주지 않는다.

## 용어

| 용어 | 정의 |
|---|---|
| 계정(Account) | Xbox XUID 기준 플레이어. 치장·칭호·친구 등 게임과 무관한 데이터를 가진다. |
| 게임 종류(Game Type) | 섬 게임의 종류. 현재는 드래곤팩토리 하나이며 선택 UI는 없다. |
| 세이브(Save) | 한 게임 종류의 진행 데이터 한 벌. 계정당 3슬롯. |
| 인스턴스(Instance) | 세이브를 서버에 불러온 실행 단위. 호스트가 접속해 있는 동안만 활성화된다. |
| 인스턴스 시간 | 인스턴스가 활성화되어 있던 누적 시간. 게임 내 모든 주기의 기준. |
| 호스트(Host) | 세이브의 소유자. 초대된 플레이어는 게스트. 게스트는 호스트 없이 입장할 수 없다. |
| 수표 | 돈을 아이템으로 출력한 것. 보관·거래·보상 지급에 쓴다. |
| 차원의 코어(Core) | 위쪽에 블록을 재생성하는 특수 블록. 드래곤팩토리의 핵심 자원 공급원. |
| 시대(Era) | 코어 테마 단위의 기술 단계. 새 코어 개방 = 새 시대 개방. |
