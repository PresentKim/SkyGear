# 12. 생산 통계와 정지 알림

> 수치(시간, 개수)는 모두 초안이며 [open-questions](open-questions.md)의 표에서 관리한다. 기계 공통 규칙은 [02 §11](02-skygear.md), 에너지는 [06](06-power-and-conduits.md), 업적 엔진은 [01 §5](01-platform.md).

공장 게임의 재미는 병목을 찾아 푸는 데 있다. 기계가 늘어나면 바라보는 것만으로는 어디가 막혔는지 알 수 없으므로, 섬이 **무엇을 얼마나 만드는지**(생산 통계)와 **어느 기계가 왜 멈췄는지**(정지 알림)를 한곳에서 보여 준다.

## 1. 생산 기록

기계가 출력 칸에 넣은 아이템과 에너지를 기록한다. 섬(세이브) 단위이고, 섬의 모두가 같은 기록을 본다.

- **무엇을**: 기계가 만든 아이템(종류별 개수), 발전한 RE(발전기·용암 발전기), 기계가 쓴 RE. 손으로 한 일은 기록하지 않지만, 손 체가 거른 결과는 섬의 생산으로 센다.
- **창**: 최근 **1분**, **5분**, **15분**의 분당 평균과 **누적**. 시간은 인스턴스 시간(섬이 켜져 있는 동안)이다. 1분 칸 15개를 돌려 쓴다.
- **누적**은 세이브에 저장된다(`State.Produced`, 아이템 종류별). 창 안의 기록은 저장하지 않는다.
- **에너지**: 발전량과 사용량의 분당 평균(RE/t로 환산)과, 에너지 셀에 쌓인 양/용량. 발전이 사용보다 낮으면 화면에서 알려 준다.

## 2. 기계의 상태

설치된 기계는 섬의 **기계 목록**에 올라가 1초마다 상태를 살핀다(틱이 멈춘 기계는 목록에서 빠진다).

| 상태 | 뜻 | 알림 |
|---|---|---|
| 작동 | 이번에 일을 했다 | - |
| 대기 | 일이 없다(입력 없음, 목표 없음) | 없음 |
| 에너지 부족 | 일하려는데 버퍼가 모자라다 | 있음 |
| 출력 부족 | 다 된 결과가 출력 칸에 들어가지 못한다 | 있음 |
| 연료 부족 | 발전기에 연료가 없고 버퍼가 비어 간다 | 있음 |
| 재료 부족 | 최근에 일하던 기계(5분 안)가 재료가 없어 쉬고 있다 | 없음 |

- 대기는 정상이다. 재료 부족은 "최근까지 일하던 기계가 쉬는 경우"로, 채팅으로도 정지 목록으로도 알리지 않는다.
- 에너지 부족은 **2초(40틱) 연속**으로 에너지가 모자랄 때만 상태가 된다. 에너지를 받으며 일하는 기계가 멈춤과 작동을 오가며 깜빡이지 않게 한다(WAILA의 "에너지 부족으로 중단"도 같다).
- 자동 제작기의 재료 부족에는 모자란 재료가 함께 나온다("재료 부족: 화약 ×2").
- 기계는 각자 **언제부터 이 상태인지**를 가진다.

## 3. 정지 알림

- **조건**: 알릴 상태(에너지·출력·연료 부족)가 **30초** 이어지면 알린다. 같은 정지는 해결될 때까지 한 번만 알린다.
- **내용**: 채팅에 한 줄. `§c[정지] 분쇄기 (12, 64, 8) 출력 슬롯 부족으로 중단`. 상태 문구는 WAILA와 같은 글을 쓰고, 좌표와 이름만 더한다.
- **받는 사람**: 섬에 있는 플레이어 중 알림을 켠 사람. 알림은 기본으로 꺼져 있고 통계 화면에서 켜고 끈다(계정이 아니라 세이브의 플레이어별 설정).
- **소리**: 알림과 함께 약한 경고음 하나.
- **폭주 막기**: 한 번에 세 줄까지 알리고 나머지는 "외 N대"로 묶는다. 같은 기계의 알림 사이에는 최소 5분을 둔다.
- **해결**: 알렸던 기계가 작동으로 돌아오면 조용히 복구로 센다(업적용).

## 4. 화면: `/통계`

메뉴 → 생산 통계, 또는 `/통계`(`/stats`). 세 쪽이 있다.

1. **생산량**: 아이템 칸 격자(아이템 아이콘, 아래 오른쪽에 분당 개수). 마우스를 올리면 "이름 / 분당 N개(최근 5분) / 1분 N · 15분 N / 누적 N개". 많이 만드는 순으로 보이고, 위에 "분당 N개 · 종류 M가지"가 있다.
2. **에너지**: 발전과 사용(RE/t), 에너지 셀, 발전기 수와 작동 수, 부족 경고.
3. **정지 목록**: 정지 중인 기계를 오래된 순으로 버튼으로 보인다. 버튼은 `이름 (x, y, z)`와 이유·지속 시간. 누르면 그 기계 옆으로 이동해 그 기계를 바라본다(소유 청크 안, 안전한 자리). 목록에는 지금 정지한 기계(에너지·출력·연료 부족)만 있다. 위에서 알림 켜고 끄기.

## 5. 업적

카운터([01 §5](01-platform.md))와 직접 주는 업적으로 만든다. 칭호는 공장의 분주함을 놀리는 말맛으로 쓴다.

| 키 | 단계 | 세는 때 |
|---|---|---|
| `made_items` 기계 생산 | 100 / 1천 / 1만 / 10만 / 100만 / 1천만 | 초마다 생산 증가분 |
| `made_ingot` 주괴 | 100 / 1천 / 1만 / 10만 | 주괴를 만들 때 |
| `made_dust` 가루 | 100 / 1천 / 1만 / 10만 | 가루를 만들 때 |
| `made_gem` 보석 | 50 / 500 / 5천 | 다이아·에메랄드·석영·청금석·자수정 |
| `made_wood` 원목·묘목 | 100 / 1천 / 1만 | 벌목기 |
| `made_block` 돌·흙 블록 | 1천 / 1만 / 10만 | 조약돌·자갈·모래·흙 |
| `alerts_seen` 정지 알림 | 1 / 10 / 50 / 200 | 알림을 받을 때 |
| `stall_fixed` 정지 해결 | 1 / 10 / 50 / 200 | 알린 기계가 돌아올 때 |
| `stats_open` 통계 화면 | 1 / 25 / 250 | 화면을 열 때 |
| 분당 생산 기록 | 60 / 300 / 1천 / 3천 / 1만 | 한 분의 합이 넘을 때(직접) |
| 발전 기록 | 100 / 500 / 2천 / 1만 RE/t | 한 분의 평균이 넘을 때(직접) |
| 무정지 운영 | 30분 / 1시간 / 3시간 | 작동 기계 10대 이상으로 알림 없이(직접) |

## 6. 구현 위치와 성능

- `stats.go`: `prodStats`(1분 칸 15개와 누적), `session.stats`, `machineState.emit`(출력 + 기록), 통계 화면.
- `monitor.go`: 기계 목록(`session.machines`), 상태 판정(`machineState.status`), 알림 상태기계, 알림 설정.
- 기계의 출력 지점은 `put(출력)` 대신 `emit`을 쓰고, 출력이 막히는 지점은 `roomFor`로 막힘을 기록한다. 발전·소비는 20틱마다 모아 기록한다.
- 기록은 맵 더하기뿐이다. 계정 카운터와 업적은 **초마다 증가분을 한 번에** 넘기므로 기계마다 계정 잠금을 잡지 않는다. 상태 판정과 알림은 초마다 기계 목록을 한 번 도는 일이다(기계 150대 안팎).
- 기계 목록은 틱할 때 갱신하고 부술 때 지운다. 10초 넘게 틱이 없는 기계는 건너뛴다.
