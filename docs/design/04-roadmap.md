# 04. 로드맵

각 단계는 실제 클라이언트로 플레이 확인이 가능한 상태로 마무리한다.

| 단계 | 내용 | 확인 |
|---|---|---|
| M0. 기술 검증 | 다중 월드 이동, 커스텀 블록·블록 엔티티·틱, 인벤토리 직렬화, 보이드 아이템 감지, 애드온 방식 | [결과](../tech/m0-verification.md), [애드온](../tech/addon.md) |
| M1. 플랫폼 뼈대 | SQLite, 계정, 서버 안내, 로비, 세이브 슬롯 3개 → 인스턴스 입장/퇴장, 상태 저장·복원, 호스트 기준 활성화/종료, 인스턴스 시간 | 두 세이브를 오가도 인벤토리가 섞이지 않는다 |
| M2. 협동 | 친구, 초대 코드, 친구 초대, 참여자 관리, 인벤토리 열람(InvSee) | 두 명이 같은 세이브에서 플레이한다 |
| M3. 스카이블록 초반 | 3×3×3 섬, 손작업 자원, 연구, 발전과제, 퇴비통·배럴·체·망치, 서랍, 섬 확장, 안전 장치 | [실기 기록](../tech/playtest-log.md) |
| M4. 자동화 | 호퍼·아이템 이동, 에너지와 도관, 분쇄기·자동 체·채굴기·수확기 | 손 안 대고 돌아가는 첫 생산 라인 |
| M5. 진행 확장 | 금속·합금로·에너지 셀, 액체 네트워크, 몬스터 시뮬레이터, 차원 게이트 웨이브 | [07](07-progression-expansion.md) |
| M6. 저장·장비 | 스토리지 컨트롤러, 장비 제작(팅커스풍), 마법 식물 | [08](08-storage-gear-magic.md) |
| M7. 계정 요소 | 칭호, 이름 색, 업적 | [01 §5](01-platform.md) |

## 앞으로의 방향

- 마나와 자연의 기운을 다루는 마법 콘텐츠, 동물 소환.
- 발효기·균사체 같은 흙 생산 확장, 서랍·도관 필터와 우선순위.
- 웨이브 단계 표시(허공 글자)와 보스 체력바.
- 공동 호스트, 두 번째 게임 종류(게임 선택 UI 노출).
