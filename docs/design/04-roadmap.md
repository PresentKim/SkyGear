- 마나와 자연의 기운을 다루는 마법 콘텐츠, 동물 소환.
- 발효기·균사체 같은 흙 생산 확장, 서랍·도관 필터와 우선순위.
- 웨이브 단계 표시(허공 글자)와 보스 체력바.
- 공동 호스트, 두 번째 게임 종류(게임 선택 UI 노출).
