# 04. 로드맵

각 단계는 실제 클라이언트로 플레이 확인이 가능한 상태로 마무리한다.

| 단계 | 목표 | 완료 기준 |
|---|---|---|
| M0. 기술 검증 ✅ | 다중 월드 이동, 커스텀 블록+블록 엔티티+틱, 인벤토리 직렬화, 보이드 아이템 감지, 애드온 방식 | [결과](../tech/m0-verification.md), [애드온](../tech/addon.md) |
| M1. 플랫폼 뼈대 ✅ | SQLite, 계정, 서버 안내, 로비, 세이브 슬롯 3개 → 인스턴스 입장/퇴장, 상태 저장·복원, 호스트 기준 활성화/종료, 인스턴스 시간 | 두 세이브를 오가도 인벤토리가 섞이지 않음 |
| M2. 드래곤팩토리 최소 루프 ✅ ([실기 기록](../tech/playtest-log.md)) | 기본 코어(주기 생성, 유일성, 재발급), 레벨 1~5 메인 미션, 납품함, 상점(재고·재입고·1회성, 매입 예산), 돈·수표, 청크 구매, 보이드 복귀, 분실물 보관함, 기본 서랍(조작·표시·호퍼) | 새 세이브에서 레벨 5까지 플레이 가능 |
| M3. 협동 ✅ | 친구, 초대 코드, 친구 초대, 참여자 관리, 인벤토리 열람(InvSee, 엔티티 상자) | 두 명이 같은 세이브에서 플레이 |
| M4. 자동화 ✅ | 분쇄기·체·판매함·자동 자원 채굴기(동력 없음, 엔티티 상자 화면, 호퍼 연동), 레벨 6~7, 운영자 도구 | 손 안 대고 돌아가는 첫 생산 라인 |
| M5. 긴급 미션 · 코어 강화 (구현됨, 실기 전) | 긴급 매입, 코어 기반(1~4티어 코어 + 코어 기반·둘레 레시피, 코어 도감·발견), 티어별 속도 강화 | 시나리오 `m5.sh` |
| M6. 시대 확장 (2시대 코어·레벨만 초안) | 2번째 이후 코어와 기계, 레벨 콘텐츠 | |
| M7. 계정 요소 (초안) | 칭호, 치장, 업적 | 업적·칭호·이름 색 |
| S1~S6. 스카이블록 진행 개편 (컨셉) | 시작 섬·손작업 자원·발전과제·체 그물·발효기·차원 게이트·마법 식물 ([05](05-sky-progression.md) §6) | |
| 이후 | 공동 호스트, 두 번째 게임 종류(게임 선택 UI 노출) | |
