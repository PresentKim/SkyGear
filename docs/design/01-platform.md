# 01. 플랫폼: 접속 흐름 · 계정 · 세이브 · 인스턴스

## 1. 접속 흐름

```
접속 → (첫 접속) 서버 안내 → 로비
로비 → 세이브 슬롯 선택(1~3) → 인스턴스 입장
인스턴스 → /lobby 또는 메뉴 → 로비 (상태 저장)
```

1. **서버 안내**: 첫 접속 시 안내 폼(서버 소개, 기본 조작, 메뉴 여는 법)을 보여준다.
   이후에는 로비 메뉴의 "안내"로 다시 볼 수 있다. 안내 버전이 바뀌면 다시 노출한다.
2. **로비**: 모든 플레이어가 공유하는 허브 월드. 건축·전투 불가.
   로비 전용 인벤토리(메뉴 아이템: 세이브, 친구, 치장)를 쓰며 인스턴스 인벤토리와 분리된다.
3. **세이브 선택**: 계정당 세이브 슬롯 3개.
   - 빈 슬롯: "새 게임" → 이름 입력 → 생성
   - 사용 중 슬롯: 이름, 진행도(레벨), 경과 일수(인스턴스 날짜), 참여자 수 → 입장 / 이름 변경 / 삭제(확인 2회)
   - 별도 탭: **참여 중인 세이브**(초대받아 참여한 다른 호스트의 세이브). 호스트가 접속 중일 때만 입장 가능.
4. **입장**: 호스트가 입장하면 인스턴스를 활성화하고 이동한다.

### 게임 종류
- 플랫폼은 여러 게임 종류를 지원하는 구조로 개발하지만, **현재 사용자에게 게임 선택 단계를 보여주지 않는다.**
  유일한 게임 종류는 **드래곤팩토리**이며 세이브 슬롯은 게임 종류별로 구분해 저장한다(추후 게임 추가 대비).

## 2. 데이터 범위

| 범위 | 예시 |
|---|---|
| 계정 | 치장, 칭호, 친구 목록, 설정, 안내 확인 버전, 누적 통계 |
| 세이브(공유) | 월드 블록, 레벨, 미션 진행, 상점 상태, 코어 레코드, 인스턴스 시간, 분실물 |
| 세이브 × 플레이어 | 인벤토리, 위치, 체력/허기, 경험치, **돈**, 개인 통계 |

- 플레이어가 인스턴스를 나갈 때(로비 이동, 접속 종료, 인스턴스 종료, 서버 종료) 세이브 × 플레이어 상태를 저장하고,
  들어올 때 복원한다. 처음 들어오는 세이브면 게임의 초기 지급품을 준다.
- 돈은 세이브 안에서만 유효하며 플레이어별로 따로 가진다. 세부 규칙은 [02-dragonfactory.md](02-dragonfactory.md) §7.

## 3. 세이브와 인스턴스

인스턴스는 **싱글 플레이 게임 같은 경험**을 위한 것이다. 시간은 호스트가 있을 때만 흐른다.

- 세이브는 **호스트 계정**에 속한다. 게스트는 호스트의 세이브에 참여할 뿐 자기 슬롯을 쓰지 않는다.
- **활성화**: 호스트가 입장하면 인스턴스(월드)를 로드하고 인스턴스 시간이 흐르기 시작한다.
- **비활성화**: 호스트가 인스턴스를 나가면(로비 이동·접속 종료) 인스턴스를 종료한다.
  - 남아 있던 게스트는 상태를 저장한 뒤 로비로 이동시키고 안내 메시지를 보낸다.
  - 세이브를 저장하고 월드를 언로드한다. 인스턴스 시간과 모든 타이머(재입고, 긴급 미션 등)는 멈춘다.
- **게스트는 호스트 없이 입장할 수 없다.**
- **공동 호스트**(예정): 호스트 대신 인스턴스를 활성화할 수 있는 등급. 지금은 기능을 구현하지 않고,
  참여자 권한을 `host / cohost / guest` 등급으로 저장하고 "인스턴스 활성화 가능 여부"를 등급으로 판단하는 구조만 만들어 둔다.

### 인스턴스 시간
- 세이브마다 **인스턴스 시간**(활성화되어 있던 누적 시간)을 기록한다. 게임 내 주기(재입고, 매입 예산 회복, 분실물 보관 기간 등)는 모두 인스턴스 시간 기준이다.
- **인스턴스 하루**: 인스턴스 시간을 일정 길이로 나눈 단위. 세이브에 **경과 일수**로 기록하고, 하루가 넘어갈 때 일 단위 갱신(매입 예산 회복 등)을 처리한다.
- 하루의 길이는 설정값으로 두고, 인게임 흐름이 잡힌 뒤 조정한다(알케미 팩토리, 마인크래프트의 하루 길이 참고).

### 활성 영역
- 활성화된 인스턴스는 섬의 **소유 청크 전체**를 로드하고 틱을 돌린다(플레이어가 멀리 있어도 공장이 동작).
- 따라서 소유 청크 수는 서버 부하와 직결된다. 섬 확장은 쉽게 주지 않는다([02-dragonfactory.md](02-dragonfactory.md) §8).

## 4. 친구 · 초대

### 친구
- `친구 요청 → 수락` 방식의 상호 관계. 오프라인 플레이어에게도 요청 가능(다음 접속 시 알림).
- 친구 목록: 온라인 여부, 현재 위치(로비 / 인스턴스) 표시.
- 차단: 차단한 플레이어의 친구 요청·초대를 받지 않는다.

### 인스턴스 초대
1. **초대 코드**: 세이브마다 6자리 코드(예: `K7Q2MX`, 헷갈리는 0/O/1/I 제외). 로비에서 코드를 입력(메뉴 또는 `/join 코드`)하면 참여자로 등록되고, 호스트가 플레이 중이면 바로 입장.
   호스트가 재발급하면 이전 코드는 무효.
2. **친구 초대**: 인스턴스 안에서 온라인 친구를 골라 초대 → 받은 쪽은 알림 폼에서 수락 → 즉시 입장.

- 한 번 참여한 게스트는 세이브의 **참여자 목록**에 남는다.
- 세이브당 최대 인원: 초안 4명(호스트 포함).

### 참여자 관리
- 호스트는 참여자를 추방할 수 있고, 게스트는 스스로 탈퇴할 수 있다.
- 추방·탈퇴한 플레이어의 세이브 × 플레이어 데이터(인벤토리, 돈)는 **삭제하지 않고 세이브에 보관**한다.
- **인벤토리 열람(InvSee)**: 호스트는 현재 참여자와 추방·탈퇴한 플레이어를 포함한 **모든 플레이어의 인벤토리를 확인하고 꺼내거나 넣을 수 있다.**
  대상이 그 세이브 안에 있으면 실시간 인벤토리를, 아니면 저장된 인벤토리를 편집한다(편집 중에는 대상이 입장할 수 없음).
  엔티티 상자 화면에서 인벤·핫바·갑옷·보조손·엔더상자를 직접 옮긴다. 같은 세이브 안의 대상은 실시간, 그 외에는 저장된 상태를 잠그고 편집한다([chestui](../tech/chestui.md)).
- 호스트 메뉴: 로비의 내 세이브 → 초대 코드 / 참여자 관리, 세이브 안에서 `/invite`, `/members`.
- 친구 초대는 10분 동안 유효하다. 로비에 있으면 바로 수락 창이 뜨고, 아니면 로비 메뉴의 '받은 초대'에 남는다.

## 5. 계정 요소

- **칭호**: 업적·이벤트로 획득, 채팅/이름표 앞에 표시. 하나를 장착.
- **치장**: 이름표 색, 채팅 색, 파티클 등 밸런스에 영향 없는 요소.
- 구현(초안, [확인 필요](open-questions.md)):
  - 업적은 계정 단위로 한 번씩 얻는다(`internal/account`, DB `achievements`). 게임이 업적을 등록하고 조건이 되면 준다(`account.Grant`).
  - 업적 대부분이 칭호를 하나씩 연다. 로비 메뉴 → 칭호·치장에서 칭호 하나와 이름 색을 고른다. 채팅(`<[칭호] 이름> …`)과 이름표에 보인다.
  - 이름 색: 기본·노랑·하늘·초록은 처음부터, 금색·분홍은 업적 3개, 빨강·파랑은 6개부터. 파티클 등은 아직 없다.
  - 드래곤팩토리 업적(`achievements.go`): Lv.3·5·8 달성, 모든 미션 완료, 첫 기계 설치, 긴급 매입 다 채우기, 청크 10개, 2티어 이상 코어 설치, 소지금 100,000G. 레벨·긴급 매입은 그때 세이브에 있는 모두가 얻는다.
