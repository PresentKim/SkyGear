# 05. 스카이블록 진행 설계

## 1. 목표

**스카이팩토리 3**·**ATM10 Sky** 모드팩을 플레이한 경험을 Bedrock 서버(서버팩)로 옮긴다. 몬스터 게이트는 **스카이팩토리 5**를 참고한다.

- 아무것도 없는 하늘섬에서 손으로 시작해, 자원을 하나씩 해금하며 자동화로 넘어간다.
- 플레이어가 할 일은 **발전과제**가 힌트로 안내한다.

## 2. 시작

- 섬: **3×3×3 하늘섬**(가장 아래층은 베드락), **가운데에 나무 한 그루**.
- 처음 열린 조합법: **참나무 판자, 조합대, 연구대(조합대 2개)** 셋. 나머지는 연구([02 §9](02-dragonfactory.md)).
- 첫 목표: 나무를 캐 원목 → 판자 → 조합대 → 연구대.
- **`/묘목`**: 묘목을 모두 잃어도 막히지 않도록 10분에 한 번 묘목을 받는다.

## 3. 초반(손작업) 진행

| 순서 | 할 일 | 얻는 것 |
|---|---|---|
| 1 | 나무 캐기 → 조합대·연구대 | 원목, 판자 |
| 2 | 연구대에서 **막대기** 연구 | 막대기 조합법 |
| 3 | **막대기로 잔디·흙 우클릭** | **돌 돌멩이**(다른 돌멩이는 체에서) |
| 4 | 돌멩이 4개 조합 | 조약돌 1개 |
| 5 | 나무를 직접 키운다. **웅크리기를 반복하면 주변 묘목이 자란다** | 원목 |
| 6 | **돌 이상 도끼로 원목 우클릭** → 껍질 벗긴 원목, 확률로 **나무껍질 섬유** 1~2개 | 나무껍질 섬유 |
| 7 | 나무껍질 섬유 3개를 조합대에 한 줄로 | **실 3개** |
| 8 | **망치**로 분해: 조약돌 → 자갈 → 모래 → **먼지** | 단계마다 체 재료 |
| 9 | **체**로 자갈·모래·먼지를 거른다(재료마다 드롭 표) | 광물 조각 등 |
| 10 | **체 메쉬 등급**: 실 → 부싯돌 → 철 → 금 → 다이아몬드 → 네더라이트. 등급이 오를수록 목표 자원 확률이 오르고 새 자원이 나온다 | 더 나은 체 |
| 11 | **퇴비통**과 **배럴**로 흙과 물을 만든다 | 흙, 물 |
| 12 | 철 이후 기계·에너지·도관으로 자동화한다 | [06](06-power-and-conduits.md), [07](07-progression-expansion.md) |

자원을 차례차례 해금하며, 각 단계마다 발전과제가 힌트를 준다.

## 4. 생물

- **동물·몬스터는 자연 스폰되지 않는다.** 몬스터는 차원 게이트의 웨이브와 몬스터 시뮬레이터로만 만난다.
- 동물은 이후 **마법 식물** 콘텐츠와 함께 **자연의 기운**을 조합해 만든다.

### 4.1 차원 게이트 (몬스터 웨이브, 스카이팩토리 5 참고)
- 자원을 어느 정도 모으면 **차원 게이트 고정 앵커**(블록)를 설치한다.
- 앵커를 우클릭해 **웨이브 단계**를 고른다. 고르면 앵커 위에 **게이트**(3칸 너비의 둥근 평면 엔티티, 천천히 돈다)가 연 사람 쪽을 향해 열리고, 단계마다 색과 무늬가 다르다(`gateportal.go`, 팩 `entity/gate_portal.entity.json`, 텍스처 `gate_portal_<단계>`). 그 단계의 몬스터가 섞인 순서로 0.2초에 한 마리씩 게이트에서 나와 게이트가 향한 쪽으로 몇 걸음 걸어 나온 뒤 플레이어를 쫓는다. 정해진 시간 안에 모든 몬스터(아직 나오지 않은 것 포함)를 잡아야 하고, 소탕하면 **다음 단계**가 열린다. 웨이브가 끝나면 게이트가 닫힌다.
- 5단계 같은 고비에 **엘리트·보스급** 구성이 나와 더 강해져야 할 이유를 준다. 단계마다 구성이 다르다(좀비만, 섞어서, 한꺼번에 등).
- 몬스터는 자기 드롭과 확률로 **에센스**를 떨군다. 에센스는 몬스터 시뮬레이터와 마법 식물의 재료이고, 나중에는 동물 소환 알의 재료가 된다.
- 단계표와 보상: [07 §7](07-progression-expansion.md).

## 5. 기술 구현

| 항목 | 구현 |
|---|---|
| 발전과제 | Bedrock에는 서버가 쓸 수 있는 발전과제가 없어 직접 만든다. 조건 추적 + 토스트 알림 + 폼 트리 화면 + 다음 할 일 힌트 |
| 3×3×3 섬 + 나무 | 새 세이브 생성 코드 |
| `/묘목` 10분 쿨타임 | 세이브별 마지막 지급 시각 |
| 막대기로 흙 우클릭 → 돌멩이 | 커스텀 아이템(돌멩이 여러 종) + 아이템 사용 처리. 4개 → 돌 블록은 연구가 여는 조합법 |
| 웅크리기로 나무 성장 | 웅크리기 이벤트에서 주변 묘목에 성장(뼛가루 효과) |
| 도끼로 원목 벗기기 + 섬유 | 원목 벗기기 뒤 확률 드롭. 섬유·실은 커스텀 아이템 |
| 먼지·체 메쉬 등급 | 먼지 블록, 체의 메쉬 칸, 메쉬별 드롭 표 |
| 차원 게이트 몬스터 | Dragonfly에는 몹과 AI가 없어 직접 만든다: 클라이언트에는 바닐라 모습(`minecraft:zombie` 등)으로 보내고 이동·추적·공격·체력·피격·죽음·드롭을 서버가 계산한다. 섬이 단순해 길찾기는 직선 + 점프로 충분하다 |

## 6. 앞으로의 방향

- 발효기·균사체 같은 흙 생산 확장.
- 마법 식물([08 §3](08-storage-gear-magic.md))의 자연의 기운으로 동물 소환 알을 만든다.
