# 05. 스카이블록 진행 개편 (컨셉 초안, 13차 뒤)


## 1. 목표

**스카이팩토리 3**·**ATM10 Sky** 모드팩을 플레이한 경험을 Bedrock 서버(서버팩)로 옮긴다. 몬스터 게이트는 **스카이팩토리 5**를 참고한다.

- 아무것도 없는 하늘섬에서 손으로 시작해, 자원을 하나씩 해금하며 자동화로 넘어간다.
- 플레이어가 할 일은 **발전과제(어드밴스먼트)** 가 힌트로 안내한다. 퀘스트 북은 필요하면 나중(우선순위 아님).

## 2. 시작

- 섬: **3×3×3 하늘섬**(가장 아래층은 베드락), **가운데에 나무 한 그루**.
- 처음 열린 조합법: **참나무 판자, 조합대, 연구대(조합대 2개)** 셋뿐. 나머지는 연구([02 §3.4](02-dragonfactory.md)).
- 첫 목표 안내: 나무를 캐 원목 → 판자 → 조합대 → 연구대.
- **안전장치 `/묘목`**: 묘목을 모두 잃어도 막히지 않게, 10분에 한 번 묘목을 다시 받는다.

## 3. 초반(손작업) 진행

| 순서 | 할 일 | 얻는 것 |
|---|---|---|
| 1 | 나무 캐기 → 조합대·연구대 | 원목, 판자 |
| 2 | 연구대에서 **막대기** 연구(첫 연구로 설계) | 막대기 조합법 |
| 3 | **막대기로 잔디·흙 우클릭** | 여러 종류의 **돌멩이**(무작위) |
| 4 | 돌멩이 4개 조합 | 조약돌 1개 |
| 5 | 나무를 직접 키움. **웅크리기를 반복하면 주변 나무(묘목)가 자람**(불쾌감 줄이기) | 원목 |
| 6 | **돌 이상 도끼로 원목 우클릭** → 껍질 벗긴 원목, 확률로 **나무껍질 섬유** 1~2개 | 나무껍질 섬유 |
| 7 | 나무껍질 섬유 조합 | **실** |
| 8 | **망치**로 분해: 돌 → 자갈 → 모래 → **먼지** | 단계마다 체 재료 |
| 9 | **체**로 자갈·모래·먼지를 거름(재료마다 드롭 표) | 광물 조각 등 |
| 10 | **체 그물 등급**: 실 → 철 → 금 → 다이아 → 네더라이트. 등급이 오를수록 쓸모없는 결과는 줄거나 사라지고 광물 등 목표 자원 확률이 오른다 | 더 나은 체 |
| 11 | **발효기**로 흙 생산 | 흙 |
| 12 | 이후 곰팡이·버섯 같은 **균사체**로 흙을 **마녀의 흙** 같은 물질로 | 다음 자원 |

자원을 이렇게 차례차례 해금한다. 각 단계는 발전과제가 힌트를 준다.

## 4. 생물

- **동물·몬스터는 자연 스폰되지 않는다.**
- 동물: 나중에 **마법 식물** 콘텐츠와 함께, **자연의 기운**을 조합해 만든다.

### 4.1 차원 게이트 (몬스터 웨이브, 스카이팩토리 5 참고)
- 지옥문과 다른 개념. 자원을 어느 정도 모으면 **차원 게이트**를 설치해 몬스터 게이트를 활성화한다.
- 활성화하면 **웨이브**가 시작되고, 정해진 시간 안에 모두 잡아야 한다. 시간 안에 소탕하면 **다음 단계**가 열린다.
- 일정 주기(예: 5·10웨이브)마다 **엘리트·보스**가 나와, 더 강해져야 할 이유를 준다.
- 웨이브 단계마다 구성이 다르다: 슬라임만, 좀비만, 섞어서, 한꺼번에 우르르, 차례대로.
- 더 좋은 보상의 몬스터를 부르려면 웨이브를 깨서 **등급**을 올린다.
- 게이트를 클릭하면 **웨이브 단계를 고른다.** 고른 단계는 서랍처럼 **허공 글자·아이템**으로 보인다.
- 몬스터는 등급이나 종류에 맞는 **에센스**를 확률로 떨군다. 에센스로 아이템을 만들고, 나중에는 마법 재료와 조합해 **동물 에센스 → 동물 소환 알**을 만든다(기획 중).

## 5. 기술 검토

| 항목 | 가능 여부 | 메모 |
|---|---|---|
| 발전과제 | 직접 만든다 | Bedrock 에는 서버가 쓸 수 있는 발전과제(자바 어드밴스먼트) 화면·알림이 없다. 지금의 업적(`internal/account`)을 넓혀 조건 추적 + 토스트 알림 + 폼/JSON UI 트리 화면 + 다음 할 일 힌트로 만든다 |
| 3×3×3 섬 + 나무 | 가능 | 새 세이브 생성 코드만 바꾼다 |
| `/묘목` 10분 쿨타임 | 가능 | 세이브(또는 계정)별 마지막 지급 시각 |
| 막대기로 흙 우클릭 → 돌멩이 | 가능 | 커스텀 아이템(돌멩이 여러 종) + 아이템 사용 처리. 4개 → 조약돌은 커스텀 조합법(연구 대상) |
| 웅크리기로 나무 성장 | 가능 | 웅크리기 이벤트에서 주변 묘목에 성장(뼛가루 효과) |
| 도끼로 원목 벗기기 + 섬유 | 가능 | Dragonfly 의 원목 벗기기 뒤 확률 드롭. 섬유·실은 커스텀 아이템, 텍스처는 팩 |
| 먼지·체 그물 등급 | 가능 | 먼지 블록(커스텀), 체에 그물 칸 추가, 그물별 드롭 표 |
| 발효기·균사체·마녀의 흙 | 가능 | 새 기계·블록. 시간 기반 |
| 몹 자연 스폰 없음 | 이미 그렇다 | **Dragonfly 에는 몹(좀비·슬라임 등)과 AI 자체가 없다.** |
| 차원 게이트 몬스터 | 직접 만든다(큰 작업) | 몹을 Go 로 구현: 클라이언트에는 바닐라 모습(`minecraft:zombie` 등, 요정이 알레이로 보이는 방식)으로 보내고 이동·추적·공격·체력·피격·죽음·드롭을 서버가 계산. 섬이 단순해 길찾기는 직선 + 점프 정도로 시작 |
| 웨이브 단계 허공 표시 | 가능 | 서랍의 허공 글자·아이템 홀더 |

## 6. 단계 제안

1. **시작 개편**(완료): 3×3×3 섬과 나무, 기본 조합법 셋(연구대 = 조합대 2개), `/묘목`, 웅크리기 성장.
2. **손작업 자원**(완료, [02 §3.3](02-dragonfactory.md)): 돌멩이·조약돌 조합, 나무껍질 섬유·실, 망치 분해 체인(먼지까지), 체 드롭 표 정리.
3. **발전과제** 뼈대와 초반 발전과제(힌트)(완료, [02 §3.5](02-dragonfactory.md)).
4. 체 그물 등급, 발효기(흙), 균사체·마녀의 흙.
5. 차원 게이트: 몹 구현(좀비·슬라임부터), 웨이브·타이머·단계 설정·허공 표시, 엘리트·보스, 에센스.
6. 마법 식물·자연의 기운·동물 소환 알.
