# 05. 스카이블록 진행 설계

## 1. 목표

**스카이팩토리 3**·**ATM10 Sky** 모드팩을 플레이한 경험을 Bedrock 서버(서버팩)로 옮긴다. 몬스터 게이트는 **스카이팩토리 5**를 참고한다.

- 아무것도 없는 하늘섬에서 손으로 시작해, 자원을 하나씩 해금하며 자동화로 넘어간다.
- 플레이어가 할 일은 **발전과제**가 힌트로 안내한다.

## 2. 시작

- 섬: **3×3×3 하늘섬**(가장 아래층은 베드락), **가운데에 나무 한 그루**.
- 처음 열린 조합법: **참나무 판자, 제작대, 연구대(제작대 2개)** 셋. 나머지는 연구([02 §9](02-skygear.md)).
- 첫 목표: 나무를 캐 원목 → 판자 → 제작대 → 연구대.
- **`/묘목`**: 묘목을 모두 잃어도 막히지 않도록 10분에 한 번 묘목을 받는다.

## 3. 초반(손작업) 진행

| 순서 | 할 일 | 얻는 것 |
|---|---|---|
| 1 | 나무 캐기 → 제작대·연구대 | 원목, 판자 |
| 2 | 연구대에서 **막대기** 연구 | 막대기 조합법 |
| 3 | **막대기로 잔디·흙 우클릭** | **돌 돌멩이**(다른 돌멩이는 체에서) |
| 4 | 돌멩이 4개 조합 | 조약돌 1개 |
| 5 | 나무를 직접 키운다. **웅크리기를 반복하면 주변 묘목이 자란다** | 원목 |
| 6 | **도끼로 원목 우클릭** → 껍질 벗긴 원목, 확률로 **나무껍질 섬유** 1~2개 | 나무껍질 섬유 |
| 7 | 나무껍질 섬유 4개를 네모로 놓으면 종이 2개, 남는 섬유는 화로 연료(막대기만큼) | 종이 |
| 8 | **크룩**으로 나뭇잎을 부숴 **누에**를 얻고, 누에를 나뭇잎에 써서 **감염된 나뭇잎**을 만든다. 감염된 나뭇잎을 부수면 실 | 실(체·메쉬 재료) |
| 9 | **망치**로 분해: 조약돌 → 자갈 → 모래 → **먼지** | 단계마다 체 재료 |
| 10 | **체**로 자갈·모래·먼지를 거른다(재료마다 드롭 표) | 광물 조각 등 |
| 11 | **체 메쉬 등급**: 실 → 부싯돌 → 철 → 금 → 다이아몬드 → 네더라이트. 등급이 오를수록 목표 자원 확률이 오르고 새 자원이 나온다 | 더 나은 체 |
| 12 | **퇴비통**과 **배럴**로 흙과 물을 만든다 | 흙, 물 |
| 13 | 철 이후 기계·에너지·도관으로 자동화한다 | [06](06-power-and-conduits.md), [07](07-progression-expansion.md) |

자원을 차례차례 해금하며, 단계마다 발전과제가 힌트를 준다.

## 4. 생물

- **동물·몬스터는 자연 스폰되지 않는다.** 몬스터는 이차원([17](17-dimension.md))에서만 만나고, 섬에서는 몬스터 시뮬레이터가 그 드롭을 만든다.
- 동물은 이후 **마법 식물** 콘텐츠와 함께 **자연의 기운**을 조합해 만든다.

### 4.1 이차원 (몬스터 사냥)
- 요정의 에메랄드로 만든 **이차원 텔레포트석**으로 들어가는, 들어갈 때마다 새로 만들어지는 평지 사냥터다. 섬에 놓는 게이트는 없다.
- 몬스터 한 종을 골라 뱀파이어 서바이벌식으로 사냥한다: 같은 몬스터의 여러 변종이 갈수록 강해지며 몰려오고, 섬에서 만든 **보구**와 판 안의 레벨업 강화로 버틴다.
- 몬스터마다 섬의 기록(최단 기록, 누적 처치)과 별 셋(클리어, 기준 시간, 누적 처치)이 남고, 별 셋을 모으면 다음 몬스터를 연다.
- 몬스터 **에센스**는 이차원에서만 나온다: 사냥 보상과, 클리어한 몬스터를 등록한 **이차원 에센스 수집기**(최단 기록에 비례). 에센스는 몬스터 시뮬레이터·마법 체·마법 꽃 씨앗·보구의 재료다.
- 전체 설계: [17](17-dimension.md).

## 5. 기술 구현

| 항목 | 구현 |
|---|---|
| 발전과제 | Bedrock에는 서버가 쓸 수 있는 발전과제가 없어 직접 만든다. 조건 추적 + 토스트 알림 + 폼 트리 화면 + 다음 할 일 힌트 |
| 3×3×3 섬 + 나무 | 새 세이브 생성 코드 |
| `/묘목` 10분 쿨타임 | 세이브별 마지막 지급 시각 |
| 막대기로 흙 우클릭 → 돌멩이 | 커스텀 아이템(돌멩이 여러 종) + 아이템 사용 처리. 4개 → 돌 블록은 연구가 여는 조합법 |
| 웅크리기로 나무 성장 | 웅크리기 이벤트에서 주변 묘목을 키운다(뼛가루 효과) |
| 도끼로 원목 벗기기 + 섬유 | 원목 벗기기 뒤 확률 드롭. 섬유는 커스텀 아이템, 종이는 바닐라. 섬유는 연료(100틱)이기도 하다 |
| 먼지·체 메쉬 등급 | 먼지 블록, 체의 메쉬 칸, 메쉬별 드롭 표 |
| 이차원 몬스터 | Dragonfly에는 몹과 AI가 없어 직접 만든다: 클라이언트에는 바닐라 모습(`minecraft:zombie` 등)으로 보내고 이동·추적·공격·체력·피격·죽음·드롭을 서버가 계산한다. 사냥터가 평지라 길찾기는 직선 + 점프로 충분하다 |

## 6. 앞으로의 방향

- 발효기·균사체 같은 흙 생산 확장.
- 마법 식물([08 §3](08-storage-gear-magic.md))의 자연의 기운으로 동물 소환 알을 만든다.
