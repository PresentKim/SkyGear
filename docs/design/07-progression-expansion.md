# 07. 진행 확장: 금속·합금·기계 (스카이팩토리 3 + ATM10 To the Sky 조합)

> 상태: **초안, 구현 진행 중.** 두 모드팩을 BE 로 옮기는 큰 틀은 [05](05-sky-progression.md). 여기서는 05 의 4번 이후(체 그물 등급 다음)를 구체적인 기계·재료·연구로 쪼갠다. 수치는 전부 초안이고 [open-questions](open-questions.md)의 밸런싱 표를 따른다.

## 1. 두 모드팩에서 가져올 뼈대

웹 검색으로 얻은 것은 적다(ATM10 To the Sky 는 "300개 이상 모드, 체질과 자동화로 시작해 Mekanism·Applied Energistics 2·Create·Thermal 로 간다, 마지막 목표는 ATM Star"). 나머지는 두 팩을 해 본 지식으로 정리한다.

| 단계 | 스카이팩토리 3 | ATM10 To the Sky | 이 서버에서의 대응 |
|---|---|---|---|
| 손작업 | Ex Nihilo 체·망치·돌멩이 | 같음(Ex Nihilo Sequentia) | **구현됨**(05 §3) |
| 광물 | 체에서 구리·주석·납·은·니켈·알루미늄 조각 | 체에서 광물 조각, 더 좋은 그물일수록 더 많이 | 철·금·구리 **구현됨**, **주석·납·은·니켈 추가**(§2) |
| 광석 두 배 | 분쇄기로 가루 → 화로(Thermal 분쇄기, Tinkers 제련소) | Mekanism 광석 가공(3배~5배) | **분쇄기: 조각 → 가루 2개 → 화로**(§3) |
| 합금 | 청동·전자·인바·강철(Thermal 유도 제련기, Tinkers) | 같음(Mekanism·Thermal) | **합금로**(에너지, 입력 2칸)(§4) |
| 에너지 | Thermal 다이나모, 에너지 셀, 덕트 | Mekanism·Powah 발전기, 에너지 큐브 | 연소 발전기 **구현됨**, **에너지 셀**(§5), 더 나은 도관 등급 |
| 액체 | 도가니(Ex Nihilo)로 용암, Thermal 액체 덕트 | 도가니·Mekanism 파이프 | 액체 도관 블록은 있음, **도가니**(§6) |
| 자동화 | Thermal/Forestry 기계, 호퍼 | Create·Industrial Foregoing 자동 기계 | 자동 체·채굴기·수확기 **구현됨**, 기계 추가 |
| 저장 | 서랍, Thermal 상자 | AE2 ME 시스템 | 서랍 **구현됨**, 이후(§8) |
| 전투 | 몬스터 게이트(SkyFactory 5) | 몬스터 팜 | **차원 게이트**는 별도 큰 작업(05 §4.1) |

## 2. 금속

새 금속은 철·금·구리처럼 **체에서 나오는 원석 조각**으로 시작한다. 모두 `OreChunk{Ore}` / `MetalDust{Metal}` / `Ingot{Metal}` 한 벌의 표로 정의한다(`metals.go`).

| 금속 | 얻는 곳 | 쓰임 |
|---|---|---|
| 철·금·구리 | 기존 | 기존 |
| **주석** | 돌 그물부터 자갈 | 청동(구리 3 + 주석 1) |
| **납** | 철 그물부터 자갈·모래 | 인바 재료, 이후 기계 틀 |
| **은** | 금 그물부터 모래·자갈 | 전자(금 + 은) |
| **니켈** | 금 그물부터 자갈 | 인바(철 2 + 니켈 1) |

체 표는 그물이 좋을수록 확률이 오르는 기존 규칙(`meshBoost`, `meshExtra`)을 따른다.

## 3. 광석 두 배

`원석 조각` → **분쇄기** → **가루 2개** → **화로** → 주괴 2개(조각 하나당). 철·금·구리 조각은 기존처럼 4개를 합쳐 광석 블록(화로)으로도 되지만, 분쇄기를 쓰면 같은 조각으로 두 배의 주괴를 얻는다(스카이팩토리 3 의 분쇄기, ATM 의 2배 가공). 새 금속은 광석 블록이 없어서 **가루 → 화로**가 유일한 길이다(조각을 화로에 직접 굽는 것도 주괴 1개).

## 4. 합금로

에너지(RE)로 도는 기계. 입력 칸 2개 → 출력 1칸. 조합법은 아래(초안). 입력은 호퍼·도관이 어느 칸이든 넣고 출력은 어느 면으로든 꺼낸다.

| 결과 | 재료 |
|---|---|
| 청동 주괴 ×4 | 구리 주괴 3 + 주석 주괴 1 |
| 전자 주괴 ×2 | 금 주괴 1 + 은 주괴 1 |
| 인바 주괴 ×3 | 철 주괴 2 + 니켈 주괴 1 |
| 강철 주괴 ×1 | 철 주괴 1 + 석탄 4 |

## 5. 에너지 확장

- **에너지 셀**: 에너지를 모아 두는 블록(Thermal 에너지 셀). 도관으로 받고 내보낸다.
- **도관 2·3단계**: 강화 = 기본 도관 + 전자 주괴, 엔더 = 강화 도관 + 강철 주괴 + 다이아몬드(초안). 속도는 이미 정의됨(에너지 240/960 RE/t 등).

## 6. 도가니와 액체

Ex Nihilo 의 도가니: 열원(횃불·화로·용암) 위에서 조약돌을 녹여 용암, 잎·묘목을 녹여 물을 만든다. 양동이로 꺼낸다. 용암이 있어야 이후 기계·제련이 열린다.

## 7. 연구·발전과제

새 기계와 재료마다 연구와 발전과제를 둔다(연구 비용은 직전 단계 재료). 개략: `주석`·`납`·`은`·`니켈`(체 그물) → `광석 두 배`(분쇄기 + 가루) → `합금로` → 각 합금 → `에너지 셀`·`도관 업그레이드`. 발전과제는 연구와 같은 순서로 힌트를 준다.
