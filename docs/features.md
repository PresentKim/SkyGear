# 기능 목록

지금 서버에 있는 기능이다. 자세한 기획은 [docs/design](design/README.md), 기술 문서는 [docs/tech](tech).

## 플랫폼

- 첫 접속 시 서버 안내, 게임 입장기 모양의 로비(메인 메뉴: 싱글 플레이·멀티 플레이·친구·칭호·치장·도움말)
- 계정당 세이브 슬롯 3개: 왼쪽 슬롯 목록과 오른쪽 동작(새 게임 / 입장 / 초대 코드 / 참여자 관리 / 이름 변경 / 삭제 2회 확인)
- 세이브마다 별도 월드(인스턴스). 호스트가 들어오면 활성화, 나가면 종료
- 세이브별 인벤토리·체력·허기·경험치·효과·위치 저장과 복원
- 인스턴스 시간과 경과 일수(호스트가 있을 때만 흐름), 자동 저장, DB·월드 자동 백업
- 낙하 피해 없음, 사망 시 인벤토리 유지
- 메뉴는 Ore UI(DDUI) 화면, 로비는 닫히지 않는 메인 화면(프로필, 세이브 카드와 섬으로 출발, Esc 시스템 메뉴)
- 한국어·영어(클라이언트 언어를 따른다)

## 협동

- 친구: 요청(오프라인 대상 포함)·수락·거절·삭제·차단, 접속 상태 표시(오프라인/로비/플레이 중)
- 초대 코드(6자리, 재발급 가능)와 친구 초대(세이브 안에서), 세이브당 최대 10명; 받은 친구 요청·세이브 초대는 알림(`/notify`, 로비 메인 화면의 알림)에 모인다
- 참여 중인 세이브 목록(입장·탈퇴), 호스트가 플레이 중일 때만 입장
- 호스트의 참여자 관리: 추방, 인벤토리 보기(엔티티 상자, 접속 중이면 실시간·아니면 저장된 인벤토리)
- 채팅과 들어옴·나감 알림은 같은 세이브 안에서만

## 계정

- 업적(카운터 업적 포함)과 칭호, 업적 수로 열리는 이름 색
- 설정(알림, 광맥 캐기 대각선)

## 스카이기어

- 3×3×3 하늘섬 + 나무 한 그루, 맨손 시작([기획 05](design/05-sky-progression.md))
- **연구**: 참나무 판자·조합대·연구대 외 모든 조합법이 잠겨 있고, 연구대에서 재료를 한 번에 써서 조합법을 연다. 섬의 모두에게 바로 열린다
- **발전과제**: 챕터별 노드 트리, 다음 할 일을 힌트로 안내하고 퀘스트 창에 보여 준다
- **손작업 자원**: 돌멩이, 나무껍질 섬유·실, 망치 분해(조약돌 → 자갈 → 모래 → 먼지), 체와 메쉬 등급, 퇴비통(흙), 배럴(물)과 돌 배럴(용암), 마녀의 물
- **자동화**: 호퍼, 에너지(RE)와 발전기, 에너지·아이템·액체 도관, 분쇄기·자동 체·자동 자원 채굴기·자동 농작물 수확기·합금로·광석 세척기·전기 화로·자동 제작기·아이템 흡수기·자동 벌목기 등. 기계 창은 엔티티 상자이고 호퍼·도관으로 넣고 뺀다
- **연구 정수와 정수 추출기**: 자동화 이후의 연구는 재료와 함께 "~의 정수"(공학·연금술·농사·사냥·마법)를 낸다([기획 11](design/11-research-essences.md))
- **기계 강화**: 합금 → 제어 회로 → 강화 키트로 기계를 고급·정밀·궁극으로([기획 13](design/13-machine-tiers.md))
- **설정 복사기**: 도관 면·자동 제작기·서랍 설정 복사와 붙이기
- **생산 통계와 정지 알림**(`/통계`)
- **서랍과 스토리지 컨트롤러**: 한 종류 대용량 보관, 앞면 넣기/꺼내기, 업그레이드·잠금, 여러 서랍을 한 저장소로 묶기
- **차원 게이트 웨이브**: 몬스터 8단계, 에센스 드롭, 몬스터 시뮬레이터, 에센스 테마로 드롭이 바뀌는 마법 체
- **장비 제작(팅커스풍)**: 머리·손잡이 조합, 도구 레벨과 강화
- **마법 식물**: 꽃·광석꽃·보석꽃·에센스꽃, 꽃잎 염색
- **요정 마법**: 밤마다 찾아오는 선물 요정과 날개가루, 요정의 마법판으로 날씨(비·눈)와 해를 다룬다
- **도감**(`/도감`): 레시피 뷰어처럼 얻는 곳·쓰이는 곳, 체 드롭표, 가공·몬스터·식물 탭
- **섬 확장**: 위에서 내려다보는 지도에서 맞닿은 청크를 조약돌로 구매, 소유 청크 밖 건축 금지
- **보이드 복귀**(가장 가까운 블록 위 높은 곳에서 다시 낙하), **분실물 보관함**(공허로 떨어진 아이템, 하루 보관)
- **WAILA**: 바라보는 블록의 이름·아이콘·기계 상태
- HUD(왼쪽 위 일차·플레이 시간, 오른쪽 퀘스트 창)
