# 해야 할 일

앞으로 할 일과 실제 클라이언트에서 확인할 것을 둔다. 끝난 항목은 지운다.
운영자 도구는 [admin.md](tech/admin.md)(`/dfadmin give <ID>`, `/dfdebug wave <단계>`, `/dfdebug ui <기계>` 등)를 쓴다.

## 할 일

### 기능
- 공동 호스트(권한 등급 `cohost` 는 DB 에 있다).
- 도관 면 설정의 우선순위·자기 공급·필터·레드스톤 제어.
- 통계 화면의 분 단위 막대 그래프, 정지한 기계 옆 표시(파티클).
- 처음 쓰는 UI 안내: 계정마다 본 UI 를 기록하고(DB 마이그레이션) 처음 열 때만 안내 줄을 보인다.
- 로비 메인 메뉴에 설정 버튼(로비 메뉴는 팩의 `ui/df_lobby.json` 그림과 같은 키로 그리므로 함께 더한다).
- 도감 책 아이템(들고 쓰면 도감, 블록을 보며 쓰면 그 블록의 쪽).
- 손에 든 도구의 내구도 "현재/최대" 글자(HUD).
- 모바일(pocket) 창고 화면에도 모두 꺼내기·모두 넣기 버튼 줄(`df_quick.side_bar`).
- 달성 토스트를 HUD 제목 표식으로 그릴지 검토(지금은 엔진 토스트).

### 시나리오
- 시나리오 봇은 JSON UI 폼만 읽는다(`run.sh` 가 팩 암호화를 꺼 DDUI 를 끈다). DDUI 화면을 읽는 봇이 없다.
- 로비의 무작위 틱 중 nil 역참조 패닉(`world/tick.go`)이 한 번 났다. 재현 조건을 찾는다.

### 그림과 모양
- 임시 그림 교체: 마녀의 물(지금은 바닐라 물 그림), 요정 아이템, 차원 게이트, 정수 추출기·마법 체·새 기계, 기계 단계 테두리(`*_t1~t3.png`), 작동 띠, 연구 정수·에센스 아이콘, 금속·도구·식물 텍스처, 발전과제 트리 그림(`common/tools/treetex`). PNG 만 바꾸면 된다.
- 블록 모델 다듬기, 아이템 아이콘을 모델 모양으로.
- 회색 테마: 기계 창 업그레이드 빈 칸 그림(`slot_empty_*`)을 새 칸 색에 맞게 다시 그리기, 읽기 어려운 글자 색은 `common/ui/theme.go` 표에서 고친다.
- 기계 입수·배치 방식 전반 개선.

## 실기 확인

### 화면 공통
- 모바일: 모든 창(326×166 이하)과 탭·컨트롤 막대가 화면 안에 드는지, 터치 스크롤·검색칸 입력·스크롤 막대 끌기.
- 터치 툴팁: 처음 탭하면 툴팁만, 두 번째 탭에 눌림. 뒤로·쪽 넘김·탭은 한 번에. 툴팁 글자 크기와 화면 끝 처리.
- 애플 기기: Ore UI 한글이 네모 없이 보이는지, 창이 가운데 서는지, 바닐라 Ore UI(HUD·바닐라 화면)가 그대로 뜨는지. 안 되면 `/uidebug` 디버그 줄을 스크린샷으로 받는다.
- 한글과 영문·숫자가 섞인 줄이 같은 높이인지(`common/oui-ddui.js` `rich`).
- Ore UI 서버 리소스(`/dfdebug oreres`): Windows 에서 `packet style`·`packet blob: script`·`pack link` 를 다시 본다. 모바일(Android, iOS)에서 같은 표가 나오는지. 결과는 [oreui-probes.md](tech/oreui-probes.md) 표에 적는다.
- Ore UI 입력 이벤트(`/dfdebug oreinput`): Windows 에서 Alt 를 누르지 않고 마우스 버튼별 `button`, `dblclick`, `contextmenu`, 휠(`dx`·`dy`), 포커스, 입력칸의 `input`·`composition*`(한글 IME)이 찍히는지. 모바일에서 터치·누른 시간·포인터 이벤트, 게임패드 연결·버튼·축. 결과는 [oreui-probes.md](tech/oreui-probes.md) 에 적는다.
- Ore UI 부분 갱신: 바뀐 칸만 바뀌고 스크롤 자리·툴팁이 남지 않는지(정수 추출기, 도움말, 통계, 연구, 도감).
- JSON UI 호버 상자: 격자 칸·서랍 창·도관 설정에서 포인터 옆에 뜨는지, 폼을 처음 열 때 꺼져 있는지.
- 카드 메뉴(한 줄 4장), 쪽 넘김 줄, 창 입체선, 회색 테마 글자 대비, 입력 폼의 안쪽 테두리.
- `slotdeco` 팩이 바닐라 인벤토리·상자 화면을 그대로 두는지(문제 시 `[ResourcePack] SlotDeco = false`).
- 영어 클라이언트: 아이템 이름(`en_US.lang`), 폼·도감·WAILA·연구·발전과제 글이 좁은 칸에서 끊기지 않는지.

### 로비와 플랫폼
- 로비 입장기: 두 클라이언트가 서로 안 보이고 같은 세이브에서는 보이는지, 화면 비율별 틀과 카메라, 채팅 막힘·토스트 알림.
- 로비 DDUI 화면(세이브 선택·멀티 플레이·친구·칭호·치장·안내): 런처 모양, 왼쪽 위 이름 자리, Esc 뒤 메인 메뉴 복귀.
- 로비 메인 화면(`ui.HomeScreen`): 왼쪽 그늘 그라데이션이 그려지는지(Gameface `linear-gradient`), 메인 화면 ↔ 하위 화면이 닫혔다 열리지 않고 바뀌는지, 바뀐 뒤 버튼 누름 자리가 맞는지(창 크기 키가 같아 같은 화면을 쓴다), 메인 화면 Esc 뒤 1.5초 또는 입력에 다시 열리는지, 짧은 화면에서 버튼 줄과 오른쪽 아래 이름이 겹치지 않는지.
- Ore UI 키 입력: 섬 확장 화면의 방향키·WASD 이동과 스페이스바·Enter 구매, 도관 설정 색 네모 우클릭(이전 채널), 메뉴의 방향키·WASD 선택(호버 모양·툴팁)과 Enter·스페이스바 누름, 마우스를 움직이면 선택이 사라지는지, 키를 누른 채로 있을 때 너무 빨리 넘어가지 않는지.
- 서버 안내와 `/guide`, 바뀐 안내가 한 번 다시 뜨는지.
- 세이브 입장·로비 이동 뒤 몇 초 안에 움직일 수 있는지.
- 멀티 플레이: 친구·초대 코드·초대 수락·추방·인벤토리 보기(실시간 반영).
- 설정 화면(`/settings`): 알림 끄기가 저장되는지.
- 칭호 목록 쪽 넘김, 업적 진행 횟수, 새 이름 색, 카운터 저장(서버 재시작 뒤 유지).

### 초반 자원
- 섬 보호 범위, 청크 원점 근처 섬의 시작 위치.
- 체: 실 메쉬로 일곱 금속 조각, 메쉬 조합, 빈손 웅크려 메쉬 빼기, 체 모델(막대 깜빡임, 메쉬 색, 상태 199개), 드롭률 체감.
- 배럴: 물·용암 시간, 호퍼·도관 입출력, 점토, 안에 들어서기·내용물 높이, 나무 양동이.
- 돌 배럴 용암(열원별 빠르기, 양동이로 퍼고 붓기, WAILA), 조약돌 생성기.
- WAILA 에서 불(영혼 불 포함)을 조준하면 아이콘 자리에 부싯돌과 부시가 그려지는지.
- 손으로 놓은 배럴(참나무·돌)을 옆면·위에서 조준하면 WAILA 가 아래 불이나 바닥 대신 배럴을 보이는지, 여러 개를 놓은 뒤에도 그런지.
- 분쇄 블록과 망치, 마녀의 물과 네 가지 섞기.
- 마법 식물: 교차 모델, 개화 텍스처, 수확, 멀리서 깜빡임.

### 에너지·도관·기계
- 발전기·도관·분쇄기 라인, 에너지 게이지와 멈춤 표시.
- 도관 모양: 팔 방향, 세 차선, 연결 변화, 100칸 이상 프레임, 선택·충돌 상자, 아이템 크기, 수평 네 방향 화살표(`tools/conduitgeo` `arrowQuad`).
- 도관 놓기·면 설정 창: 들고 우클릭, 웅크려 놓기, 카드 여섯 개 배치, 색 네모·`+` 고르기 판, 새 도관은 모든 면 꺼짐, 라운드 로빈 출력, 속도 표기.
- 기계 창: 컨트롤 막대 정보 버튼, 모두 꺼내기·넣기·있는 것만 넣기 버튼, 자동 제작기 칸과 조합법 목록.
- 있는 것만 넣기(상자·기계 창): 창고에 이미 있는 아이템만 옮기는지, 창을 열고 닫을 때 끊기는지(인벤토리 36칸 × 창고 54칸 비교 바인딩).
- 자동 채굴기·수확기·자동 체 출력과 호퍼·도관, 전기 화로·흡수기·벌목기.
- 작동 애니메이션: 작동 중에만 움직이는지, 멈추면 약 2초 뒤 돌아오는지.
- 기계 강화: 키트 사용·소리·파티클, 단계별 속도·소비·범위, 단계 테두리가 재시작 뒤에도 남는지.
- 설정 복사기: 도관 면·자동 제작기 조합법·서랍 설정 복사와 붙이기.
- 서랍 앞면의 손에 쥐는 모양 아이템(막대기·뼈·블레이즈 막대·브리즈 막대): `/dfdebug holderpose` 로 다른 아이템처럼 평면·같은 크기로 보이는 회전·크기·위치를 찾아 `animations/item_holder.animation.json` 기본값에 적기. 다른 아이템도 비스듬히 크게 보이면 `item_holder.entity.json` 목록에 추가([drawer.md](tech/drawer.md) '손에 쥐는 모양 아이템').

### 진행 확장
- 금속 가공(분쇄기·세척기·화로), 합금로, 에너지 셀.
- 액체: 탱크·도가니·액체 도관·용암 발전기, 돌 배럴 용암 빼기.
- 몬스터 시뮬레이터, 차원 게이트(게이트 방향·빛·회전, 몬스터 행렬, 웨이브 8단계와 새 몬스터 4종, 타격감, 낙하 몬스터).
- 마법 체: 창 배치, 에센스 충전, 테마별 드롭, WAILA 충전 표시.
- 스토리지 컨트롤러 조작: 우클릭 한 번이 손의 아이템만 넣는지(한 클릭에 사용 패킷이 두 번 와 인벤토리까지 넣히지 않는지), 0.5초 안 두 번 우클릭과 누르고 있기가 인벤토리를 넣는지, 블록을 든 채 웅크려 우클릭할 때 목록이 열리고 블록이 잠깐 놓였다 사라지지 않는지.
- 스토리지 컨트롤러 목록: 모든 아이템이 한 격자에 스크롤되는지(종류가 수백 개일 때 폼이 무거운지), Ore UI 검색 칸 입력에 결과가 바로 바뀌는지, 컨트롤 막대의 모두 넣기(아래 화살표)·정렬 버튼(바닐라 `store_filter_icon`)이 보이고 툴팁이 맞는지, 정렬 네 가지.
- 스토리지 컨트롤러·링크·검색(초성), 장비 제작대(메뉴, 채굴 속도, 레벨업, 강화).
- 정수 추출기: 카드·생산 화면, 호퍼·도관 입출력, 정수 비용과 생산 시간 밸런스.
- 생산 통계와 정지 알림(30초 뒤 한 줄, 되풀이 없음, 기계로 이동 버튼), 관련 업적.
- 요정 마법(`/dfdebug weather`·`sun`): 빗줄기, 눈의 안개와 눈송이, 해 흐름과 고정.
- 요정의 시간: 요정의 뼛가루를 작물·줄기·마법 식물·묘목에 썼을 때 입자와 단계 변화, 보통 뼛가루를 웅크려 작물에 쓰면 아무 일도 없는지, 요정의 모래시계를 기계에 썼을 때 WAILA 남은 시간 줄과 빨라진 진행, 1시간을 채운 뒤 우클릭이 기계 창을 여는지.
- 프로젝트 연구와 용의 알.

### 연구·발전과제·도감
- 연구 화면(`/dfdebug research load 300`·`random 50`): 격자·상세·쪽 넘김·연타, 미리보기 연구와 "먼저 필요" 버튼.
- 발전과제 트리: 틀 3종과 상태 색, 선 이음과 꺾임, 입구 표시 이동, 확대·축소(휠·두 손가락·버튼), 가장 큰 챕터의 열림 시간.
- 발전과제 달성: 잠긴 과제만 먼저 달성, 새 세이브 퀘스트 창(나무 얻기), 사건형 과제.
- 도감: 탭 다섯 개, 검색(초성), 아이템 쪽 구역과 즐겨찾기, 체 드롭표, 블록을 보며 `/도감`.
- 도움말: 아이콘 탭, 주제 앞·뒤 버튼, 마지막 탭 기억.
- 섬 확장 DDUI 화면: 청크 버튼과 화면 속 청크의 자리(어긋나면 `oui-ddui.js` `layoutPlanes` 의 시야각), 구매·끝내기.
