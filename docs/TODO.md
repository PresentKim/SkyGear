# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

`/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 망치(`hammer`)를 받을 수 있다.

1. **카드 격자 메뉴**(`/menu`): 버튼 카드가 3열로 보이는지, 아이콘·글자, 누르기·스크롤. 상점 구매·판매·분실물도 — [json-ui.md](tech/json-ui.md)
2. **기계 창**: 어두운 패널·칸, 진행 화살표 칸에 배경이 없는지
3. **서랍 표시**: 자물쇠가 손잡이 위에 작게, 오른쪽 위에 용량 배수(`×2`)·공허 구슬. 서랍 회수 뒤 글자가 남지 않는지
4. **커스텀 블록 파괴**: 서랍·납품함·기계·코어를 계속 누르면 부서지는지(서랍 앞면은 꺼내기라 옆·위를 캔다)
   - 안 되면 `platform.toml` 에 `[Experimental] BlockActions = true` 를 넣고 다시 캔 뒤 서버 로그의 `block action` 줄을 알려 주세요
5. **기계 위 글자**: 기계 위에 이름과 진행도(`분쇄기 40%`, `대기`)가 보이는지, 기계를 부수면 사라지는지
6. **납품함**: 우클릭 → 미션 폼, "제출하기"로 인벤토리에서 납품, 손에 든 아이템이 바로 들어가지 않는지
7. **블록 모델**: 코어(기둥 사이 수정)·납품함(뚜껑)·서랍(움푹한 앞판·손잡이, 방향별)·분쇄기(깔때기·롤러)·채굴기(아래 드릴)·판매함(동전 구멍)·체가 깨지거나 검게 보이지 않는지
8. **체**(Dorios 방식): 자갈·모래·흙을 들고 사용 → 하나 얹힘(체 위에 보임), 다시 사용할 때마다 내려가다 4번째에 부산물이 위로 튀어나오는지. 옆 체도 함께 걸러지는지, 가만히 두면 저절로 걸러지는지, 웅크려 사용하면 기계 창
9. **망치**: 돌·조약돌·자갈에 대고 사용(누르고 있기) → 4번에 조약돌·자갈·모래로 바뀌는지, 내구도 감소
10. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
11. 섬 확장 모드(메뉴 → 섬 확장): 메뉴가 보이게 되었으니 이전 확인 항목(카메라·유리 바닥·구매·끝내기)도 함께
