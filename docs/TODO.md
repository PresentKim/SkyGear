# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체 등을 받는다.

1. **18차 실기**: 조합대·벗긴 나무 같은 바닐라 블록 이름이 WAILA 패널에 한국어로 나오는지(클라이언트 번역 키를 쓴다. 키가 맞지 않으면 `tile.xxx.name` 글자가 그대로 보일 수 있으니 알려 주세요), 체 메쉬 판의 깜빡임(z 파이팅)이 사라졌는지, 빈손 숙이고 우클릭이 빈 체의 메쉬를 빼내는지(메쉬 끼우기·빼기는 눌린 체 하나만), 기본 실 메쉬가 자갈·모래·흙·먼지에서 철 원석 조각까지만 주는지(구리는 부싯돌 메쉬부터, 금은 철 메쉬부터), 실 메쉬 3×3 조합과 상위 메쉬의 두 조합(실 메쉬 + 재료 1개, 가운데 재료 + 둘레 실)이 되는지

2. **리소스팩 암호화·minify**(19차): 서버를 새로 켜고 접속해 팩이 정상으로 적용되는지(텍스처·모델·UI·WAILA·이름). 안 열리거나 UI 가 깨지면 `platform.toml` 의 `[ResourcePack]` `Encrypt`/`Minify` 를 하나씩 꺼 보고 알려 주세요([resourcepack.md](tech/resourcepack.md))

3. **돌 배럴·용암**(20차): "돌 배럴" 연구(돌 32) 뒤 돌 6 + 막대기 2 로 돌 배럴, 실 1 + 숯 1 로 촛불이 되는지. 촛불 위에 돌 배럴을 두고 조약돌 8개를 채우면 2분 뒤 용암이 되는지(용암·마그마 블록 위에서는 4배·8배), 빈 양동이로 용암 양동이를 얻는지, WAILA 패널의 남은 시간. 돌 배럴 그림 세 장(`barrel_stone`·`barrel_cobble`·`barrel_lava`)은 임시 그림. 물과 용암으로 조약돌 생성기를 만들어 자동 채굴기로 돌을 얻을 수 있는지

4. **에너지(RE)·발전기·에너지 도관**(20차, [06](design/06-power-and-conduits.md)): "연소 발전기" 연구(철 16, 선행: 철 가공·화로) 뒤 발전기를 만들 수 있는지(철 6 + 화로 + 레드스톤 2), 연료(석탄·숯·판자…)를 창이나 호퍼로 넣으면 WAILA 에 에너지가 차오르는지. "에너지 도관" 연구 뒤 철 2 + 레드스톤 1 → 도관 4개, 도관을 이어 놓으면 이어진 면에 팔이 뻗는지(모양 64가지, 그림은 임시), 발전기 – 도관 – 분쇄기 라인에서 분쇄기가 일하고 에너지가 없으면 "에너지가 모자라 멈춤"이 뜨는지. **분쇄기·자동 체·채굴기·수확기는 이제 에너지를 쓰고, 연구도 발전기가 먼저다**(옛 세이브의 기계는 발전기를 놓아야 돈다). 도관 연결 판정·손맛(설치 방향, 부술 때, 구멍으로 보이는지). **아이템 도관**: 연구("아이템 도관", 선행 호퍼) 뒤 철 2 + 실 1 → 4개, 상자 사이에 놓으면 이어지는지, **숙이고 빈손으로 면을 우클릭**하면 모드(양쪽 → 꺼내기만 → 넣기만 → 꺼짐)가 바뀌고 꺼짐이면 팔이 사라지는지, 1단계가 0.4초에 1개, 금 4개, 다이아몬드 16개로 나르는지, 분쇄기 아래에 도관을 두면 결과가 나오는지. 금·다이아몬드 도관 업그레이드 조합(4개 + 금/다이아 1개)

## EnderIO 도관 포팅 후속
- 실기 확인: 도관 팔·코어에 EnderIO 텍스처가 맞게 보이는지(UV 배치), 투명 영역 처리.
- 면별 설정 폼(채널·우선순위·라운드로빈) → 아이템/에너지 도관에 적용.
- 번들 실기 확인(가장 불확실): ① 도관 아이템을 놓으면 블록이 생기는지(번들), 이미 있는 도관에 다른 종류를 놓으면 합쳐지는지, 클라이언트에 옆칸 유령 블록이 남지 않는지 ② 에너지+아이템 번들의 대각선 모양과 단계별 텍스처(뼈대 이름으로 고른 `material_instances`, permutation 병합) ③ 1024개 상태·1008개 permutation 과 지오메트리 192개(약 2MB)로 접속이 느려지지 않는지, 다른 블록 텍스처(참나무 판자 등)가 정상인지 ④ 선택 상자 크기.
- 도관 재료: 모래·자갈 체크무늬 → 도관 결합 반죽(6개) → 화로 → 결합체 → 기본 에너지/아이템 도관 8개(결합체 위아래 줄, 가운데 레드스톤 3개 / 철 조각·상자·철 조각). 연구(에너지 도관·아이템 도관)가 반죽 레시피를 여는지, 반죽이 창작 인벤토리·레시피 책에 나오는지, 아이콘(EnderIO 그림).
- **도관 표시 엔티티(21차)**: 도관 모양을 블록 상태 대신 표시 엔티티로 그린다(`docs/tech/conduits.md`). 실기에서 확인: ① 도관을 놓으면 코어와 가는 팔이 보이는지(엔티티 `conduit_visual`, 렌더 컨트롤러가 `query.variant`를 푸는지) ② 팔이 올바른 방향(동서·남북)으로 뻗는지(안 맞으면 `tools/conduitgeo`의 `flipZ` 를 바꾸고 재생성) ③ 에너지만 이어지는 면에는 에너지 팔만 뻗는지, 아이템도 마찬가지 ④ 에너지+아이템 번들에서 두 줄이 겹치지 않고 위·아래·옆에서 다 보이는지 ⑤ 연결이 바뀌면 팔이 즉시 바뀌는지 ⑥ 부수면 모양이 사라지는지(엔티티가 남지 않는지), 접속을 끊었다 들어와도 모양이 있는지 ⑦ 도관 100칸 이상 깔았을 때 프레임·접속 시간 ⑧ 새 아이템 아이콘(`conduit_energy_N`) ⑨ **옛 도관**(번들 이전에 놓은 것)이 한 틱 뒤 새 모양으로 바뀌는지 ⑩ 선택 상자(3~13픽셀)로 도관을 찍을 수 있는지.
- **도관 2차(표시 엔티티 후)**: ① 인벤토리·손의 도관 아이템이 블록(짧은 파이프)으로 보이는지, 텍스처(에너지 빨강·아이템 청록·액체 파랑 슬롯) ② 부술 때 균열·파편이 보이는지(10픽셀 투명 큐브 + 회색 텍스처 방식이 통하는지; 안 되면 큐브 크기나 UV 조정) ③ 액체 도관(`/dfadmin give fluid_conduit_1`)을 에너지·아이템과 한 블록에 넣었을 때 세 차선(−3 / 0 / +3)이 모든 방향에서 나란히 보이는지, 팔 방향 ④ 도관 블록에 없는 종류를 우클릭하면 그 안에 들어가는지, 있는 종류는 안 놓이는지 ⑤ 숙이고 우클릭하면 옆 칸에 새로 놓이는지 ⑥ 도관 너머의 블록을 찍어도 도관 칸에 들어가는지 ⑦ 통 옆에 액체 도관을 두면 팔이 뻗는지.
- 자동 채굴기·수확기는 더 이상 이웃 상자·기계로 밀어 넣지 않는다: 결과가 기계 안에 쌓이고 호퍼(아래)·아이템 도관(어느 면이든)이 꺼내는지, 안내 글이 바뀌었는지. 자동 체도 같은 방식이다(출력 칸 4개, 가득 차면 멈춤, 클릭하면 창이 열리고 진행도는 오르지 않음, 창이 수확기 배치로 보이는지).
- **도관 연결부**: ① 도관이 상자·기계·통과 이어지는 끝에 연결부(판+목)가 보이는지, 위치(차선 위, 가장자리 안쪽)와 방향 ② 연결부를 우클릭하면 아이템 도관은 모드가 바뀌고(팁으로 면 이름·모드) 꺼짐에서도 연결부가 남는지 ③ 연결부 히트박스(6픽셀)가 잡히는지, 뒤의 상자를 열 때 방해되지 않는지 ④ 도관 블록 크기가 9픽셀로 줄어 조준·파괴가 자연스러운지 ⑤ WAILA 에 "초당 N개"가 뜨는지.
- 점토: 물이 담긴 배럴에 먼지를 들고 우클릭하면 점토 공이 나오는지(물 유지), 체에서 점토가 더 나오지 않는지, 점토 연구가 배럴 연구 뒤에 열리고 안내 글이 맞는지. 연소 발전기·자동 채굴기 창의 진행 표시가 게이지 링인지(발전기는 남은 연료).
- **연결부 판**(앞의 6픽셀 연결부 엔티티를 대체): ① 도관이 상자·기계와 이어지는 면에 검은 판과 종류별 연결부가 붙는지, **그림자가 없는지**, 판·연결부 위치 ② 아이템 도관이면 판에 화살표 두 개(꺼내기/넣기)가 채널 색으로 보이고 모드에 따라 켜지고 꺼지는지(양쪽/꺼내기만/넣기만/꺼짐) ③ **숙이고 빈손으로** 판 자리(상자 면 가운데)를 우클릭하면 폼이 열리는지, 도관 블록 면을 클릭해도 열리는지 ④ 폼: 꺼내기/넣기 켜짐·꺼짐과 채널 고르기, 같은 채널끼리만 아이템이 가는지 ⑤ 숙이고 빈손이 아닐 때(아이템을 들었을 때) 상자가 평소처럼 열리는지.
- **에너지 게이지**: 발전기·분쇄기·자동 채굴기·수확기 창 오른쪽(슬롯 17)에 건전지가 차오르고, 올려 보면 "에너지 N/최대 RE"가 뜨는지, 칸이 비는 곳이 없는지(수확기 결과 칸 옆), 그림(임시)이 보이는지.
- **도관**: 도관 아이템이 8픽셀 큰 코어 하나로만 보이는지, WAILA 에 `N item/t`(0.125 / 0.5 / 2)가 뜨는지, 이미 든 종류의 도관 블록을 우클릭하면 아무 일도 없고(안내 글 없음) 숙이면 옆에 놓이는지(도관 2종이 든 번들에 설치가 안 된다는 보고: 재현은 못 했고 이 경우로 보인다).
- 도관 블록 충돌 상자가 9픽셀로 줄어 걸어 다닐 때 풀 블록처럼 막히지 않는지, 액체 도관 WAILA 에 `N mB/t`가 뜨는지.
- 도관 아이템 큐브가 일반 블록의 9/16 정도 크기로 보이는지(인벤토리·손·바닥에 떨어진 모습). 아직 크면 `tools/conduitgeo`의 `iconHalf` 를 줄인다.
- 연결부 판 설정 창: 곡괭이 같은 도구를 들고도 숙이고 판 자리(상자·기계 면)나 도관 옆면을 우클릭하면 열리는지, 도관 아이템을 들고 숙이면 놓이는지.
- 자동 체 조합: 철 4 + 체 + 호퍼를 조합대에서 만들 수 있는지(레시피 책에서 체 칸이 비지 않고 빨갛지 않은지; 체를 어떤 상태로든 받도록 와일드카드 메타로 바꿈).
- 새로 놓은 아이템 도관은 모든 면이 꺼짐이라 상자·기계와 이어지지 않고 팔도 판도 없다가, 설정 창에서 켠 면만 이어지는지(옛 도관·이미 놓은 도관은 그대로).
- 아이템 도관 출력이 라운드 로빈인지(꺼내는 상자 하나에서 목적지 상자 둘 이상으로 번갈아 한 개씩 가는지).
- 07 진행 확장(금속·합금로·에너지 셀): 체에서 주석·납·은·니켈 조각이 나오는지, 조각을 조합대에서 갈면 가루, 분쇄기는 가루 2개, 화로가 가루를 주괴로 굽는지, 합금로 창(입력 2칸·화살표·출력·게이지)과 청동·엘렉트럼·인바·강철 결과, 에너지 셀이 도관으로 충전·방전되는지, 강화·엔더 도관 조합, 새 금속 텍스처(임시 그림)와 연구·발전과제 힌트.
- 몬스터 시뮬레이터: 먼지를 철 그물 이상으로 걸러 정수가 나오는지, 시뮬레이터(윈도우 입력 칸·링·출력 4칸·게이지)에 정수를 넣으면 8번 드롭이 나오는지, 엔더 진주·블레이즈 막대 발전과제가 열리는지.
- 도관 연결부: 아이템 도관에만 4×4 칼라가 있고(꺼짐인 면에는 칼라·화살표 모두 없음)(에너지·액체는 없음), 네 옆면(수평 팔은 위·아래 포함)에 넣기·꺼내기 화살표가 나란히 보이는지, 어느 각도에서도 깜빡이지 않는지. 검은 판이 없어지고 아이템 연결부 옆면에 채널 색 화살표가 붙는지(깜빡임 없음), 넣기/꺼내기 화살표 방향이 맞는지(수직·x·z 팔 모두, 틀리면 `tools/conduitgeo` 의 `arrowQuad` 방향 계산 수정).
- 도관의 판 없는 면을 숙이고 우클릭하면 연결된 목표 블록의 설정 창이 열리고, 목표가 여럿이면 누를 때마다 다음 면으로 넘어가는지.
- 도관 면 설정 창: 제목이 "서쪽 면: <블록 이름>"인지, 위에 도관·속도, 아래 좌우에 넣기·꺼내기 판(유리/콘크리트 상태 칸 + 작은 "+" 버튼이 틀 없이 옆에 붙는지), 상태 칸 누르면 다음 색, 호버 상자, "+" 로 여는 고르기 화면과 돌아가기, 창이 좁은 화면에서 잘리지 않는지.
