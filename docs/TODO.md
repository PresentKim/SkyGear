# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체 등을 받는다.

1. **18차 실기**: 조합대·벗긴 나무 같은 바닐라 블록 이름이 WAILA 패널에 한국어로 나오는지(클라이언트 번역 키를 쓴다. 키가 맞지 않으면 `tile.xxx.name` 글자가 그대로 보일 수 있으니 알려 주세요), 체 메쉬 판의 깜빡임(z 파이팅)이 사라졌는지, 빈손 숙이고 우클릭이 빈 체의 메쉬를 빼내는지(메쉬 끼우기·빼기는 눌린 체 하나만), 기본 실 메쉬가 자갈·모래·흙·먼지에서 철 원석 조각까지만 주는지(구리는 부싯돌 메쉬부터, 금은 철 메쉬부터), 실 메쉬 3×3 조합과 상위 메쉬의 두 조합(실 메쉬 + 재료 1개, 가운데 재료 + 둘레 실)이 되는지

2. **리소스팩 암호화·minify**(19차): 서버를 새로 켜고 접속해 팩이 정상으로 적용되는지(텍스처·모델·UI·WAILA·이름). 안 열리거나 UI 가 깨지면 `platform.toml` 의 `[ResourcePack]` `Encrypt`/`Minify` 를 하나씩 꺼 보고 알려 주세요([resourcepack.md](tech/resourcepack.md))

## 추후 검토

- 다국어: 틀은 만들어 두었고(`docs/tech/i18n.md`), 서버 글 약 480줄을 카탈로그로 옮기는 일과 영어 번역이 남았다.
- M3 협동(멀티 플레이): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영). 멀티 플레이는 통째로 나중에 검토한다.
