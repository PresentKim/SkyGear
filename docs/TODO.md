# 해야 할 일

실기(실제 클라이언트)에서 확인할 것과 앞으로의 과제를 둔다. 끝난 항목은 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md)에 남긴다.
운영자 도구는 [admin.md](tech/admin.md): `/dfadmin give <ID>`로 기계·서랍·씨앗 같은 아이템을, `/dfadmin wave <단계>`로 웨이브를 바로 얻고 시작한다.

## 실기 확인

### 시작과 자원 흐름 점검
- 새 세이브가 1×1 청크 한가운데(8, 8) 섬에서 시작하는지(옛 세이브는 예전 위치 그대로), 나무·섬 위치와 보호 범위.
- 나무 양동이(연구 "나무 양동이"): 물만 담기고 배럴·탱크·물 원천에 쓰이는지, 철 양동이와 섞이지 않는지.
- 배럴: 물·용암이 1분 만에 되는지, 호퍼·아이템 도관으로 넣고 빼는지, 가루가 점토 블록이 되는지.
- 체와 메쉬: 새 드롭표(천분율)가 체감상 알맞은지, 도감 표기.
- 정지 알림이 처음엔 꺼져 있고 기계 화면에서 켜지는지.

### 리소스팩과 표시
- 세이브 선택 화면(`ui.ListSplitMenu`): 세이브가 없을 때 첫 빈 슬롯이 골라지는지, 좁은 화면(모바일)에서 창과 2×2 버튼이 잘리지 않는지, 입력 폼의 제목 없는 창과 제출 버튼(`df.submit`)이 모바일에서도 잘리지 않는지. 이미 고른 슬롯 줄을 눌러도 화면이 닫히지 않는지, 컨트롤 막대의 뒤로 버튼이 로비로 돌아가는지, 이름 입력 폼의 뒤로 버튼과 닫기가 세이브 선택으로 돌아오는지.
- 기계 창의 컨트롤 막대: 모두 꺼내기·모두 넣기·정보 버튼이 창 오른쪽 위 어두운 막대에 닫기 왼쪽으로 나란히 보이는지(모든 기계 레이아웃), 작은 화면에서 막대가 잘리지 않는지.
- 폼 애니메이션: 연구 목록처럼 버튼으로 화면을 옮길 때 창이 다시 올라오지 않는지(탭·쪽 넘김·목록 줄·동작·뒤로), 명령이나 블록으로 처음 열 때는 올라오는지.
- 세이브 입장·로비 이동: 허공에 잠깐 떠 있거나 청크 로딩 전에 추락하지 않는지, 도착 후 움직일 수 있는지(몇 초 안에 풀리는지).
- 연구 목록: 제목줄 뒤로가기 왼쪽의 "?"(호버 시 설명, 누르면 본문에 펼침), 한 화면의 두 구역(제목이 한 줄을 차지하고 글이 오른쪽으로 이어지는지, 칸이 11개씩 줄을 맞추는지), 칸이 늘어도(필요 23 + 완료 33 이상) 열 때 멈추지 않는지(쪽 나누기는 없앴다). 멈추면 쪽 나누기를 되살린다.
- 호버 상자를 엔진 툴팁(`hover_text_renderer`)으로 바꿨다: 연구 목록·보상·분실물 같은 격자 칸, 서랍 창 칸, 도관 설정 작은 칸에서 마우스를 올리면 포인터 옆에 상자가 뜨는지, 줄바꿈(글의 `\n` 에서만)·색 코드, 안 뜨면 `gslot_hover_tip` 의 `#hover_text` 바인딩을 의심한다.
- 호버 상자가 폼을 처음 열 때 꺼져 있는지(연구 목록·서랍 창·도관 설정, PC 마우스와 터치 각각). 마우스가 칸 위에 놓인 채 열리면 그 칸의 상자는 정상으로 뜬다. 그래도 켜져 있으면 어느 기기·어느 칸인지 적는다([json-ui.md](tech/json-ui.md)).
- 오픈소스 모드에서 가져온 텍스처([asset-credits.md](tech/asset-credits.md)): 기계(합금로·자동 제작기·몬스터 시뮬레이터·세척기·연구소·전기 화로·도가니·발전기류·흡수기·벌목기·에너지 셀·탱크·컨트롤러·링크·제작대·게이트)의 여섯 면과 작동 띠·단계 테두리가 어색하지 않은지, 아이템(합금·회로·키트·복사기·주괴·가루·덩어리)이 알아볼 만한지. 마음에 안 드는 것은 PNG만 바꾸면 되고, 다른 그림이 필요하면 `tools/modtex` 의 `entries` 를 고친다.
- 리소스팩 암호화·minify: 서버를 새로 켜고 접속해 팩이 정상으로 적용되는지(텍스처·모델·UI·WAILA·이름). 문제가 있으면 `platform.toml`의 `[ResourcePack]` `Encrypt`/`Minify`를 하나씩 꺼 본다([resourcepack.md](tech/resourcepack.md)).
- 바닐라 블록 이름(조합대·벗긴 나무 등)이 WAILA 패널에 한국어로 나오는지. 키가 맞지 않으면 `tile.xxx.name` 글자가 그대로 보인다.
- 새 아이템·블록·도구의 텍스처(금속, 기계, 84종 도구, 72종 이상 식물·씨앗·꽃잎)는 임시 그림이다. 교체본이 오면 PNG만 바꾼다.

### 손작업과 체
- 체 메쉬 판이 깜빡이지 않는지, 빈손으로 숙이고 빈 체를 우클릭하면 메쉬가 빠지는지(눌린 체 하나만).
- 기본 실 메쉬가 자갈·모래·흙·먼지에서 철 원석 조각까지만 주는지(구리는 부싯돌 메쉬부터, 금은 철 메쉬부터). 실 메쉬 3×3 조합과 상위 메쉬의 두 조합(실 메쉬 + 재료 1개, 가운데 재료 + 둘레 실)이 되는지.
- 점토: 물이 담긴 배럴에 먼지를 들고 우클릭하면 점토 공이 나오는지(물 유지), 점토 연구가 배럴 연구 뒤에 열리는지.
- 돌 배럴·용암: 연구 뒤 돌 6 + 막대기 2로 돌 배럴. 횃불 위 돌 배럴에 조약돌 8개를 채우면 2분 뒤 용암이 되는지(용암·마그마 블록 위는 4배·8배), 빈 양동이로 용암을 얻는지, WAILA의 남은 시간. 물과 용암으로 조약돌 생성기를 만들어 자동 채굴기로 돌을 얻을 수 있는지.

### 에너지와 도관
- 연소 발전기: 연구 뒤 만들 수 있는지(철 6 + 화로 + 레드스톤 2), 연료를 창이나 호퍼로 넣으면 WAILA에 에너지가 차오르는지.
- 발전기 – 도관 – 분쇄기 라인에서 분쇄기가 일하고, 에너지가 없으면 멈춤이 표시되는지.
- 에너지 게이지: 발전기·분쇄기·자동 채굴기·수확기 창 오른쪽(슬롯 17)에 건전지가 차오르고, 올려 보면 "에너지 N/최대 RE"가 뜨는지.
- 도관 재료: 모래·자갈 체크무늬 → 도관 결합 반죽(6개) → 화로 → 결합체 → 기본 도관 8개. 연구가 반죽 레시피를 여는지, 반죽이 창작 인벤토리·레시피 책에 나오는지.
- 도관 모양(표시 엔티티, [conduits.md](tech/conduits.md)): ① 놓으면 3×3×3 코어와 가는 팔이 보이는지 ② 팔 방향(동서·남북)이 맞는지(안 맞으면 `tools/conduitgeo`의 `flipZ`) ③ 에너지·아이템·액체 세 차선(−3 / 0 / +3)이 모든 방향에서 나란히 보이는지 ④ 연결이 바뀌면 팔이 즉시 바뀌는지 ⑤ 부수면 모양이 사라지는지, 접속을 끊었다 들어와도 모양이 있는지 ⑥ 도관 100칸 이상에서 프레임·접속 시간 ⑦ 선택 상자(3~13픽셀)로 찍을 수 있는지, 충돌 상자가 9픽셀이라 풀 블록처럼 막히지 않는지.
- 도관 아이템: 인벤토리·손·바닥의 아이템이 9/16 크기 큐브로 보이는지(크면 `tools/conduitgeo`의 `iconHalf`), 부술 때 균열·파편이 보이는지.
- 도관 놓기: 없는 종류를 들고 우클릭하면 그 안에 들어가는지, 있는 종류는 안 놓이는지, 숙이고 우클릭하면 옆 칸에 놓이는지, 도관 너머 블록을 찍어도 도관 칸에 들어가는지.
- 도관 연결부: 아이템 도관에만 4×4 칼라가 있고(꺼짐인 면에는 칼라·화살표 모두 없음), 네 옆면에 넣기·꺼내기 화살표가 나란히 보이는지, 어느 각도에서도 깜빡이지 않는지, 화살표 방향이 맞는지(수직·x·z 팔 모두, 틀리면 `tools/conduitgeo`의 `arrowQuad`). 그림자가 없는지.
- 면 설정: 숙이고 빈손으로 도관 면이나 연결부를 우클릭하면 설정 창이 열리고(목표가 여럿이면 누를 때마다 다음 면), 도구를 들고도 열리는지. 창 제목 "서쪽 면: <블록 이름>", 위에 도관·속도, 아래 좌우에 넣기·꺼내기 판(상태 칸을 누르면 다음 색, "+"로 고르기 화면과 돌아가기), 좁은 화면에서 잘리지 않는지.
- 새로 놓은 아이템 도관은 모든 면이 꺼짐이고, 설정 창에서 켠 면만 이어지는지. 출력이 라운드 로빈으로 목적지 상자들에 번갈아 한 개씩 가는지. 숙이지 않고 아이템을 들었을 때 상자가 평소처럼 열리는지.
- 아이템 도관 속도: 1단계가 0.4초에 1개, 2단계 4개, 3단계 16개. WAILA에 `N item/t`(0.125 / 0.5 / 2), 액체 도관은 `N mB/t`.
- 자동 채굴기·수확기·자동 체: 결과가 기계 안에 쌓이고 호퍼(아래)·아이템 도관(어느 면이든)이 꺼내는지. 자동 체는 출력 칸 4개가 차면 멈추고, 클릭하면 창이 열리고 진행도는 오르지 않는지. 연소 발전기·자동 채굴기 창의 진행 표시가 게이지 링인지.
- 자동 체 조합(철 4 + 체 + 호퍼)이 레시피 책에서 체 칸이 비지 않고 만들어지는지.

### 진행 확장
- 금속: 철·금·구리 광석 블록이 분쇄기에서 가루 2개(세척기는 3개)가 되는지, 주석·납·은·니켈 조각은 분쇄기에서 50%로 가루 1개가 되는지, 화로가 가루를 주괴로 굽는지.
- 합금로: 창(입력 2칸·화살표·출력·게이지), 청동·엘렉트럼·인바·강철 결과, 에너지 셀의 충전·방전, 강화·엔더 도관 조합.
- 몬스터 시뮬레이터: 먼지를 철 그물 이상으로 걸러 에센스가 나오는지, 에센스를 넣으면 8번 드롭이 나오는지, 엔더 진주·블레이즈 막대 발전과제가 열리는지.
- 액체: 양동이로 탱크에 붓고 빼는지, 도가니에 조약돌을 넣으면 용암이 차는지(WAILA), 액체 도관이 도가니 → 탱크·용암 발전기로 이어져 액체가 옮겨지는지, 돌 배럴의 용암이 도관으로 빠지는지, 통 옆 액체 도관에 팔이 뻗는지.
- 차원 게이트: 우클릭하면 단계 폼, 시작하면 둘레에 몬스터(바닐라 모양)가 나타나 걸어와 때리는지, 칼로 때리면 데미지·넉백·피격 모션, 다 잡으면 클리어 메시지와 다음 단계·보상, 시간 초과 시 사라지는지, 섬 밖으로 떨어진 몬스터가 웨이브를 막지 않는지, 걷는 모션과 화살 방향이 자연스러운지.
- 스토리지 목록의 "검색"(이름·초성 ㅊㅈㄱ)과 "인벤토리 모두 넣기"(가진 종류만), 검색 중 쪽 넘김·꺼내기 뒤에도 검색이 유지되는지.
- 스토리지 컨트롤러·링크: 서랍 줄 끝에 컨트롤러를 붙이면 호퍼·도관으로 넣고 빼지는지, 링크로 떨어진 서랍이 묶이는지, 16칸 밖 서랍은 빠지는지, 우클릭 목록(쪽 넘김·한 묶음 꺼내기)과 WAILA 줄.
- 장비 제작대: 메뉴(만들기 → 종류 → 머리 → 손잡이, 강화)가 열리는지, 도구의 이름·레벨·설명, 곡괭이·도끼·삽의 채굴 속도(클라이언트에도), 검으로 몬스터를 칠 때 데미지·내구 감소·경험, 레벨업 메시지와 강화 칸 증가, 신속(성급함) 효과.
- 캐릭터(메뉴 → 캐릭터): 몬스터를 잡으면 경험·레벨업 메시지, 스킬 포인트를 찍으면 최대 체력·성급함·신속이 적용되는지(재접속 뒤에도), 칭호 설정 버튼, 메인 메뉴 카드가 7장(생산 통계 포함)인지.
- 마법 식물: 씨앗을 심으면 교차 모델(`magic_plant.geo.json`) 싹이 보이는지, 개화 후 텍스처가 바뀌는지, 우클릭 수확, 몬스터의 씨앗 드롭, 상위 씨앗 조합이 창작 인벤토리·레시피 책에 보이는지.

### 자동화 설비 ([09](design/09-automation-equipment.md))
- 자동 제작기 창: 3×3 재료 칸, 가운데 위 조합법 칸, 진행 링, 오른쪽 결과 칸 4개, 게이지가 겹치지 않고 보이는지(`ui/df_machine.json`의 `crafter_slots`). 조합법 칸에 아이템을 올리면 되돌아오고 조합법이 정해지는지, 칸을 눌러 빈 손으로 집으면 지워지는지, 재료 칸이 정해진 조합법의 재료만 받는지(손·호퍼·도관).
- 빈손으로 웅크리고 우클릭하면 조합법 목록 폼이 열리고(연구로 연 것만), 쪽 넘김과 지우기가 되는지.
- 전기 화로(원석 가루·원목·음식 굽기), 아이템 흡수기(범위 안 드롭 거두기, 범위 밖은 그대로), 자동 벌목기(높은 원목부터 베기, 원목이 없으면 묘목 심기, 흡수기와 함께 순환).
- 새 기계 텍스처 4종(임시 그림).

### 도감·프로젝트·상태 표시 ([10](design/10-user-flow.md))
- 도감 검색(첫 카드): 이름·초성(예: ㅊ ㅈㄱ)으로 찾기, 비운 채 확인하면 전체 목록과 쪽 넘김, 결과 칸을 누르면 아이템 도감으로 가는지. 아이템 도감 아래 "만드는 재료"·"이것으로 만드는 것" 두 구역과 칸을 눌러 이어가기(칸이 많으면 11칸 줄바꿈).
- `/도감`: 첫 화면 카드 7장과 쪽 이동, 체 드롭표(블록 → 메쉬 → 칸 격자에 확률 글자)가 잘리지 않는지, 칸을 누르면 그 아이템의 도감으로 가는지, 아이템을 손에 들고 `/도감`을 치면 "얻는 곳 / 쓰이는 곳"이 바로 열리는지. 메뉴 → 도움말 맨 위의 도감 카드.
- 프로젝트: 연구 목록에서 공장·사냥꾼·재배자 프로젝트가 아이콘과 함께 보이는지(조합법 없는 연구), 비용 칸 6개가 잘리지 않는지, 마지막 연구 뒤 용의 알이 조합되는지, 알을 놓으면 섬의 모두에게 알림과 파티클·소리가 나오고 칭호가 열리는지.
- 바라보면 나오는 패널의 "출력 슬롯 부족으로 중단"과 자동 제작기의 "조합법 미설정 / 재료 부족: …".
- 도움말에 "목표와 흐름", "자동화 라인 예시"가 생겼는지(카드가 많아져 스크롤이 자연스러운지).

### 연구 정수와 연구소 ([11](design/11-research-essences.md))
- 연구소 창(`§d§m§8`): 3×3 재료 칸, 정수 칸 4개, 진행 링, 에너지 게이지, 정보 아이콘이 겹치지 않고 보이는지. 연구소 블록 앞면·옆면·위·아래 텍스처가 맞는지(임시 그림이다).
- 연구 정수 5종 아이콘(유리병 안의 색)이 연구 화면·창·도감에서 구분되는지.
- 레시피별 주기가 진행 링과 패널의 남은 시간(웅크리고 바라보기)에 맞는지, 도관·호퍼로 재료를 넣고 정수를 뽑을 때 다른 재료가 칸을 막지 않는지.
- 정수가 드는 연구(38개)의 비용 줄에 정수가 보이고 모자란 정수가 알려지는지, 끝낼 때 색 물보라와 소리가 나는지. 퀘스트 창이 연구소 연구와 모자란 정수를 보여 주는지.
- 정수 비용(`researchEssenceCosts`)과 레시피(`labRecipes`) 밸런스: 연구소 몇 대, 발전기 몇 대로 어느 시간에 닿는지.

### 생산 통계와 정지 알림 ([12](design/12-production-monitor.md))
- 메뉴 → 생산 통계와 `/통계`: 세 쪽(생산량 격자, 에너지, 정지 목록)과 탭이 잘리지 않는지, 생산량 칸의 아이콘·분당 개수·툴팁(5분 평균·1분·15분·누적)이 맞는지.
- 출력 칸을 가득 채운 기계가 30초 뒤 채팅 한 줄(`[정지] 분쇄기 (x, y, z) 출력 슬롯 부족으로 중단`)과 경고음으로 알려지는지, 같은 정지가 되풀이되지 않는지, 풀면 정지 목록에서 사라지는지. 알림 켜고 끄기가 저장되는지.
- 정지 목록의 버튼이 기계 옆으로 데려다 주는지(소유 청크 안, 막히지 않는 자리).
- 업적: 기계 생산량·분당 기록·발전 기록·무정지 가동이 실제 라인에서 오르는지.

### 새 몬스터와 마법 체 ([15](design/15-magic-sieve.md))
- 웨이브 3·4·6·7·8단계에 마녀·익사자·피글린·위더 스켈레톤이 바닐라 모습으로 나오고 시간이 맞는지(130·130·160·190·260초), 마녀의 화살, 첫 클리어 보상의 새 에센스.
- 마법 체 창(`§d§m§9`): 입력·에센스 칸, 링, 출력 4칸, 에너지 게이지가 겹치지 않는지. 블록 모습(보라빛 체 텍스처는 임시 그림), 메쉬 끼우기·빼기, 에센스 한 개가 24번 충전되는지.
- 테마가 드롭을 바꾸는지: 익사자+모래는 바다 것만, 피글린+자갈·모래는 지옥 것만, 엔더맨+자갈·모래는 엔드 것만 나오는지. 어려운 몬스터일수록 희귀 항목이 잘 나오는지(표본을 많이 돌려 본다).
- 도감 → 몬스터·웨이브에 테마 표와 난이도, 테마 아이템의 "얻는 곳"에 마법 체 줄이 나오는지. WAILA의 충전 표시("익사자 에센스 · 18회").
- 새 에센스 4종 아이콘(임시 그림)이 구분되는지, 새 아이템 이름이 클라이언트 번역으로 나오는지.

### 체 메쉬 표시
- 체의 메쉬 판이 깜빡이지 않는지(판을 얇게 하고 틀과 0.1픽셀 띄웠다), 끼운 메쉬(실·부싯돌·철·금·다이아몬드·네더라이트)마다 색이 다르게 보이는지. 체 한 종류의 상태가 199개로 늘었으니 블록이 정상으로 보이는지 먼저 확인한다(안 보이면 상태 값 수 한도를 의심).

### 연구 미리보기
- 연구 필요 탭 끝에 어두운 회색 이름으로 한 단계 앞의 연구가 보이는지(읽기 어렵지 않은지), 그 연구의 정보 폼에서 "먼저 필요: ○○" 버튼이 해당 연구로 이동하는지, 선행 연구를 끝내면 회색이 일반 색으로 바뀌는지.

### 기계 작동 애니메이션 ([block-animation](tech/block-animation.md))
- 전기 화로를 가동하면 정면 톱니바퀴가 도는지(flipbook이 커스텀 블록에서 움직이는지), 멈추면 약 2초 뒤 정지 텍스처로 돌아오는지, 상태가 바뀔 때 깜빡이거나 구멍이 나지 않는지. 모든 화로가 같은 박자로 도는 것은 한계다.
- 다른 기계(분쇄기·세척기·합금로·시뮬레이터·도가니·자동 제작기·연구소, 채굴기·수확기·발전기·용암 발전기·퇴비통·흡수기·벌목기)도 작동 중에만 움직이는지, 발전기는 연료가 탈 때만 켜지는지. 띠 그림은 임시이니 교체본이 오면 PNG만 바꾼다. 체는 모델 블록이라 제외했다.

### 기계 강화 ([13](design/13-machine-tiers.md))
- 합금로에서 인퓨즈·강화·원자 합금이 나오는지, 회로 I~IV와 키트 1~3이 조합대(레시피 책)에서 만들어지는지(제어 회로 IV와 궁극 키트는 3×3 재료가 맞는지).
- 키트를 들고 기계를 우클릭하면 한 단계 오르고 소리·파티클이 나는지, 단계가 틀리면 짧은 안내만 나오는지. 이름 "분쇄기 [고급]", 기계 창 정보 아이콘, WAILA의 속도·소비.
- 속도: 분쇄기·전기 화로 등이 단계마다 2·4·8배로 빠른지, 에너지 도관의 속도(40/240/960 RE/t)가 정밀·궁극 단계를 받쳐 주는지, 에너지 소비가 안내와 맞는지.
- 발전기 출력 ×1/2/4/8과 연료 소모, 에너지 셀 용량, 수확기·흡수기·벌목기의 범위 확대. 부수면 기계와 쓴 키트가 나오는지.
- 블록 모양: 키트로 올리면 블록이 철·금·다이아몬드 테두리 텍스처로 바뀌는지, 작동 중 띠도 단계 색을 유지하는지, 부쉈다 다시 놓아도 단계 모양이 남는지, 서버를 껐다 켜도 맞는지. 단계 텍스처는 임시 그림이라 `textures/blocks/*_t1~t3.png`를 직접 고치면 된다.

### 기계 창 버튼
- 모든 기계 창의 제목 줄(닫기 왼쪽)에 정보 아이콘 왼쪽으로 "모두 넣기"(주황 화살표 ↓)·"모두 꺼내기"(초록 화살표 ↑)가 겹침 없이 보이는지(분쇄기·합금로·자동 제작기·연구소·채굴기 레이아웃), 호버하면 이름이 뜨는지, 누르면 손에 들리지 않고 옮겨지는지. 출력만 있는 기계(채굴기·수확기·흡수기)에는 꺼내기만, 입력만 있는 기계에는 넣기만 있는지. 인벤토리가 가득할 때 꺼내기가 기계에 남기는지. 아이콘은 임시 그림이다.

### 도감 탭·목표·창 꾸밈 ([ui-style.md](tech/ui-style.md), [codex-jei.md](tech/codex-jei.md))
- 도감: 탭 다섯 개(검색·체·가공·몬스터·식물)가 창 폭(280)에 들어가고 글과 아이콘이 겹치지 않는지, 어느 쪽(아이템 쪽·체 드롭표)에서도 탭이 보이고 눌리는지, 검색 탭 위의 "목표"·"최근 본 아이템" 구역과 "전체" 구역의 줄이 맞는지, 뒤로 가기가 (아이템 쪽 → 보던 목록, 탭 쪽 → 메뉴)로 가는지.
- 아이템 쪽: "만드는 기계"·"만드는 재료"·"이것으로 만드는 것" 구역, "필요한 원재료" 줄(가진 수 색), "목표로 지정/해제"(세 개까지), 퀘스트 창에 목표 이름과 원재료 줄이 붙는지(줄이 너무 길어 잘리지 않는지).
- `/도감` 을 빈손으로 블록을 보며 치면 그 블록의 쪽이 열리는지.
- 칭호·치장: 탭 셋(칭호·이름 색·업적), 칭호 쪽 위의 상태 줄, 하위 쪽 제목 "칭호·치장 · 그룹".
- 폼 칸의 등급 테두리·배지(도감·스토리지·자동 제작기 목록): 칸 테두리가 칸 틀 위에 겹치는 모양, 많은 칸(44개)에서 열림이 느려지지 않는지.
- 창 가장자리의 입체선(`panel_bevel`)이 어색하지 않은지.
- 인벤토리 보기(72칸) 제목 줄 오른쪽 검색 칸: 글자를 칠 수 있는지(한글 포함), 입력과 맞지 않는 칸이 어두워지는지, 검색 칸에 글을 칠 때 인벤토리 키가 창을 닫지 않는지, 칸이 많아도 열림이 느려지지 않는지. 안 되면 `inventoryui/ui/inventoryui/vertical_scroll_screen.json` 의 `search_box`·`search_cell` 을 의심한다.

### 연구 화면 ([research-screen.md](tech/research-screen.md))
- `/dfadmin research load 300` 뒤 `/dfadmin research random 50` 으로 두 탭을 채우고 연구 화면을 연다: 창 크기(500×88%)·탭 두 개·8×5 격자(고른 칸 테두리, 모자란 칸은 빈 틀)·오른쪽 카드·본문·재료·보상 칸이 겹침 없이 보이는지, 칸을 누르면 상세만 바뀌는지, 쪽 넘김(약 8쪽)과 칸 연타의 깜빡임, 열림 지연.
- 같은 화면에서 "연구 진행"(재료를 넣고 누르면 다음 연구가 골라지는지), 선행 연구 버튼, "?" 호버·누름, 모바일에서 칸을 누르고 있을 때 상자.
- 복사본이 연구 칸·상세에서 원본과 같은 글을 보이는지, `load 0` 으로 없어지는지.

### 탭과 쪽 넘김 ([ui-style.md](tech/ui-style.md))
- 쪽 넘김("이전 쪽 (1/3)"·"다음 쪽 (3/3)", 화살표 아이콘): 스토리지 목록·도감 검색·도감 식물·자동 제작기 조합법·칭호 목록의 아래 동작 줄에서 같은 모양으로 보이는지(도감 식물의 쪽 넘김은 예전에 위쪽 탭 줄에 있었다).

### 슬롯 장식 ([slotdeco.md](tech/slotdeco.md))
- 서버를 새로 켜고 접속해 `slotdeco` 팩이 정상으로 적용되는지(바닐라 인벤토리·상자 화면이 그대로 보이는지). 문제가 있으면 `[ResourcePack] SlotDeco = false`.
- 칸 뒤 등급 배경: 인퓨즈 합금(고급, 초록)·강화 합금(희귀, 하늘)·원자 합금(영웅, 보라), 정밀 키트·회로 IV(전설, 금색)가 인벤토리·기계 창·인벤토리 보기 칸에서 아이템 뒤에 보이고 그림을 가리지 않는지. 아이템 이름 색이 등급 색인지, 이름 앞에 이상한 글자가 안 보이는지.
- 전면 배지: 키트·회로·합금 칸 왼쪽 위의 점 1~4개, 정지한 기계 창 정보 아이콘의 빨간 느낌표(멈춘 기계에 열었을 때·열린 채 멈출 때).
- 도구 이름이 레벨에 따라 색이 바뀌는지(3 고급, 5 희귀, 8 영웅, 10 전설), 호버 상자에 표식 글자가 안 보이는지.
- 터치 선택 말풍선의 등급 테두리가 말풍선 크기에 맞는지(어긋나면 `slotdeco.json` 의 `tip`).
- 인벤토리 보기(72칸)·연구소·자동 제작기처럼 칸이 많은 창이 열릴 때 지연이 없는지.

### 설정 복사기 ([14](design/14-config-copier.md))
- 연구 "설정 복사기"와 레시피. 우클릭(복사)·웅크리고 우클릭(붙여넣기)·허공 우클릭(비우기), 이름 아래 설명 한 줄, 알림.
- 도관 면(연결 판), 도관 묶음 몸통, 자동 제작기 조합법, 서랍 아이템·잠금이 복사되고 붙는지. 종류가 맞지 않으면 "붙일 수 없음"만 나오는지. 복사기를 든 채 눌러도 상자·창이 열리지 않는지.

### 칭호와 업적
- 칭호·치장 → 칭호 고르기에서 분류별 목록과 쪽 넘김이 자연스러운지(칭호가 한 분류에 수십 개), 업적 목록의 진행 횟수(`지금/목표`)가 보이는지. 새 이름 색(짙은 초록~네더라이트)이 채팅과 이름표에 제대로 보이는지.
- 카운터가 실제 플레이에서 오르는지: 막대기·망치·도끼·체·퇴비통·배럴, 기계 작업(분쇄기·합금로·자동 체 등), 발전량, 웨이브·몬스터, 연구·발전과제·청크, 걷기·점프·접속 시간. 20초마다·퇴장·종료 때 저장되는지(서버를 껐다 켜도 횟수가 이어지는지).

### 연구와 발전과제
- 연구 22개 추가분이 연구 화면에 뜨고 이름·설명이 맞는지. 염색 연구 뒤 꽃잎 1개로 염료 2개가 나오는지, 열여섯 색 유리·테라코타·콘크리트 가루·양초 조합이 열리는지. 양동이 연구 전에는 양동이가 나오지 않고 돌 배럴·유체 탱크가 그 뒤에 열려 흐름이 막히지 않는지. 엔더 상자가 열리는지.
- 발전과제: 제목·힌트가 사이드바(두 줄)에서 잘리지 않는지, 발전과제 화면의 긴 이름이 버튼에서 넘치지 않는지, 사건형(첫 사냥·웨이브 3/8·캐릭터 레벨·스킬·도구 제작·꽃 수확·청크 8/16)이 때맞춰 달성되는지.

## 앞으로의 과제

### 기능
- 통계 화면에 분 단위 막대 그래프, 정지 알림을 기계 옆 표시(파티클)로 보조.
- 처음 쓰는 UI 안내: 계정 단위로 본 UI를 기록하고(DB 마이그레이션), 처음 열 때만 제목 플래그와 JSON UI 조건부 패널(또는 폼 안내 줄)로 보여 준다. 시스템이 안정된 뒤 검토한다.
- 섬 확장 모드의 선택 범위가 불편하면 몸을 커서 쪽으로 옮기는 방식 검토.
- 공동 호스트 기능(권한 등급 `cohost`는 준비되어 있다).
- 다국어: 틀은 갖춰져 있고(`docs/tech/i18n.md`) 한국어 글은 모두 카탈로그에 있다. 영어 번역과 표·사이드바의 언어별 표시가 남았다.
- 멀티 플레이 실기: 클라이언트 두 대로 친구·초대 코드·초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영).
- 도관 면 설정의 우선순위·자기 공급·필터·레드스톤 제어.

### 도감 ([docs/tech/codex-jei.md](tech/codex-jei.md))
- 아이템 쪽에 "만드는 기계" 칸, 최근 본 아이템, 북마크한 목표 아이템의 원재료 계산(퀘스트 창), 도감 책·WAILA 로 바라보는 블록 조회.
- 검색 결과를 상자 창으로 보여 주는 방식을 폼과 비교(열림 시간·프레임)해 정한다.

### 디자인·연출
- JSON UI 테마 다듬기(크기·색·글자).
- 블록 모델 다듬기, 아이템 아이콘을 모델 모양으로.
- 기계 입수·배치 방식 전반 개선.

### 발전과제 트리 화면 ([advancement-tree.md](tech/advancement-tree.md))
- 실기 확인: 노드 틀 3종·상태 색, 연결선 이음, 고른 노드 테두리, 호버 글, 화살표 창 이동, 탭 5개, 모바일 터치, 칸 48개 열림 시간.
- 텍스처는 `tools/treetex` 자리표시 그림이다. 직접 그린 그림으로 교체한다.
- 달성 토스트를 BedrockAdvancements 식 HUD 제목 표식으로 그릴지(지금은 엔진 토스트).

### 회색 테마 ([ui-style.md](tech/ui-style.md))
- 실기 확인: 모든 폼(카드·목록·표·칸·연구 분할·기계 창)의 글자 대비. 창 위 글은 `ui.OnPanel` 이 색 코드를 어둡게 바꾸고, 버튼 위 글과 툴팁은 그대로다. 읽기 어려운 색이 있으면 `theme.go` 의 표를 고친다.
- 입력 폼(게임 기본 흰 글자)은 어두운 안쪽 테두리(`inset`) 안에 그린다. 모양 확인.
- 기계 창의 업그레이드 빈 칸 그림(`slot_empty_*`)은 어두운 테마용으로 그려져 있다. 새 칸 색에 맞게 다시 그린다.
- HUD(스코어보드·퀘스트 창)는 반투명 오버레이라 바꾸지 않았다.
