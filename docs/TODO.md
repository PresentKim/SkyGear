# 해야 할 일

진행 중이거나 미뤄 둔 일. 끝나면 지우고 해당 문서에 결과를 반영한다.

## 사용자 실기 확인 (실제 Bedrock 클라이언트)

자동 테스트로 볼 수 없는 화면·조작 확인. 사용자가 확인 후 결과를 알려 주면 반영한다.

- [ ] M2 실기 확인 — [docs/tech/m2-playtest.md](tech/m2-playtest.md) (1차 결과 반영됨)
  - 다시 볼 것: 코어 생성 간격(3초), 서랍 3~6번(`/dfadmin give drawer`), 상점·분실물 상자, 청크 지도, 납품함 제출 시 끊김(끊기면 화면의 이유를 알려 주세요)
- [ ] M3 협동: 실제 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방 조작감
- [ ] 엔티티 상자 — [docs/tech/chestui.md](tech/chestui.md)
  - 1차: 블록 클릭 시 열렸다 바로 닫히거나, 폼 뒤에 안 열리거나, 닫힘 반복 후 끊김 → 열기 절차를 InvMenu 방식으로 바꿈(지연 열기·확인될 때까지 재전송·엔티티 탑승). 다시 확인 필요
  - 창이 열리는지, 제목의 서식 코드가 보이지 않는지, 플레이어에 탑승한 엔티티가 이동·시점에 영향을 주지 않는지
  - 크기: PC 3줄(메뉴)·스크롤(InvSee 72칸), 모바일 화면
  - InvSee: 꺼내기·넣기·나누기·Shift 이동·버리기, 대상 쪽에서 바로 보이는지, 대상이 동시에 바꿀 때 복사·증발이 없는지
  - 메뉴 버튼: 클릭 시 아이템이 커서에 붙었다 돌아가는 깜빡임 정도, 연속 클릭
  - 메뉴 → 폼(수표 발행·미션 등): `CloseThen` 250ms 뒤 폼이 뜨는지, 메뉴 → 다른 상자(상점) 전환
  - 리소스팩 필수 설정으로 접속 시 팩 받기 흐름

- [ ] M4 기계 — [docs/tech/machines.md](tech/machines.md)
  - 기계 4종 임시 텍스처, 우클릭 시 기계 창(입력·출력·진행도 표시), 진행도 갱신
  - 호퍼로 넣고 빼기, 자동 채굴기 → 분쇄기·판매함 무인 라인(`/dfadmin line`), 판매함 주인 지갑 입금
  - 기계를 부술 때 내용물이 함께 떨어지는지
