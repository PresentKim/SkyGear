# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **판매 표 아이콘**: 표 칸의 아이템이 왼쪽이 잘리지 않고 다 보이는지(16×16, 왼쪽 여백 4로 바꿈)
2. **토스트 알림**: 상점·판매 등 폼 동작의 실패(돈 부족·재고 없음 등)는 화면 위 토스트만, 구매·판매 성공은 토스트와 채팅 둘 다 오는지. 알림 폼은 더 뜨지 않고 폼은 바로 다시 열리는지
3. **토스트 간격**: 상점에서 빠르게 여러 번 사거나 실패해도 토스트가 밀리지 않고, 3초 안의 알림은 하나로 합쳐 "(외 n건)" 으로 나오는지. 토스트가 3초보다 빨리/늦게 사라지면 `ui.ToastGap` 조정
4. **서랍 조작 소리**: 잠금·해제(구리 다락문 닫힘·열림), 업그레이드 장착(철 갑옷 착용), 빈 서랍 잠금·업그레이드 초과(거부음) 때 메시지 없이 소리만 나는지
5. **블록 아이템 아이콘 정리**: 코어·납품함·서랍·기계 아이템이 인벤토리·핫바·바닥에 떨어진 모습·폼에서 전처럼 블록 모양으로 보이는지(아이템 아이콘 텍스처를 지움)
6. **WAILA 패널**: 블록을 보면 화면 위 가운데에 패널(아이콘·이름·정보 줄·도구 아이콘)이 **보스바 아래**에 뜨는지, 정보 아래 회색 칸이 없는지(콘텐츠 로그에 "expected a string" 경고가 없는지), 시선을 돌리면 바로 바뀌고 허공을 보면 사라지는지.
   - 아이콘이 블록 모양으로 나오는지(부제목 값을 읽는 방식, 안 나오면 알려 주기), 일반 제목(레벨 업·긴급 매입)이 패널에 덮이지 않는지
   - 정보 줄: 기계 진행 %(넣은 것은 칸으로), 서랍 수량·잠김·업그레이드, 코어 만드는 것·다음까지 초, 작물 남은 시간(매초 갱신), 납품함 미션
   - 도구 아이콘: 돌을 맨손으로 보면 곡괭이에 ✗ 표시, 곡괭이를 들면 ✓
   - **보관 블록 내용**: 상자·통(묶어서 수량, 17종류 넘으면 +n), 화로(입력·연료·결과), 호퍼, 기계(입력·출력 칸)를 보면 아이템 칸이 패널에 나오는지, 수량 글자 위치
   - 작물 우클릭 시 시간 글자가 더는 안 뜨고(제거함) 블록도 안 놓이는지
7. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
