# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **HUD**(13차 뒤, 사이드바를 나눔): 왼쪽 위 `일차 · 플레이 시간`, 오른쪽 위 돈, 오른쪽 가운데 퀘스트 창(미션 이름 + 아이템별 `12/32`, 다 채우면 초록)이 보이는지, 사이드바가 따로 남지 않는지, 줄 사이가 비지 않는지(숨긴 줄이 자리를 차지하면 알려 주기). 경험치 레벨 = 섬 레벨, 경험치 바 = 미션 진행인지. `/dfadmin tps` 로 왼쪽 위에 부하 한 줄이 켜지고 꺼지는지(로비에서도), `%` 가 보이는지. 모바일에서 왼쪽·오른쪽 위 버튼과 겹치지 않는지
2. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
