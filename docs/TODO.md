# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **카드 메뉴**(`/menu`): 한 줄에 3개(메인 메뉴 3×3). 상점 구매·판매·분실물도
2. **전체 판매**: 누르면 팔릴 아이템·수량·합계가 먼저 나오고, "판매"를 눌러야 팔리는지
3. **폼 반복**: 메뉴 아이템을 누르고 있거나 여러 번 눌러도 같은 폼이 닫을 때마다 다시 뜨지 않는지
4. **서랍**
   - 자물쇠가 손잡이보다 조금 위에 보이는지
   - 앞면 좌클릭 1개, 웅크리고 좌클릭 1스택
   - 잠긴 서랍에 다른 아이템을 든 채 빠르게 두 번 우클릭 → 인벤토리의 서랍 아이템만 전부 들어가는지(다른 아이템은 안 들어감)
5. **체·자동 체**
   - 체: 자갈·모래·흙 1개 얹기, 사용할 때마다 내려가다 4번째에 부산물이 위로. 저절로는 안 걸러지고 창도 없음, 위에 글자 없음
   - 자동 체(회색 틀): 호퍼나 손으로 여러 개 넣으면 3초마다 저절로 걸러 옆·아래 상자로, 상자가 없거나 가득 차면 위로
6. **망치**: 돌·조약돌·자갈을 캐면(좌클릭) 조약돌·자갈·모래가 떨어지는지, 석재 곡괭이 정도로 빨리 캐지는지, 내구도 감소
7. **텍스처**: 새 서랍 열쇠·망치 아이콘, 자물쇠·공허 글리프
8. **섬 확장 모드**(메뉴 → 섬 확장)
   - 몸이 고정되고 카메라가 위에서 내려다보는지, 대상 청크에 알레이(커서)가 보이는지
   - 이동 키(앞=위쪽/북, 왼쪽=왼쪽/서)로 커서가 한 청크씩 움직이는지. **반대로 움직이면 알려 주세요**(설정 한 줄로 뒤집음)
   - 유리 바닥을 클릭해도 사라지지 않는지(잠깐 사라졌다 돌아오는 정도는 괜찮은지)
   - 웅크리기 또는 `/menu` → 구매·끝내기, 끝내면 카메라·이동·바닥이 원래대로
9. **코어 개편**: 새 세이브가 나무 코어 하나로 시작하는지, 레벨별로 상점에 코어가 열리고 사서 여러 개 둘 수 있는지(`/dfadmin level 10`), 코어 블록·아이템 모양(틀 + 자원 텍스처)과 이름 `[N티어] ○○ 코어`, 메뉴 → 코어 관리의 티어별 속도 강화 후 코어 우클릭 안내의 주기가 줄어드는지(`/dfadmin points 10`). 옛 세이브의 대지·생명 코어가 나무·수박 코어로 바뀌는지
10. **긴급 매입**: `/dfadmin urgent` → 제목·소리·채팅 알림, 사이드바 줄, 메뉴 본문, 메인 미션 폼의 "긴급 납품", 호퍼로 납품함에 넣기. `/dfadmin skip 30` 으로 시간 종료
11. **한글 아이템 이름**: 사이드바·미션·상점·코어 안내에 영어 ID 대신 한글
12. **2시대 초안**: `/dfadmin level 8` → 상점의 호박·수박 코어 구매·설치, 돌 괭이, Lv.9 자동 수확기(밀 등 다 자란 작물 9×9)
13. **업적·칭호**: 레벨 업·기계 설치 등에서 업적 알림, 로비 메뉴 → 칭호·치장에서 칭호·이름 색 고르기 → 채팅·이름표에 보이는지
14. **도움말**: 메뉴 → 도움말 각 항목
15. **로비·친구·세이브 폼 아이콘**, 로비 메뉴 카드
16. **작물 성장**: 밀 등을 심고 인스턴스 시간에 맞춰 단계별로 자라는지(밀 8분), 세이브를 나갔다 오면 그동안 멈춰 있는지, 줄기 옆에 4분마다 수박·호박, 코어 관리의 "작물 성장" 강화. `/dfadmin skip <분>` 으로 시간 넘기기
17. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
18. **상점 분류**: 상점 · 구매가 도구·재료 / 기계 / 코어로 나뉘어 열리고, 분류 안에서 사고 나면 같은 분류가 다시 열리는지, "← 상점"으로 돌아가는지
