# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **판매 표 아이콘**: 표 칸의 아이템이 왼쪽이 잘리지 않고 다 보이는지(16×16, 왼쪽 여백 4로 바꿈)
2. **작물 남은 시간**: 작물 우클릭 후 4초 동안 남은 시간 글자가 1초마다 줄어드는지
3. **토스트 알림**: 상점·판매 등 폼 동작의 실패(돈 부족·재고 없음 등)는 화면 위 토스트만, 구매·판매 성공은 토스트와 채팅 둘 다 오는지. 알림 폼은 더 뜨지 않고 폼은 바로 다시 열리는지
4. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
