# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

`/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계를 받을 수 있다.

1. **새 폼 테마(JSON UI)** — [json-ui.md](tech/json-ui.md)
   - 모든 폼이 어두운 창·제목 막대·닫기 버튼으로 보이는지, 버튼 아이콘·글자, 스크롤, 닫기(X·Esc)
   - 메뉴(`/menu`) → 미션·상점·판매·수표·코어·섬 확장·분실물·로비, 각 화면의 "← 메뉴로"
   - 섬 확장 지도: 9×6 격자, 화살표·내 위치, 노란 칸 → 확인 창 → 구매, 다른 칸 → 그 칸이 가운데로
   - 확인 창(예/아니오)과 입력 폼(수표 금액 등)의 모양
   - 모바일·컨트롤러 조작(가능하면)
2. **기계 창 레이아웃**: 분쇄기·체·채굴기·판매함 창에서 필요한 칸만 보이는지, 진행 화살표가 차오르는지, 오른쪽 아래 "기계 회수"
3. **상자를 연 채 떨어지기/밀려나기**: 상자(InvSee·기계)가 닫히지 않는지
4. **`/df`** 로 메뉴가 열리는지
5. **서랍 방향**: 동·서·남·북을 보며 설치했을 때 손잡이 앞면이 플레이어 쪽인지
6. **서랍 글자**: 배경 없이 더 작게, 자물쇠는 앞면 오른쪽 위에 작게, 앞면과 겹쳐 깜빡이지(z-fighting) 않는지
7. **청크 경계**: 섬 확장 화면을 열면 30초간 초록(소유)·노랑(구매 가능) 경계와 가격 글자가 잘 보이는지
8. **코어 안내**: 코어를 우클릭하면 종류·티어·생성 주기·블록별 확률이 나오는지
9. **서랍 회수**: 서랍 메뉴(웅크려 빈손 사용)의 "서랍 회수"
10. **커스텀 블록 파괴**: 서랍·납품함 1.5초, 기계·코어 2.25초 동안 계속 누르면 부서지는지(도구와 관계없이 같은 시간).
    - 원인 추정: 클라이언트는 블록 정의의 맨손 시간(기계 4.55초)으로 캐는데 서버의 금 가는 표시는 도구 시간(2~3초)이라, 표시가 끝나도 클라이언트는 아직 캐는 중이었음
11. 상자 설정 실험(선택): `platform.toml` `[ChestUI]` 의 `WaitLatency`·`Retry` 를 하나씩 켜 보고 상자가 정상인지. `Debug = true` 면 서버 로그에 열기·닫기 과정이 남는다
12. M3 협동: 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
