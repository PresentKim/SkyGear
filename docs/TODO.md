# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **카드 메뉴**(`/menu`): 한 줄에 3개(메인 메뉴 3×3). 상점 구매·판매·분실물도
2. **판매**: 전체 판매가 어두운 테마의 표(아이콘·이름·수량·개당·합계)와 아래 합계·판매·취소 버튼으로 나오는지, 표 칸을 눌러도 아무 일 없는지. 품목을 누르면 슬라이더로 개수를 고르고 그만큼만 팔리는지. 확인 창(추방·삭제 등)도 어두운 테마인지
3. **폼 반복**: 메뉴 아이템을 누르고 있거나 여러 번 눌러도 같은 폼이 닫을 때마다 다시 뜨지 않는지
4. **서랍**
   - 서랍이 손잡이 없는 정육면체(정면만 다른 텍스처)로 보이는지, 정면이 놓은 방향을 향하는지, 앞면 아이템 표시가 면에 묻히거나 떠 보이지 않는지(앞판이 0.5px 들어가 있던 예전 모델 기준으로 맞춘 위치)
   - 자물쇠가 더 작아지고 위 테두리에, 업그레이드 표시와 같은 높이로 보이는지
   - 앞면 좌클릭 1개, 웅크리고 좌클릭 1스택
   - 잠긴 서랍에 다른 아이템을 든 채 빠르게 두 번 우클릭 → 인벤토리의 서랍 아이템만 전부 들어가는지(다른 아이템은 안 들어감)
5. **체·자동 체**
   - 체: 자갈·모래·흙 1개 얹기, 사용할 때마다 얹힌 블록이 같은 모양 그대로 반 픽셀씩 내려가다 8번째에 부산물이 위로(이전처럼 다른 블록으로 바뀌지 않는지). 저절로는 안 걸러지고 창도 없음, 위에 글자 없음
   - 자동 체(회색 틀): 호퍼나 손으로 여러 개 넣으면 3초마다 저절로 걸러 옆·아래 상자로, 상자가 없거나 가득 차면 위로
6. **망치**: 돌·조약돌·자갈을 캐면(좌클릭) 조약돌·자갈·모래가 떨어지는지, 석재 곡괭이 정도로 빨리 캐지는지, 내구도 감소
7. **텍스처**: 새 서랍 열쇠·망치 아이콘, 자물쇠·공허 글리프
8. **섬 확장 모드**(메뉴 → 섬 확장)
   - 몸이 고정되고 카메라가 위에서 내려다보는지, 선택 청크가 색(소유 하늘색·구매 가능 주황·불가 빨강)과 테두리로 보이는지, 소유 청크가 체크무늬로 경계가 보이는지
   - 이동 키로 선택이 한 청크씩 움직이고 카메라가 바로 따라오는지
   - 유리 바닥을 좌·우클릭해도 사라지지 않는지(보기 전용 게임 모드), 끝내면 다시 부수고 놓을 수 있는지
   - 웅크리기 또는 `/menu` → 구매·끝내기, 끝내면 카메라·이동·바닥이 원래대로
9. **코어 기반**: 새 세이브의 코어가 원목 코어 기반 위에서 원목을 만드는지. 코어를 캐서 조약돌(상점 → 재료 탭) 위에 놓으면 조약돌로 바뀌는지, 코어 기반 옆에 물을 두면 돌이 나오고 "새 코어 레시피를 발견했습니다" 알림이 오는지. 코어 우클릭 안내(코어 기반·만드는 것·반응 없음·티어 부족), 메뉴 → 코어 관리 → 코어 도감(???·단서·★). 코어 블록·아이템의 티어별 색(1 초록·2 파랑·3 보라·4 금). `/dfadmin level 10`, `/dfadmin give core_t3`
10. **긴급 매입**: 화면 위 보스바(품목·납품 수·남은 시간, 게이지가 줄어드는지), 다 채우면 바로 끝나는지.  `/dfadmin urgent` → 제목·소리·채팅 알림, 사이드바 줄, 메뉴 본문, 메인 미션 폼의 "긴급 납품", 호퍼로 납품함에 넣기. `/dfadmin skip 30` 으로 시간 종료
11. **한글 아이템 이름**: 사이드바·미션·상점·코어 안내에 영어 ID 대신 한글
12. **2시대 초안**: `/dfadmin level 8` → 상점의 호박·수박 코어 구매·설치, 돌 괭이, Lv.9 자동 수확기(밀 등 다 자란 작물 9×9)
13. **업적·칭호**: 레벨 업·기계 설치 등에서 업적 알림, 로비 메뉴 또는 세이브 안 메뉴(/menu → 칭호·치장, /title)에서 칭호·이름 색 고르기 → 채팅·이름표에 보이는지
14. **도움말**: 메뉴 → 도움말 각 항목
15. **로비·친구·세이브 폼 아이콘**, 로비 메뉴 카드
16. **작물 성장**: 작물 우클릭 → 남은 시간 글자(4초, 하나만), 다 자란 작물 우클릭 → 수확·자동 심기, 작물 위에 블록이 놓이지 않는지(웅크리면 놓임).  밀 등을 심고 인스턴스 시간에 맞춰 단계별로 자라는지(밀 8분), 세이브를 나갔다 오면 그동안 멈춰 있는지, 줄기 옆에 4분마다 수박·호박, 코어 관리의 "작물 성장" 강화. `/dfadmin skip <분>` 으로 시간 넘기기
17. **기간제 아이템**: `/dfadmin timed 60` 으로 든 아이템에 "기간제 · …까지" 설명 줄이 붙는지(한국 시간), 1분 뒤 사라지고 채팅 알림이 오는지, 기간제 아이템이 일반 아이템·다른 만료 시각 아이템과 한 서랍에 섞이지 않고 판매함·납품함에는 안 들어가는지, 서랍 안에서 만료되면 서랍이 비는지
18. **상점 탭**: 위쪽 탭(도구·재료·설비·기계·코어)이 보이고 첫 탭이 선택된 채 열리는지, 탭을 눌러 바뀌는지, 상품이 작은 카드로 한 줄 5개, 재고가 "재고 n"으로만, 닫기 버튼 왼쪽에 뒤로 버튼(다른 메뉴도 같은 자리)이 있는지
19. **선물 요정·연구 노트**: `/dfadmin fairy` → 이름표 없는 알레이가 주위를 자연스럽게 날아다니는지, 우클릭·좌클릭 모두 맞는 동작 없이 선물을 내 쪽으로 던지고 위로 날아가는지(2분 두면 그냥 떠나는지). `/dfadmin give research_note` 를 들고 우클릭 → 단서 메시지, 코어 도감의 `???` 에 단서가 붙는지. 노트 텍스처
20. **폼 알림**: 상점에서 돈이 부족하거나 재고가 없을 때 "알림" 폼이 뜨고 확인을 누르면 상점으로 돌아가는지, 구매·판매 결과가 다시 열린 폼 위쪽에 한 줄로 보이는지. 친구·세이브 메뉴의 오류도 같은지. 상점 탭·닫기 왼쪽 뒤로 버튼이 이번에는 보이는지
21. **기계 창 정보 아이콘**: 기계 창 제목 줄 닫기 버튼 왼쪽에 정보 아이콘이 자연스러운 위치·크기로 보이는지(위치는 어림값, 실기로 맞춤), 툴팁에 설명, 진행 화살표 툴팁에는 진행도만, 회수 버튼이 없어졌는지
22. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
