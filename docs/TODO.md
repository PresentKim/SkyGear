# 해야 할 일

진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체(`auto_sieve`), 망치(`hammer`), `/dfadmin item <이름>` 으로 아무 아이템을 받을 수 있다.

1. **판매 표 아이콘**: 표 칸의 아이템이 왼쪽이 잘리지 않고 다 보이는지(16×16, 왼쪽 여백 4 → 7로 더 옮김, 11차 실기)
2. **WAILA 패널**(11차 뒤 바뀐 것):
   - 상자·통·화로 칸 오른쪽 아래에 **수량**이 보이는지(`§f` 로 시작하게 바꿈)
   - 체·분쇄기: "흙 [작은 아이콘] ×3 ◔" 줄, 비면 회색 "비어있음"
   - 서랍: "횃불 [작은 아이콘]" 만(수량·잠금·업그레이드 없음)
   - 게이지 링 크기(약 60%)와 0.2초 갱신이 부드러운지
   - 우리 블록의 도구 아이콘(서랍·납품함 도끼, 기계·코어 곡괭이, 들면 ✓)
   - 제목 접두어를 `_waila` 로 바꾼 뒤에도 패널·도구 아이콘·상자 칸이 그대로 나오는지(팩 위치 자르기를 모두 1씩 옮김)
3. **서랍**: 옆·뒤에서는 메뉴도 안 열리는지, 인벤토리가 꽉 찼을 때 꺼낸 아이템이 발밑에 떨어지는지, 빈 서랍을 잠그면 호퍼로는 안 들어가고 손으로는 들어가는지
4. **자동 농작물 수확기**: 씨앗(거둔 것 또는 수확기 결과 칸)이 있을 때만 다시 심고 씨앗이 줄어드는지. **자동 자원 채굴기** 창이 결과 1칸으로 나오는지
5. M3 협동(나중에): 클라이언트 두 대로 친구·초대 코드·친구 초대 수락 창·추방·인벤토리 보기(꺼내기·넣기·Shift 이동, 대상 쪽 실시간 반영)
