진행 중이거나 미뤄 둔 일만 둔다. 끝나면 지우고, 실기 결과는 [실기 기록](tech/playtest-log.md) 에 차수별로 남긴다.

## 지금 실기로 확인할 것

운영자 도구는 [admin.md](tech/admin.md). `/dfadmin give <ID>` 로 서랍(`drawer`), 잠금 키(`drawer_key`), 업그레이드, 기계, 체(`sieve`)·자동 체 등을 받는다.

1. **18차 실기**: 조합대·벗긴 나무 같은 바닐라 블록 이름이 WAILA 패널에 한국어로 나오는지(클라이언트 번역 키를 쓴다. 키가 맞지 않으면 `tile.xxx.name` 글자가 그대로 보일 수 있으니 알려 주세요), 체 메쉬 판의 깜빡임(z 파이팅)이 사라졌는지, 빈손 숙이고 우클릭이 빈 체의 메쉬를 빼내는지(메쉬 끼우기·빼기는 눌린 체 하나만), 기본 실 메쉬가 자갈·모래·흙·먼지에서 철 원석 조각까지만 주는지(구리는 부싯돌 메쉬부터, 금은 철 메쉬부터), 실 메쉬 3×3 조합과 상위 메쉬의 두 조합(실 메쉬 + 재료 1개, 가운데 재료 + 둘레 실)이 되는지

2. **리소스팩 암호화·minify**(19차): 서버를 새로 켜고 접속해 팩이 정상으로 적용되는지(텍스처·모델·UI·WAILA·이름). 안 열리거나 UI 가 깨지면 `platform.toml` 의 `[ResourcePack]` `Encrypt`/`Minify` 를 하나씩 꺼 보고 알려 주세요([resourcepack.md](tech/resourcepack.md))

3. **돌 배럴·용암**(20차): "돌 배럴" 연구(돌 32) 뒤 돌 6 + 막대기 2 로 돌 배럴, 실 1 + 숯 1 로 촛불이 되는지. 촛불 위에 돌 배럴을 두고 조약돌 8개를 채우면 2분 뒤 용암이 되는지(용암·마그마 블록 위에서는 4배·8배), 빈 양동이로 용암 양동이를 얻는지, WAILA 패널의 남은 시간. 돌 배럴 그림 세 장(`barrel_stone`·`barrel_cobble`·`barrel_lava`)은 임시 그림. 물과 용암으로 조약돌 생성기를 만들어 자동 채굴기로 돌을 얻을 수 있는지

4. **전기(RE)·발전기·전기 도관**(20차, [06](design/06-power-and-conduits.md)): "연소 발전기" 연구(철 16, 선행: 철 가공·화로) 뒤 발전기를 만들 수 있는지(철 6 + 화로 + 레드스톤 2), 연료(석탄·숯·판자…)를 창이나 호퍼로 넣으면 WAILA 에 전기가 차오르는지. "전기 도관" 연구 뒤 철 2 + 레드스톤 1 → 도관 4개, 도관을 이어 놓으면 이어진 면에 팔이 뻗는지(모양 64가지, 그림은 임시), 발전기 – 도관 – 분쇄기 라인에서 분쇄기가 일하고 전기가 없으면 "전기가 모자라 멈춤"이 뜨는지. **분쇄기·자동 체·채굴기·수확기는 이제 전기를 쓰고, 연구도 발전기가 먼저다**(옛 세이브의 기계는 발전기를 놓아야 돈다). 도관 연결 판정·손맛(설치 방향, 부술 때, 구멍으로 보이는지). **아이템 도관**: 연구("아이템 도관", 선행 호퍼) 뒤 철 2 + 실 1 → 4개, 상자 사이에 놓으면 이어지는지, **숙이고 빈손으로 면을 우클릭**하면 모드(양쪽 → 꺼내기만 → 넣기만 → 꺼짐)가 바뀌고 꺼짐이면 팔이 사라지는지, 1단계가 0.4초에 1개, 금 4개, 다이아몬드 16개로 나르는지, 분쇄기 아래에 도관을 두면 결과가 나오는지. 금·다이아몬드 도관 업그레이드 조합(4개 + 금/다이아 1개)

## EnderIO 도관 포팅 후속
- 실기 확인: 도관 팔·코어에 EnderIO 텍스처가 맞게 보이는지(UV 배치), 투명 영역 처리.
- 면별 설정 폼(채널·우선순위·라운드로빈) → 아이템/에너지 도관에 적용.
- 번들 실기 확인(가장 불확실): ① 도관 아이템을 놓으면 블록이 생기는지(번들), 이미 있는 도관에 다른 종류를 놓으면 합쳐지는지, 클라이언트에 옆칸 유령 블록이 남지 않는지 ② 전기+아이템 번들의 대각선 모양과 단계별 텍스처(뼈대 이름으로 고른 `material_instances`, permutation 병합) ③ 1024개 상태·1008개 permutation 과 지오메트리 192개(약 2MB)로 접속이 느려지지 않는지, 다른 블록 텍스처(참나무 판자 등)가 정상인지 ④ 선택 상자 크기.
- 도관 재료: 모래·자갈 체크무늬 → 도관 결합 반죽(6개) → 화로 → 결합체 → 기본 전기/아이템 도관 8개(결합체 위아래 줄, 가운데 레드스톤 3개 / 철 조각·상자·철 조각). 연구(전기 도관·아이템 도관)가 반죽 레시피를 여는지, 반죽이 창작 인벤토리·레시피 책에 나오는지, 아이콘(EnderIO 그림).
- **도관 표시 엔티티(21차)**: 도관 모양을 블록 상태 대신 표시 엔티티로 그린다(`docs/tech/conduits.md`). 실기에서 확인: ① 도관을 놓으면 코어와 가는 팔이 보이는지(엔티티 `conduit_visual`, 렌더 컨트롤러가 `query.variant`를 푸는지) ② 팔이 올바른 방향(동서·남북)으로 뻗는지(안 맞으면 `tools/conduitgeo`의 `flipZ` 를 바꾸고 재생성) ③ 전기만 이어지는 면에는 전기 팔만 뻗는지, 아이템도 마찬가지 ④ 전기+아이템 번들에서 두 줄이 겹치지 않고 위·아래·옆에서 다 보이는지 ⑤ 연결이 바뀌면 팔이 즉시 바뀌는지 ⑥ 부수면 모양이 사라지는지(엔티티가 남지 않는지), 접속을 끊었다 들어와도 모양이 있는지 ⑦ 도관 100칸 이상 깔았을 때 프레임·접속 시간 ⑧ 새 아이템 아이콘(`conduit_energy_N`) ⑨ **옛 도관**(번들 이전에 놓은 것)이 한 틱 뒤 새 모양으로 바뀌는지 ⑩ 선택 상자(3~13픽셀)로 도관을 찍을 수 있는지.
- **도관 2차(표시 엔티티 후)**: ① 인벤토리·손의 도관 아이템이 블록(짧은 파이프)으로 보이는지, 텍스처(전기 빨강·아이템 청록·액체 파랑 슬롯) ② 부술 때 균열·파편이 보이는지(10픽셀 투명 큐브 + 회색 텍스처 방식이 통하는지; 안 되면 큐브 크기나 UV 조정) ③ 액체 도관(`/dfadmin give fluid_conduit_1`)을 전기·아이템과 한 블록에 넣었을 때 세 차선(−3 / 0 / +3)이 모든 방향에서 나란히 보이는지, 팔 방향 ④ 도관 블록에 없는 종류를 우클릭하면 그 안에 들어가는지, 있는 종류는 안 놓이는지 ⑤ 숙이고 우클릭하면 옆 칸에 새로 놓이는지 ⑥ 도관 너머의 블록을 찍어도 도관 칸에 들어가는지 ⑦ 통 옆에 액체 도관을 두면 팔이 뻗는지.
