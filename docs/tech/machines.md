# 기계

기획: [02-skygear.md §11](../design/02-skygear.md). 코드: `content/skygear/machine.go`.

## 구조

- `Machine{Kind}` 하나의 블록 타입이 종류(`crusher`, `sieve`, `auto_sieve`, `auto_miner`, `harvester`, `alloy_smelter` …)마다 따로 등록된다.
  식별자는 `skygear:<종류>`. 모델·텍스처는 리소스팩 `assets/resourcepack/skygear/`(`models/blocks/`, `textures/`), Go 는 식별자·재질 이름만(`blockmodel/models.go`·`sieve.go`).
- 체 세 종류는 상태 하나(`skygear:look`, 끼운 메쉬 단계×내용물×높이의 번호 `000`~)가 있는 블록이라 메쉬(여섯 단계, 단계마다 색이 다른 `sieve_mesh_<단계>` 텍스처를 입힌 가로세로 막대 여덟 개)와 내용물·진행(8단계, 높이 6픽셀에서 1픽셀까지)이 모델에 보인다. 모델과 메쉬 텍스처는 Ex Nihilo Fabrico 의 체·메쉬 모델에서 `tools/fabricotex` 가 만든다(창 없음, [sieve.go](../../content/skygear/sieve.go)). 상태를 하나로 둔 것은 클라이언트가 런타임 ID를 상태 순서대로 짝짓기 때문이다.
- 설치된 기계는 `machineState`(포인터)를 가진다. Dragonfly 상자처럼 블록 값이 상태를 가리키고,
  블록 엔티티 NBT(`Items`, `Progress`, `Owner`, `OwnerName`)로 월드와 함께 저장된다.
  설치는 `HandleBlockPlace` → `placeMachine` 이 새 상태로 바꿔 놓는다.
- 기계 인벤토리 = 27칸 `chestui.Storage` 그 자체. 창의 칸이 곧 입력·출력 칸이고, 나머지는 회색 판유리(조작 불가).
  창 제목의 표식(`§d§m§<n>`)으로 리소스팩이 기계별 레이아웃을 골라 필요한 칸만 보여 준다([json-ui.md](json-ui.md)). 자동 농작물 수확기는 채굴기 레이아웃(`§d§m§3`)을 같이 쓴다. `§d§m§2`는 링·출력 4칸·게이지가 있는 레이아웃이다.
- 진행도 칸에는 진행 화살표 아이템(`progress_0`~`progress_10`)이 10% 단위로 들어간다.
- 26번 칸은 **정보 아이콘**(`skygear:machine_info`)이다: 이름은 기계 이름, 설명(툴팁)은 하는 일. 칸 배치가 아니라 창 오른쪽 위 모서리 위의 어두운 컨트롤 막대(`sg_machine.control_bar`, 메뉴 화면의 컨트롤 막대와 같은 모양)에 닫기 버튼 왼쪽으로 그려지고, 모든 기계 창에서 같은 자리에 있다.
- **모두 꺼내기·모두 넣기**는 모든 창고와 같은, 창 오른쪽 바깥의 세로 버튼 줄이다(common inventoryui `ui/sg_quick.json`, [chestui.md](chestui.md)). 클라이언트가 칸마다 빠른 이동(쉬프트 클릭)을 하므로 서버 버튼이 없다. 기계 창에서는 레이아웃마다 꺼낼 칸을 출력 칸으로 거르고(`sg_machine.json` `$sg_machine_outputs`, `quickbar_test.go` 가 `machineKinds` 와 맞는지 본다), 넣기는 핫바까지 옮긴다. 클라이언트는 빈 칸 아무 데나 넣으려 하므로, 입력이 아닌 칸에 놓이는 아이템을 서버가 취소하고 기계가 받는 것이면 같은 월드 작업으로 입력 칸에 채운다(`machineHandler.HandlePlace`, `putFrom`: 같은 종류가 있는 칸에 먼저, 없으면 빈 칸 하나에, 안 들어가는 것은 플레이어에게 남음). 손으로 하는 쉬프트 클릭도 같다.
- 진행 칸(화살표)에는 진행도만 쓴다. 기계는 블록을 부수면 내용물과 함께 나온다. 여러 명이 같이 열어도 같은 내용이 보인다.
- 블록 `Tick`(20틱/초)으로 동작한다. 인스턴스가 활성인 동안만 돈다. 로드 반경 밖의 소유 청크는 청크별 로더로 계속 돈다.
- 진행도는 기계 창과 WAILA 에서, 체는 모델로 본다.

## 아이템 이동

- 호퍼: 위·옆 호퍼 → `InsertItem`(입력에 받을 수 있는 아이템만 1개씩), 아래 호퍼 ← `ExtractItem`(출력에서 1개씩).
- 받을 수 없는 아이템(분쇄기에 흙 등)은 호퍼에 남는다.
- 기계는 결과를 이웃에 밀어 넣지 않는다. 결과 칸에 쌓이고, 아래 호퍼나 어느 면의 아이템 도관이 꺼낸다.
- 체의 부산물은 칸에 두지 않는다: 손 체는 위로 떨군다. 자동 체는 창의 출력 칸 4개에 쌓고(손 체 클릭으로는 진행하지 않는다, 클릭하면 창이 열린다), 칸에 자리가 없으면 멈춘다. 창은 `sieve_slots` 배치(제목 표식 §d§m§2): 입력 10, 링 12, 출력 13~16, 에너지 게이지 17. 출력 칸에 자리가 없으면 걸러 낸 물건은 기계 안(pending)에 두고 자리가 날 때까지 기다린다(부술 때 같이 나온다). 종류가 4개보다 많은 체 표도 돈다.
- 자동 농작물 수확기: 같은 높이 9×9에서 다 자란 밀·당근·감자·비트를 거둬 다시 어린 작물로 두고, 수박·호박 블록을 자르고, 핀 마법 식물을 거둔다.
- 자동 자원 채굴기: 캐는 동안 주변 플레이어에게 그 블록이 금 가는 모습(`StartCrackAction`, 남은 시간)을 보내고 다 캐면 부서지는 파티클을 낸다.
  아래 블록이 일반 블록(블록 엔티티·액체·부술 수 없는 블록 제외)이면 돌 곡괭이로 캔 결과를 출력 칸에 넣는다.

## 기계의 한 틱과 강화 단계

- `Machine.Tick`이 상태를 `session.machines`에 올리고 `st.stuck`을 지운 뒤, `st.reps()`번 `runMachine`(종류별 동작)을 돌린다. 막히거나(`stuck`) 아무 진전이 없는 반복은 멈춘다. 에너지는 `tickWork()`가 `consume()`으로 쓴다.
- 강화 단계(`machineState.tier`, NBT `Tier`)는 `tier.go`의 `tierSpecs`가 정한다: 반복 횟수(속도), 작업당 에너지(`useCost`), 버퍼(`energyCap`), 발전량·연료 속도, 범위(`reach`). 발전기·에너지 셀은 반복하지 않는다.
- 출력은 `emit`·`roomFor`를 쓴다([monitor.md](monitor.md)).
- 마법 체는 자동 체 코드(`runAutoSieve`)를 같이 쓴다.

## 주기형 기계의 링 게이지

자동 농작물 수확기(2초)처럼 주기마다 반복하는 기계는 진행 칸에 화살표 대신 **채워지는 빈 원(링)**(`skygear:cycle_0`~`cycle_10`, `textures/items/cycle_*.png`)을 보인다. 주기는 할 일이 있든 없든 계속 돈다(수확할 작물이 없어도 100%에서 멈추지 않는다). 진행 칸 아이템은 10% 마다 바뀌어 링이 도는 것처럼 보인다.

## 정육면체 블록 (모델링 없음)

자동 자원 채굴기·자동 농작물 수확기는 모델 없이 바닐라 정육면체(`minecraft:geometry.full_block`)에 텍스처를 붙인다(`blockmodel/models.go` `CubeProperties`).
텍스처는 `textures/blocks/<이름>_<side|up|down>.png` 3장: 네 옆면은 `side` 하나를 같이 쓴다(방향 없음).
이름은 `auto_miner`, `harvester`다. 면 그림만 바꾸려면 PNG를 교체한다.
놓는 방향으로 돌지 않는다.

분쇄기도 모델 없는 정육면체지만 정면이 따로 있다(`blockmodel.FrontCubeProperties`): `textures/blocks/<이름>_<front|back|side|up|down>.png` 5장, 정면 **남쪽**·후면 북쪽·좌우 두 옆면은 `side` 공통. 블록 아이템은 인벤토리에서 남쪽 면이 보이게 그려지므로 정면을 남쪽에 둔다(서랍은 기본 상태를 남쪽으로: `drawerFacings`). 블록 아이템은 인벤토리·폼에서 블록 모양 그대로 보이므로 아이템 아이콘 텍스처는 두지 않는다.

## 에너지 게이지

에너지를 담는 기계의 창에는 **에너지 게이지**가 있다: 창 오른쪽 열(슬롯 17, `energyGaugeSlot`)에 건전지 그림이 10단계로 차오르고(`EnergyGauge`, `textures/items/energy_gauge_N.png`, 임시 그림), **마우스를 올리면** "에너지 보유량/최대량 RE"가 뜬다(`showEnergy`, 0.5초마다 갱신). 레이아웃은 `ui/sg_machine.json`의 `s17@sg_machine.indicator`. 운영자 시험 공장(`unlimited`)의 기계는 가득 찬 것으로 보인다.
