# 실기 확인 기록

실제 Bedrock 클라이언트로 확인한 결과만 차수별로 남긴다. **지금 확인할 항목은 [TODO](../TODO.md) 에만** 둔다.
자동 테스트(단위 테스트, `spike/scenarios` 봇)로 확인되는 내용은 여기에 적지 않는다.

## 1차 (2026-10-08, Windows 1.26.52)

| 항목 | 결과 | 조치 |
|---|---|---|
| 코어·납품함 텍스처 | 정상 | - |
| 코어 생성 | 3초보다 빠르게, 때로 즉시 | 수정: 위 칸이 빈 동안만 주기를 센다 |
| 보이드 복귀 | 정상 | - |
| 분실물 수집 | 정상. 상자 화면은 안 열림 | 상자 열기 수정(아래 차수) |

| 납품함 폼 버튼 | 이유 없이 끊김 | 패킷 오류 시 이유 표시·ERROR 로그, 없는 폼 응답 무시, 연타 방지 |

| Xbox 인증 | 정상 | - |
| 엔티티 상자 | 블록 클릭 시 열렸다 닫힘, 폼 뒤에 안 열림, 닫힘 반복 후 끊김 | InvMenu 방식 시도(2차) |
