# UI 스타일 가이드

메뉴(DDUI 화면)·기계 창·HUD 의 모양과 쓰는 규칙. 창·탭·컨트롤 막대·칸은 바닐라 그림을 가리켜 쓴다([vanilla-ui.md](vanilla-ui.md)). 메뉴 화면의 구현은 [oreui.md](oreui.md), 창고 창·HUD 의 JSON UI 는 [json-ui.md](json-ui.md), 칸 장식은 [slotdeco.md](slotdeco.md), 성능 규칙은 [codex-jei.md](codex-jei.md).

## 팔레트

게임 기본 화면 같은 **회색 테마** 하나를 쓴다. 화면의 모양은 `assets/resourcepack/oreui/hbui/oui-mc.css` 가 정하고, 버튼·창 그림의 색은 `tools/uitextures/main.go` 위쪽 한 곳에서 정해 그 도구가 `assets/resourcepack/sgui` 에 그림을 만든다(없는 것만, `-f` 는 모두).

| 쓰임 | 색 | 값 |
|---|---|---|
| 창 안의 판(`panel`) | 밝은 회색 + 검은 테두리, 위·왼쪽 흰 선, 아래·오른쪽 어두운 선 | `(198,198,198)` / `(255)` / `(85)` |
| 제목 | 제목 막대 없이 창 위에 가운데 정렬한 어두운 글자 | 글자 `0.2` |
| 버튼 / 호버 / 눌림 | 중간 회색 / 푸른 기 도는 밝은 회색 / 어두운 회색(들어간 모양) | `(66)` / `(84,84,128)` / `(48)` |

글자: 창 위의 글은 어두운 회색, 버튼 위의 글은 흰색이다. 코드의 색 코드(`§f` 이름, `§7` 보조, `§8` 흐린 보조, `§e` 머리글, `§a` 좋음, `§c` 나쁨)는 **어두운 배경 기준**으로 적혀 있어서, 창 위에 바로 그려지는 글(`ink: "panel"` 아래의 본문·머리글·상세)은 렌더러가 어두운 변형으로 바꾼다(`§f→§0`, `§7→§8`, `§8→§7`, `§e→§1`, `§6→§4`, `§a→§2`, `§b→§3`, `§c→§4`, `§d→§5`, `oui-ddui.js`). 버튼 위 글, 칸 개수와 툴팁은 그대로 둔다. 등급 색은 이름에만 쓴다(`§a` 고급, `§b` 희귀, `§d` 영웅, `§6` 전설). 로비 화면은 남색 창에 밝은 글이다([oreui.md](oreui.md) "로비 화면").

## 화면의 종류

| 종류 | Go | 쓸 때 |
|---|---|---|
| 카드 격자 | `ui.CardMenu` | 같은 무게의 갈래 6~12개(메뉴, 도움말, 도감 첫 화면) |
| 목록 | `ui.Menu`, `ui.Confirm` | 항목이 글 위주이고 몇 개~수십 개, 예·아니오 질문 |
| 칸 격자 | `ui.ItemGrid`, `ui.ItemGridSections`, `ui.SearchGrid`, `ui.ItemBoard` | 아이템이 주인공(스토리지, 도감 검색, 레시피) |
| 분할 | `ui.SplitMenu`, `ui.ListSplitMenu` | 목록에서 고른 항목의 동작을 같은 창 오른쪽에(연구, 세이브 선택, 친구, 멀티 플레이, 참여자 관리) |
| 퀘스트 책 | `ui.QuestBookMenu` | 선후 관계가 있는 노드(발전과제, [advancement-tree.md](advancement-tree.md)) |
| 선택 판·면 설정 | `ui.ChoiceMenu`, `ui.SidesMenu` | 설정 고르기(요정의 마법판), 블록 면마다 설정(도관) |
| 탭 | `ui.Tab` | 같은 창의 서로 다른 **보기**를 오가는 화면: 생산 통계(생산·에너지·정지), 도감(검색·체·가공·몬스터·식물), 칭호·치장(칭호·이름 색·업적), 친구(친구·차단, 알림 화면으로 가는 탭). 탭은 창 위에 붙은 아이콘 칸(24×22)이고 글은 툴팁으로 뜬다 |
| 쪽 넘김 | `ui.Pager`, `ui.BarPager` | 긴 목록을 나눌 때. 모든 쪽 넘김이 같은 글("이전 쪽 (1/3)")·같은 아이콘 |
| 뒤로 / 도움말 | `ui.Back`, `ui.Help` | 컨트롤 막대의 닫기 왼쪽 작은 버튼. 뒤로 가기는 한 단계 위(대부분 카드 메뉴)로 간다 |

- 탭과 카드를 섞지 않는다: **갈래를 고르는 것은 카드, 한 화면의 보기를 바꾸는 것은 탭**.
- 쪽 넘김은 탭이 아니다. 탭 줄에는 보기 탭만 둔다.
- 입력은 `ui.Input`(한 줄)으로 한다. 검색은 창 안의 검색칸과 결과 격자다(`ui.SearchGrid`: 스토리지 목록, 도감).

## 목록 분할 화면

세이브 선택·친구·멀티 플레이·참여자 관리는 같은 모양이다(`ui.ListSplitMenu`).

- 왼쪽 목록에는 새로 만드는 줄을 둔다: 빈 슬롯(세이브 만들기), 친구 추가, 초대 코드 입력. 이 줄은 누르면 바로 그 입력 창을 연다. 같은 일을 하는 버튼을 오른쪽에 또 두지 않는다(한 화면에 같은 기능은 한 번만). 자기 세이브 안의 초대 코드 줄은 코드를 보여 주고, 고르면 오른쪽에 다른 일(새 코드)이 나온다.
- 줄 글은 이름과 그 아래 작은 정보 줄(일차·플레이 시간, 로비/플레이 중/오프라인, 남은 분)이다(`ui.ListRowText`). 상태는 줄에서 보이므로 오른쪽 본문에 다시 쓰지 않는다.
- 오른쪽 첫 버튼은 전체 폭의 주된 동작(입장, 참여, 수락), 나머지는 두 칸씩. 지우기·차단처럼 되돌릴 수 없는 동작은 뒤쪽에 둔다.
- 숫자·코드 같은 짧은 정보는 본문보다 그 버튼 글에 넣는다("초대 코드 NGYKA6", "참여자 1/4"). 본문이 버튼을 밀어 내려 스크롤이 생기지 않게 한다.
- 확인 질문(삭제, 차단, 추방, 새 코드)의 취소는 화면을 닫지 않고 원래 화면의 같은 줄로 돌아간다(platform `pf.confirm`). 동작이 끝나도 같은 화면을 다시 보낸다: 결과가 목록에 보이므로 따로 알리지 않는다.
- 목록이 비면 왼쪽 칸은 그대로 두고 오른쪽 본문에 짧은 명사구("받은 친구 요청이 없습니다.")만 쓴다.

## 버튼 아이콘

버튼 아이콘은 그 버튼이 하는 일을 그림만 보고 알 수 있어야 한다. 바닐라 그림(아이템·블록·`textures/ui`)이 그 뜻을 말하면 그대로 쓰고(세이브=잔디, 삭제=방벽, 이름 변경=이름표), 말하지 못하면 팩에 아이콘을 둔다: `skygear` 팩 `textures/ui/sg/icon_*.png`(16×16 RGBA, deep-pixels 로 그려 배경을 투명하게) — 입장(문으로 들어가는 화살표), 친구 추가, 수락(초록 체크), 거절(빨간 X), 받은 요청(봉투), 초대(초대장), 초대 코드(열쇠), 참여자(두 사람), 추방(문 밖 화살표). 로비의 흰 선 아이콘(`icon_cube`·`icon_people`·`icon_person`·`icon_crown`·`icon_help`)은 `assets/resourcepack/sgui` 에 있다.

## 고른 칸

격자에서 지금 보고 있는 칸(고른 연구, 도감의 고른 블록·설비)은 금색 두 줄 테두리 칸(`slot_chosen`)이다. 호버한 칸과 구별되고, 눌리지 않는다(`ItemSlot.Selected`).

## 화면 제목

메뉴 아래로 한 단계 들어간 화면의 제목은 `ui.SubTitle(상위, 하위)` 로 "상위 · 하위"다(도감, 장비 제작대, 칭호·치장). 맨 위 줄에서 블록·설비를 고르는 화면은 고른 것의 이름을 하나 더 붙인다("도감 · 가공과 합금 · 분쇄기", JEI 의 분류 이름처럼).

## 탭 모양

탭은 창조 인벤토리 탭처럼 아이콘만 있는 칸이다: 바닐라 탭 그림(`TabTopBack`)으로 낮게 놓이고, 포인터가 올라오면 밝아지며(`TabTopBackHover`) 탭 이름이 툴팁으로 뜨고, 선택된 탭은 창과 같은 색(`TabTopFront`)으로 한 칸 솟는다(`oui-mc.css` `.mc-tab`). 연구·친구 화면도 같은 아이콘 탭이다.

## 칸과 아이템

- 아이템 칸은 바닐라 칸(`cell_image`)에 아이템 그림, 오른쪽 아래 개수, 툴팁으로 이름·설명. 개수는 1만부터 `12k`(`ui.CountText`).
- 등급이 있는 아이템은 칸 뒤 색 테두리와 이름 색으로 보인다(DDUI 화면은 `deco_<희귀도>_0`). 창고 창에서는 단계 점, 문제는 빨간 느낌표 배지(기계 정보 아이콘)도 보인다([slotdeco.md](slotdeco.md)). 같은 규칙이 가방·상자·기계 창·인벤토리 보기에 한꺼번에 적용된다.
- 기계 창은 제목 줄 오른쪽에 정보 아이콘이 있고, 모든 창고처럼 창 오른쪽 바깥에 모두 꺼내기·모두 넣기 버튼이 세로로 있다([machines.md](machines.md)).

## 창 겉모양(게임 기본 화면 기준)

- 창은 바닐라 인벤토리 크기(326×166) 하나다(퀘스트 책 포함, [oreui.md](oreui.md)). 내용이 넘치면 창 안이 스크롤된다.
- 창은 바닐라 `dialog_background_opaque` 다. 창 안의 판(`.mc-panel`: 분할 화면의 왼쪽, 선택 판의 수치)은 `panel` 그림으로, 위·왼쪽 흰 선과 아래·오른쪽 어두운 선을 직접 갖고 모서리가 둥글다(`tools/uitextures` 의 `roundCorners`).
- 제목은 막대 없이 창 위 가운데에 쓴다. 쪽 화살표·도움말(?)·뒤로·닫기는 창 오른쪽 위 모서리 위에 붙은 어두운 둥근 막대(바닐라 `toolbar_background`)에 둔다. 틀은 없고 포인터가 올라오면 칸이 밝아진다.
- 탭은 창 위 왼쪽 가장자리에 붙는다.
- 카드(72×46)의 아이콘은 22px 이고 카드 가운데에 놓인다(이름은 아래).
- 뒤로 버튼은 픽셀 꺾쇠 그림(`chevron_left`)이고, 호버·누름은 닫기 버튼처럼 테두리 없는 회색 정사각형(`hover_flat`, `press_flat`)이다.
- 화면 뒤는 어둡게 한다(`.mc-screen`, 투명도 0.5). 로비 화면은 로비 섬이 보이도록 위·아래만 옅게 그늘진다.
