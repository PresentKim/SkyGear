# M2 실기 확인 목록

자동 테스트(단위 테스트, 테스트 클라이언트)로 확인한 것과, **실제 Bedrock 클라이언트로만 확인할 수 있는 것**을 나눈다.

## 자동 테스트로 확인됨

- 코어: 주기 생성, 같은 종류 두 번째 사본 제거, 재발급 시 이전 사본 무효, 설치 검증
- 미션: 납품·레벨 업·보상, 필요한 만큼만 회수, 납품함 호퍼 입력(필요 없는 아이템은 호퍼에 남음)
- 상점: 재고·하루 재입고·1회 한정, 레벨 제한 / 판매: 하루 예산·품목 한도·다음 날 회복
- 수표: 발행·사용, 복사본·다른 세이브 수표 거부
- 섬: 소유 청크 보호, 구매 가능 청크(맞닿음 + 로드 반경), 보이드 복귀 위치 탐색
- 분실물: 보이드 아이템 수집·같은 아이템 합치기·하루 뒤 만료
- 서랍: 넣기/꺼내기/용량/잠금/공허, 아이템 NBT 보존, 호퍼 입출력, 표시 엔티티 생성·자동 정리
- 실제 서버 + 테스트 클라이언트: 접속 → 세이브 생성 → 메뉴·상점·미션 폼 흐름

## 실제 클라이언트로 확인 필요

| # | 항목 | 확인할 것 |
|---|---|---|
| 1 | 코어 · 납품함 · 서랍 텍스처 | 코드로 만든 임시 텍스처가 보이는지(대지 코어: 갈색+초록 중앙, 납품함: 나무색+금색 중앙, 서랍: 앞면에 손잡이) |
| 2 | 대지 코어 생성 | 코어 위 블록을 캐면 **정확히 3초 뒤** 새 블록이 생기는지, 코어가 은은하게 빛나는지 |
| 3 | **서랍 방향** | 서랍을 동·서·남·북을 보며 설치했을 때 **손잡이 있는 앞면이 플레이어 쪽**인지. 반대로 보이면 회전 부호 수정 필요(`drawer.go` `facingRotation`) |
| 4 | 서랍 표시 | 앞면의 아이템이 확정된 깊이로 보이는지, 수량 글자(이름표) 위치가 앞면 아래쪽에 보기 좋게 있는지 |
| 5 | 서랍 조작 | 앞면 우클릭 넣기, 빠른 두 번 우클릭 전체 넣기, 앞면 때리기 1스택, 웅크려 때리기 1개, 앞면을 계속 때려도 안 부서지는지, 옆면 채굴 |
| 6 | 서랍 업그레이드 | 업그레이드 아이템 텍스처, 앞면에 사용해 장착, 웅크려 빈손 사용 → 메뉴에서 떼기 |
| 7 | 보이드 복귀 | 섬 밖으로 떨어지면 가까운 블록 위 높은 곳에서 다시 떨어져 피해 없이 착지하는지 |
| 8 | 분실물 보관함 | 아이템을 공허로 던진 뒤 `/menu` → 분실물 보관함에 들어오는지 |
| 9 | 사이드바 | 레벨·일차·미션·돈 표시가 잘 보이는지 |
| 10 | 섬 확장 | 청크 지도에서 위치·방향이 잘 보이는지, 구매 후 그 청크에서 건축 가능, 밖은 막히는지 |

## 1차 실기 결과 (2026-10-08, Windows 1.26.52)

| # | 결과 | 조치 |
|---|---|---|
| 1 | 대지 코어·납품함 텍스처 정상. 서랍은 미확인 | - |
| 2 | 3초보다 빠르게, 때로 즉시 생성 | **수정**: 위 칸이 차 있는 동안에도 주기가 흘렀음. 이제 빈 동안만 센다. 빛남은 미확인 |
| 3~6 | 서랍을 얻지 못해 보류 | `/dfadmin give drawer` 등 추가 |
| 7 | 정상 | - |
| 8 | 수집 정상. 상자 화면(상점·분실물 등)이 안 열림 | **수정**: 엔티티 상자 열기 절차를 InvMenu 방식으로([chestui](chestui.md)) |
| 9 | 표시 정상 | 총 플레이 시간(분 단위) 추가 |
| 10 | 차단·구매 정상. 위치·방향 파악이 어려움 | 청크 지도 화면으로 교체 |
| + | 납품함 폼 버튼을 누르면 이유 없이 끊김 | 패킷 오류 킥에 이유 표시 + ERROR 로그(원래 Debug), 없는 폼 응답 무시, 블록 화면 연타 방지. 원인이 남아 있으면 이제 화면/로그에 이유가 나온다 |
| + | Xbox 인증을 켠 접속 정상 | - |
| + | 필요 없는 아이템을 들고 납품함 클릭 시 블록이 설치된 것처럼 보임 | **수정**: 블록 사용 후 주변 블록 재전송 |

## 테스트용 명령

`platform.toml` 의 `Admin.Operators` 에 이름을 넣으면 `/dfadmin` 을 쓸 수 있다.
`give <상품 ID|기계>` (서랍, 업그레이드, 납품함, 기계 등), `money <금액>`, `level <레벨>`, `line`(샘플 무인 라인), `status`.
