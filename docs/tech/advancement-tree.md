# 발전과제 트리 화면


## 배치(서버)

- 챕터는 과제마다 데이터에 적는다(`Advancement.Chapter`). 과제는 선행을 여럿 가질 수 있다(`Parents`).
- 배치는 챕터마다 한 번 계산해 둔다(`advancement/layout.go` `layoutChapter`, 모든 노드를 보이므로 자리가 바뀌지 않는다). 왼쪽에서 오른쪽으로 놓는다(Java 모양).
  - 열 = 챕터 안에서 선행을 따라간 가장 긴 깊이. 여러 선행이면 가장 늦은 선행 다음 열이다.
  - 다른 챕터의 선행은 첫 자식 바로 앞 열에 **입구 표시**로 놓는다(그 선행 과제의 아이콘, 툴팁은 챕터와 과제 이름, 누르면 그 챕터로 간다). 그래서 선 없이 떠 있는 노드가 없고 입구의 선이 짧다.
  - 한 열보다 먼 선행과의 선은 사이 열마다 빈 경유 칸(`vias`)을 하나씩 차지한다. 배치는 경유 칸도 노드처럼 정렬하므로 선이 지나는 칸이 비어 있다.
  - 선으로 이어진 묶음마다 따로 놓는다(`layoutGroup`): 열마다 선행들 행의 평균(무게중심), 다음엔 자식들 행의 평균으로 두 번 오가며 정렬한 뒤 이웃 노드끼리 바꿔 양옆 열과의 선 교차가 줄면 자리를 바꾼다. 노드는 선행들 행의 가운데에 서되 위 노드와 겹치면 아래로 민다.
  - 선행이 없는 칸(주로 입구 표시)은 자식들 행의 가운데까지 아래로 내린다(아래 칸은 넘지 않는다). 그래서 입구가 첫 줄에 몰려 긴 선을 내리지 않는다.
  - 묶음은 목록 순서로 위에서 아래로 쌓고, 격자 아래(21행)를 넘는 묶음은 오른쪽에 새 띠로 시작한다. 한 챕터는 11열·21행 안에 들어가야 한다(`TestAdvancementTreeFits`).
- 모든 노드가 보인다: 달성, 열림(선행을 모두 달성), 잠김(선행이 남음). 잠김도 이름·아이콘·힌트를 보이고, 툴팁에 남은 선행을 적는다.
- 연결선은 자식 열 칸의 왼쪽 6px 띠에 그린다: 부모 행은 왼쪽 가장자리에서 띠 가운데까지, 사이 행은 세로 줄, 자식 행은 띠 가운데에서 노드까지. 띠는 위·아래·왼·오른 비트 4개(`ui.StripUp` …)다. 선은 바로 앞 열의 선행(여럿이면 행이 가장 가까운 것) 하나에서만 긋고, 선행이 여럿인 노드는 툴팁에 선행을 모두 적는다. DDUI 퀘스트 책은 선행마다 선을 긋는다: 선행에서 오른쪽으로 나와 열 사이 틈의 세로 길(선행마다 따로)을 따라가 노드 행에서 오른쪽으로 들어간다(`ui.questLines`). 한 틈의 세로 길 순서는 선끼리 덜 엇갈리는 순서로 고른다(`questLaneOrder`, 같으면 아래 선행일수록 왼쪽). 선행이 여럿인 노드는 선마다 들어가는 높이를 조금씩 달리 한다(위 선행일수록 위, 같은 행의 선은 곧게). 달성한 선은 다른 선 위에 그린다. 먼 선행은 경유 칸을 거친다. 그래서 선이 노드 위를 지나지 않고, 다른 선행의 선과 포개지지 않는다. 열 간격은 행 간격의 1.5배다.
- 노드 모양(`advancement.Frame`): 과제 = 일반 틀, 연구 과제 = 목표 틀, `advChallenges` = 도전 틀. 색은 상태(잠김 어둡게·열림·달성 밝게). 입구 표시는 일반 틀에 선행의 상태 색이다.

## 모양

Java 발전과제 화면처럼 보인다: 밝은 회색 창(모서리 3단 입체), 창 위에 붙은 28×32 탭(고른 탭은 밝고 창과 이어진다), 안쪽 테두리(inset) 안에 타일 배경(`textures/blocks/dirt`) 위의 트리, 흰 선에 검은 테두리 연결선, 달성(금색)·열림(회색)·잠김(어두움) 노드 틀. 다른 폼의 어두운 테마(`df_form.window`)를 쓰지 않고 `tree_form` 이 창을 직접 그린다. 제목·진행 글은 어두운 회색이라 색 코드를 쓰지 않는다.

## 폼

- 칸 32×27(띠 6 + 노드 26) 의 11열 격자를 항상 231칸(11×21)을 보낸다(빈 칸 포함: 격자가 앞의 231개 버튼을 모두 칸으로 삼으므로 모자라면 뒤의 탭·뒤로 버튼이 깨진 칸으로 나온다, 한 번에 다 보인다. 창 안쪽이 세로로 스크롤된다). 렉이 걸려도 한 번에 다 보여 주는 쪽을 택했다. 칸을 눌러도 같은 화면에서 다시 보내는 일은 없고 노드를 누르면 상세 폼이 열린다.
- 칸 버튼 글은 자리로 읽는다(`treeLabel`): 9바이트 표식 `§0§v§r`, 9번째 띠 글자(`a`+비트), 10번째 노드 글자(`a`+3×틀+상태, 틀 = 과제·목표·도전, 상태 = 잠김·열림·달성, `z` 는 노드 없음), 11번째 고름(`s`), 20바이트부터 호버 글. 리소스팩은 `'%.Ns'` 로 자리의 글자 하나를 잘라 텍스처 이름(`tree_node_<글자>`, `tree_strip_<글자>`)을 만든다. 텍스처 이름은 항상 조각 하나만 이어 붙인다. 보이기는 글자를 `#변수`에 담아 비교한다([json-ui.md](json-ui.md)).
- 제목 표식 `§d§f§z§r`(`ui.TreeToken`)이 `server_form.json` 에서 이 화면으로 보낸다.

## 텍스처

`common/` 에서 `go run ./tools/treetex`(없는 것만 만든다, `-f` 는 모두)가 `packs/dfui` 에 노드 틀 9종(`tree_node_a`~`i`)·고름 테두리·호버 빛·띠 15종(6×27) 자리표시 그림을 만든다. 직접 그린 그림으로 바꿔도 된다(이름이 같으면 도구는 덮어쓰지 않는다).
