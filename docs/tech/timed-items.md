# 기간제 아이템

코드: `internal/timed` (플랫폼 공용), 적용: `internal/instance`(정리·사용 차단), 각 게임(보관 규칙).

## 원칙

- 기간은 **현실 시간으로만** 센다. 아이템에 "언제까지"라는 실제 시각을 적어 두고, 그 시각이 지나면 사라진다.
  서버가 꺼져 있었든, 세이브가 비활성이었든, 플레이어가 접속하지 않았든 상관없다.
- 인스턴스 시간(게임 내 날짜)이나 사용량으로 기간을 세지 않는다. 사용량으로 제한할 것은 내구도·사용 횟수로 따로 만든다.

## 저장

- 아이템 스택 값(`item.Stack.WithValue`) `df-server:expires` 에 만료 시각(Unix 초, int64)을 둔다.
  Dragonfly 가 스택 값을 아이템 NBT(`dragonflyData`)로 저장하므로 플레이어 상태(DB), 상자, 분실물에서도 유지된다.
- 아이템 설명(lore) 마지막 줄에 `기간제 · 2026-10-09 21:00까지` 를 한국 시간(Asia/Seoul)으로 보여 준다(확정).
- 만료 시각이 다른 아이템끼리는 겹쳐지지 않는다(스택 값이 다르면 Dragonfly 가 다른 아이템으로 본다). 같은 시각이면 겹쳐진다.

## API (`internal/timed`)

| 함수 | 하는 일 |
|---|---|
| `For(st, d)` / `Until(st, t)` | 지금부터 d 동안 / t 까지인 기간제 아이템으로. 이미 기간제면 새 기간으로 바꾼다 |
| `Clear(st)` | 기간 해제 |
| `Expiry`, `Is`, `Expired`, `Remaining` | 만료 시각, 기간제 여부, 만료 여부, 남은 시간 |
| `Sweep(inv)` | 인벤토리에서 만료된 스택을 지우고 돌려준다 |
| `SweepPlayer(p)` | 인벤토리·갑옷·왼손·엔더 상자를 정리하고 플레이어에게 알린다 |
| `Describe(d)` | 남은 시간 문구(`2일 3시간`, `5분` …) |
| `Now`, `Zone`, `Name` | 시계(테스트용 교체), 표시 시간대, 메시지에 쓰는 아이템 이름(게임이 한글 이름으로 바꿈) |

## 사라지는 때

- **들고 있는 플레이어**: 인스턴스가 1초마다 안에 있는 플레이어를 정리한다(`Instance.sweepTimed`). 세이브에 들어오면 다음 1초 안에 접속하지 않은 사이 끝난 아이템도 사라진다.
  메시지: `기간이 끝나 사라졌습니다: 나무 곡괭이 x1`. 알림은 사라질 때만 하고 만료 전 미리 알림은 없다(확정).
- **사용 순간**: 만료된 아이템을 손에 들고 캐기·설치·사용·공격·먹기를 하면 그 동작을 취소하고 바로 정리한다(1초 정리 사이의 틈).
- **상자 등 컨테이너**: 플레이어가 컨테이너 블록을 사용(우클릭)할 때 그 안의 만료된 아이템을 지운다.
- **땅에 떨어진 아이템**: 만료된 것은 줍지 못한다. 그대로 사라지거나 공허로 떨어진다.
- **로비**: 로비 인벤토리는 세이브와 따로라 기간제 아이템을 두지 않는다.

## 드래곤팩토리 보관 규칙

아이템은 **NBT 전체로 구분**한다(이름·설명·스택 값 포함). 그래서 기간제 아이템은 따로 막지 않아도 다른 아이템과 섞이지 않는다.

- 서랍: 똑같은 아이템만 한 서랍에 들어간다. 기간제 아이템은 만료 시각까지 같아야 함께 들어가고, 만료되면 서랍이 비워진다(잠금 서랍도 아이템 지정까지 풀림).
- 기계 입력, 연구 비용 납부, 청크 구매: **추가 NBT가 없는 순수 아이템만** 받는다(`plain`). 기간제·이름 붙은 아이템 등은 레시피·연구가 요구하는 아이템과 다른 아이템으로 본다.
- 분실물 보관함: 같은 아이템끼리만 합쳐진다. 이미 만료된 것은 넣지 않고, 보관 중 만료되면 목록에서 지운다.
