# dragonfactory — 원블럭 팜

> **현재 코드는 프로토타입입니다.** 앞으로의 방향(멀티 게임 플랫폼, 공장 만들기 게임)은 [docs/design](docs/design/README.md)을 참고하세요.

[Dragonfly](https://github.com/df-mc/dragonfly) 기반의 **원블럭 서바이벌 × 스카이블럭** 농사 컨텐츠 서버입니다 (Minecraft Bedrock).

## 실행

```sh
go run .
```

처음 실행하면 `config.toml`(Dragonfly 서버 설정)과 `game.toml`(게임 설정)이 생성됩니다.
기본 포트는 `19132/udp` 입니다.

## 게임 흐름

1. 처음 접속하면 보이드 월드에 **원블럭 섬**이 자동으로 생성되고 그 위로 이동합니다.
2. 발밑의 블록(OneBlock)을 캐면 즉시 다음 블록으로 다시 생성되고, 확률적으로 씨앗·묘목·뼛가루 같은 보너스 아이템이 나옵니다.
3. 블록을 캔 횟수에 따라 **단계**가 올라가며, 나오는 블록과 보상이 바뀝니다.

   | 단계 | 시작 | 특징 |
   |---|---|---|
   | 초원 | 0 | 흙·잔디·참나무, 밀 씨앗 |
   | 밭 | 100 | 건초·호박·수박, 당근·감자·비트, 물 양동이 |
   | 숲 | 300 | 여러 원목, 묘목, 코코아 콩 |
   | 동굴 | 650 | 돌·광석 |
   | 습지 | 1100 | 진흙·점토·맹그로브, 사탕수수·연잎 |
   | 네더 정원 | 1700 | 영혼 모래·네더 사마귀 |
   | 풍요의 대지 | 2500 | 고급 광석·작물 (마지막 단계 반복) |

4. 다 자란 작물을 수확하면 **농사 XP**를 얻습니다. 레벨이 오를수록 추가 수확 확률(레벨당 2%)이 늘고, Lv.5 부터 **자동 재파종**이 해금됩니다.
5. 작물을 `/sell` 로 팔아 돈을 벌고, `/shop` 에서 씨앗·흙·물 양동이·도구를 사서 섬을 넓힙니다. 상점 상품은 섬 단계에 따라 해금됩니다.

## 명령어

| 명령어 | 설명 |
|---|---|
| `/is` | 메인 메뉴 (폼) |
| `/is create` · `home` · `sethome` · `info` | 섬 생성 / 이동 / 홈 설정 / 정보 |
| `/is invite <플레이어>` · `accept` · `leave` · `kick <이름>` | 섬 멤버 관리 (협동) |
| `/is visit <이름>` · `top` | 다른 섬 방문 / 순위 |
| `/sell hand` · `/sell all` | 작물 판매 |
| `/shop` | 농사 상점 |
| `/farm` · `/farm replant` | 농사 레벨 정보 / 자동 재파종 토글 |
| `/money` | 소지금 |
| `/spawn` | 로비로 이동 |

## 구조

```
main.go                  서버 부트스트랩, 보이드 생성기, 자동 저장/종료 처리
internal/game/           게임 로직 (플레이어 핸들러, 명령어, 폼, 스코어보드, 설정)
internal/oneblock/       원블럭 단계 및 블록/보너스 테이블
internal/farm/           수확 판정, 농사 레벨, 판매 가격
internal/island/         섬 인덱스 ↔ 좌표 그리드
internal/store/          섬/프로필 JSON 저장소
```

- 섬은 `Spacing`(기본 512) 간격의 격자에 배치되며, 중심에서 `Radius`(기본 100) 이내만 섬 멤버가 건축할 수 있습니다.
- 로비(0, 64, 0)와 섬 밖은 보호 구역이며, 보이드로 떨어지면 섬으로 되돌아갑니다. PvP는 비활성화되어 있습니다.
- 작물 성장 속도는 `game.toml` 의 `Farming.RandomTickSpeed`(기본 6, 바닐라의 2배)로 조절합니다.
- 게임 데이터는 `data/game.json` 에 주기적으로, 그리고 종료 시 저장됩니다.
